## 它能做什么

- 🚀 **我的启动清单** —— 开机按顺序打开常用软件，每步可设延时、星期条件、窗口风格；顺路还能关窗口、切前台、静音。 条件不止看钟表：还能限定「某程序在跑 / 没跑」「仅接电源 / 仅用电池」「某个文件或文件夹存在时」。
- ⏰ **定时任务** —— 到点弹提醒（可朗读），或静默跑一个动作。点「是」还能运行程序、打开文件 / 网页，或触发一个组。 也可以不看钟表、改由事件触发 —— 解锁时、锁屏时、睡眠唤醒时、空闲 N 分钟后、插拔电源时、电量偏低时。 只想临时定一个？托盘里有**快速提醒** —— 5 到 60 分钟，响一次就自己删掉。 还有几种触发看的是硬件——插拔显示器、网络接通或断开、U 盘插入——以及一种看的是你：连续用满 N 分钟就提醒你起来活动一下。
- 🎛️ **动作** —— 把一串操作打包成一套（专注 / 会议 / 收工 / 睡前……），从托盘、**全局热键**、启动清单或定时任务一键触发；内置模板可直接改。步骤之间能传值：**用户输入 / 用户选择 / 获取选中的文字**产出一个变量，后面的步骤在地址或文本里写 `{名字}` 引用它——「问我搜什么，再去搜」就是两步。
- 🧹 **系统启动项** —— 把电脑里所有开机自启的东西列在一处：不需要的关掉（只禁用、不删除），或接管到自己的清单里。
- 🔌 **端口** —— 正在被监听的 TCP 端口，连同占用它的进程和它来自哪个项目：双击一行用浏览器打开 `localhost:3000`，右键释放端口（结束占着它的全部进程，含子进程）。默认只显示从你自己项目目录跑起来的服务，那个忘了关的 dev server 不会被聊天软件和系统服务埋掉。
- ⚡ **快捷面板** —— 一个热键（默认 `Ctrl+Alt+Space`）在鼠标已经在的地方弹出瓦片网格：你自己的动作，再加重跑清单、停止、免打扰、打开窗口。点一格，或方向键选中后回车；**Esc** 或点到别处即消失。托盘菜单里也有入口，所以清空热键关掉的是快捷键，不是这个功能；而**设置 → 使用快捷面板**关掉的是功能本身，热键和中键一起停。 更喜欢用鼠标？把**长按中键**打开，完全不用键盘就能唤出它 —— 普通中键点击照常可用。 面板的页是你在面板管理器里自己建、自己排的一样东西，页上每一格是一个操作 —— 于是单个操作（锁屏、静音、打开某个软件、打开某个网址）和「跑一整个动作」可以并排摆在同一页上。页多了就分类：**顶栏选分类、左栏列这一类里的页**，两条栏都能拖着排序；不分类的话它们全在「未分类」里，那条分类栏根本不出现。
- 🖱️ **鼠标手势** —— 按住**右键**画一条轨迹，松手即运行对应的动作。八个方向，动作可以是任意一种步骤（也包括跑一整个动作）。画的时候屏幕上跟着出一条线，松手即消失。**装完就带 10 条常用的**（复制 / 粘贴 / 后退 / 前进 / 搜索选中的文字（↑↓）/ 到最底部，四个斜角是窗口的最小化·最大化·切换置顶·关闭），可直接用，也可以照着改。代价说在前面：只要有一条启用的手势，右键就被接管，**右键拖拽要先停一下再拖**（按住不动约 0.2 秒，右键就还给系统；资源管理器里右键拖文件、3D 软件里右键旋转都照这个来）——**设置**页有一个总开关（**使用鼠标手势**），手势管理器标题行上也有一个，要让右键完全不被碰时翻一下即可。不想用自带的也行：关掉总开关，让 WGestures / StrokesPlus / Quicker 去画，动作那半仍走 `Clockwork.exe --run-group "组名"`。

> **随时叫停** —— 标签条右端的急停按钮（只在有东西在跑时出现）、托盘「停止正在运行的动作」，或全局急停键（默认 `Ctrl+Alt+Q`）。正在等的长延时会被当场打断，不用干等。

## 适用范围

| 方面 | 说明 |
| --- | --- |
| **系统** | Windows 10 / 11，x64 |
| **安装** | 不用装。就一个便携的 `Clockwork.exe`，放哪个文件夹都行 |
| **管理员** | 只有「开机自启」和你自己勾了**以管理员运行**的步骤才需要 |
| **你的配置** | 就在 exe 旁边的 `clockwork.settings.json`（首次运行时该目录不可写则落到 `%APPDATA%\Clockwork\`，此后一直认这一份）——不联网、不外传 |
| **界面** | 18 种语言 + 深色 / 浅色主题。语言首次运行跟随 Windows；主题默认深色，也可设为跟随 Windows |

**已知限制。** 免安装也意味着没有自动更新——升级请下载新的 zip 覆盖 exe。沙箱 / 降权启动器会挡住发送按键、鼠标、窗口动作、已运行则激活、音量这些底层调用（会给明确提示，单纯「启动程序」不受影响）。按键重映射与文本展开不在本工具范围内——那是 AutoHotkey 的强项。

## 怎么开始用

1. 到 [Releases](https://github.com/rockbenben/Clockwork/releases) 下载最新版本——两种构建、三个下载——最后你手上都是单个 `Clockwork.exe`，放进任意文件夹。
   - **`Clockwork-<版本号>-win-x64.zip`**—— 内含 .NET 运行时，哪台 Windows 10/11 拿到都能直接跑。拿不准、或电脑在内网装不了东西，就选它。
   - **`Clockwork-<版本号>-win-x64-needs-dotnet10.zip`**—— 需要已装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)。能联网的电脑装一次，之后每次更新都只下一个很小的包。
   - **`Clockwork.exe`**—— 就是上面那个不含运行时的版本，只是没套 zip：点开即用，也可以直接盖掉现有的那份完成更新。缺运行时时 Windows 会自己提示下载。
2. 双击打开设置窗口。首次载入的示例**全都没勾选**——你不勾，什么都不会跑。
3. 想每次开机自动运行：到**设置**页勾选**开机自启**（以管理员权限注册计划任务，开机不会弹一堆授权框）。

之后它就待在托盘里：双击托盘图标打开窗口，点窗口的关闭按钮只是收回托盘。彻底退出用托盘右键的**退出**。

> [!IMPORTANT]
> **程序没有做代码签名**，首次运行 SmartScreen 会弹「已保护你的电脑」——点**更多信息 → 仍要运行**。部分杀毒软件也可能报警：写注册表 Run 键和计划任务，既是启动管理器该干的事，也是恶意软件常干的事，从外部无法区分。不想凭信任接受的话，[自己编译一份](CONTRIBUTING.md)——结果一样，二进制是你自己的。 每个 Release 也附带 `SHA256SUMS.txt` 与 GitHub 构建来源证明：`gh attestation verify <文件> -R rockbenben/Clockwork` 可验证下载的文件确实出自本仓库的 CI，而不是谁的笔记本。

## 小提示

- **双击条目即编辑**。路径 / 进程 / 日期都不用硬记：**行尾的 … 按钮**会打开对应的选择器（文件、带搜索的进程列表、日期），组合键点 **「捕获」** 按一下即录。
- **拖动一行即可调整顺序** —— 三个列表和动作编辑器的步骤列表都支持，上下移按钮照样能用。
- **保存前先试跑** —— 动作编辑器里的 **▶ 运行这一步** 和 **▶ 运行整组**，跑的都是屏幕上此刻的内容，运行时按钮会变成 **■ 停止**。
- **「复制」**在选中项下方克隆一份，比重建一条相近的快；**删除一律先确认**，处处如此。
- 双击 `Clockwork.exe` 只是打开窗口，**不会**重跑启动清单；要跑用托盘的**重新运行启动清单**。
