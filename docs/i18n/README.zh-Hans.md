> Windows 托盘小工具：开机启动 · 定时提醒 · 系统启动项 · 动作组

[![365 开源计划 #020](https://img.shields.io/badge/365%20%E5%BC%80%E6%BA%90%E8%AE%A1%E5%88%92-%23020-1f6feb)](https://github.com/rockbenben/365opensource)

![Clockwork](../../assets/social-card.png)

一个给 Windows 用的托盘小工具，帮你**管好开机与日常这几件事**：

- 🚀 **我的启动清单** —— 开机后自动、按顺序打开常用软件（可设管理员权限、先后延时、仅某些星期 / 仅 N 点前、窗口风格、已开则激活、备用路径），还能顺手做几件杂事（关掉或激活某些窗口、发送按键 / 发送文本、调音量等）。
- ⏰ **定时任务** —— 到点弹提醒，可朗读、按「星期 / 每 N 天 / 每月」周期、也能「登录时」触发；点「是」还能运行程序 / 打开文件（如音乐）/ 开网页 / 跑一个动作组；也支持循环运行（每隔 N 分钟）与仅一次。
- 🧹 **系统启动项** —— 把电脑里**所有开机自启的软件**列出来，一键关掉不需要的（只禁用、不删除，随时恢复），还能一键「纳入」到自己的启动清单来接管。
- 🎛️ **动作组** —— 把一串动作打包成可复用的「组」（专注 / 会议 / 收工 / 睡前……），在托盘、**全局热键**、启动清单或提醒里一键触发；内置常用模板。

免安装、绿色单文件夹、所有设置点点鼠标就能改；暗色界面、高分屏自适应。界面提供 **18 种语言**，首次运行默认跟随系统显示语言。

> 📖 **详细使用说明：** [English](../USAGE.md) · [中文](../USAGE.zh-CN.md)

## 运行要求

- Windows 10 / 11（x64）
- 无需额外安装：自包含单文件 `Clockwork.exe`，内置 .NET 运行时，开箱即用。

## 怎么开始用

1. 到 [Releases](https://github.com/rockbenben/Clockwork/releases) 下载最新的 `Clockwork-<版本号>.zip`，解压得到单个 `Clockwork.exe`，放进任意文件夹（绿色免安装，放哪都行）。想自己构建见下方 **给开发者**。
2. 双击 **`Clockwork.exe`** 打开设置窗口。
   - **首次打开**会在启动清单和定时提醒里各载入几条**示例**，照着改成你自己的即可——它们全都默认没勾选，你不勾就什么都不会执行。「动作组」页也自带两个可直接运行的组（离开一下 / 收工·下班）——这两个**默认勾选**，因为动作组不会自己触发，只有你主动运行它才会执行。你的设置存在同文件夹的 `clockwork.settings.json`，只在本机、不入库。
3. 想每次开机自动运行：到 **「设置」** 页点「开机自启」按钮开启（用管理员权限注册计划任务，避免开机弹一堆授权框）。

> 平时它安静待在右下角托盘。双击托盘图标打开窗口；点窗口关闭按钮只是收起到托盘，不会退出。彻底退出用托盘右键「退出」。

> **首次运行会有告警，属正常。** 程序未做代码签名，SmartScreen 会弹「已保护你的电脑」——点「更多信息」→「仍要运行」。部分杀毒软件也可能报警，因为写注册表 Run 键和计划任务既是启动管理器该干的事，也是恶意软件常干的事，从外部无法区分。不想凭信任接受的话，按下方**开发者构建**自己编译一份，结果一样、二进制是你自己的。

## 五个标签页

### 我的启动清单

一条**有序步骤列表**，开机时从上到下依次执行。点「新增 ▾」选类型，可任意增删、上下移；每步可单独启用 / 禁用、设「执行后延时」、设「重复次数」（循环 N 次），并加条件「仅某些星期 / 仅 N 点前」。步骤类型：

- **启动程序** —— 目标（可「浏览…」选文件）/ 参数 / 工作目录（留空 = 目标所在目录）/ 管理员。目标可填 `.exe`、文档、快捷方式、网址；`.ps1` 会自动用 PowerShell 运行。进阶：**窗口风格**（最小化 / 最大化 / 隐藏）、**已在运行则激活**（把它带到最前、不重复启动；进程名可「选择…」）、**备用路径**（每行一条完整路径，取第一个存在的——多设备安装路径不一致时用）。
- **发送按键** —— 如 Win+D、Alt+K、Ctrl+Enter、F5（可点「捕获」直接按下快捷键录入）。
- **发送文本** —— 往当前焦点窗口逐字输入一段文本（也可指定「目标进程」，可「选择…」）。
- **音量** —— 静音 / 取消静音 / 设为音量。
- **窗口动作** —— 按进程名（可「选择…」，带搜索）关闭 / 最小化 / 最大化 / 带到最前面 / 置前并发送按键；慢启动应用可设「等窗口出现最多 N 秒」。
- **系统命令** —— 显示桌面 / 锁屏 / 息屏 / 清空回收站 / 清空剪贴板 / 打开设置 / 任务管理器 / 截图 / 睡眠 / 休眠 / 注销 / 重启 / 关机（后三项执行前弹确认框）。
- **延时** —— 单纯等待 N 秒再继续。
- **动作组** —— 引用一个已定义好的动作组；它的「重复次数」指**这条引用**触发几次（组自身也能整组重复——见下方「动作组」）。

> **开机延迟**（设置页，仅开机自启）：登录后先固定等这么多秒，让「登录风暴」（磁盘 / CPU 被一堆自启抢占）过峰，再跑清单；手动「重新运行」不受影响。开机太早、有软件没起来就把它调大（0–600 秒）。

> **随时叫停** —— 窗口标签条右端的**急停按钮**（只在有动作在跑时出现），或托盘「停止正在运行的动作」，或按全局**急停键**（设置页设，默认 `Ctrl+Alt+Q`）。正在跑的会在当前动作后立刻停下；开机延迟、等窗口出现等长等待也会被立即打断。

### 定时任务

设**时间**（或改「登录时」）、**周期**（星期 / 每 N 天 / 每月 / **仅一次（指定日期）**），再选一种**动作**：**弹窗提醒**或**静默运行动作组**。只显示所选动作的字段，不会让你填一个填了不生效的框。

配了「点是后」动作（运行程序 / 打开文件 / 开网页 / 跑动作组）的会弹「是 / 否」窗、还带「稍后」（默认 10 分钟，▾ 可选 5–60 分钟）；其余走右下角**提醒卡片**（不抢视线，显示时长由「自动关闭」秒数决定，**0 = 常驻到你点掉**）。文字可选朗读。

**循环运行**把一条任务变成全天日程：*每隔 N 分钟一次，直到 HH:mm*（留空 = 当天结束）。它和**未确认时催促**是两码事——催促一确认就停，循环运行确认后照跑下一轮，静默动作组正是靠这条才能当轮询用。循环不跨午夜，次日从任务自己的时间重新开始。进度会落盘，中午重启程序也不丢当天剩下的轮次。

**仅一次**在指定日期触发后**自动取消勾选**，条目仍留在列表里——改个日期重新勾上即可再用。它会等催促 / 稍后都走完才关掉自己，不会把一次还没送达的提醒掐断。

没人应答的弹窗既不会一直挡路、也不会弄丢：最多挂 1 分钟就自动转成「**稍后 10 分钟**」，过会儿重新弹。这个状态和手点的稍后一样落盘——重启不丢；开了「**错过必补**」的，即使合盖睡过午夜，次日也会补弹一次。同一条提醒重复触发只占一张卡片（标 **×N**），点掉或自动消失的卡片都能在托盘右键「**最近通知**」里回看并重弹。

进阶：**自动关闭**、**重复催促**（每 N 分钟再弹、直到某时刻）、**到点后延迟 + 随机延迟**、**宽限**（到点恰好关机 / 睡眠时补弹）、**错过必补**（休眠 / 关机整段错过时下次补弹一次）、「每 N 天」的**起算日**（可「选日期」）。「当天已弹 / 稍后到几点」会落盘（`clockwork.state.json`），跨重启不丢、也不重弹。

要专注或开会时，托盘可「**暂停提醒** 1 / 2 / 4 小时」（勿扰）：期间所有提醒（含静默组）都不触发，到时自动恢复。

### 系统启动项

列出电脑里**所有开机自启**的项（注册表 Run 键、启动文件夹、计划任务）。取消「启用」即禁用——**只禁用、不删除，随时勾回来恢复**（即时生效）。带「需管理员」的项会提示以管理员身份重开。系统 / 策略 / 一次性项（组策略 Run、RunOnce、Winlogon、Active Setup）不可改动、**默认不显示**——勾「显示系统 / 只读项」才列出（置灰）。**右键某行**可「接管到启动清单」（交给本工具管，仅支持注册表 Run 键与启动文件夹项）或「从系统中删除」（**彻底移除、需确认且无法撤销**；只想让它别开机启动的话取消勾选即可）。顶部**过滤框**按名称 / 命令快速筛；命令太长悬停可看全文。

### 动作组

把一串动作打包成可复用的「组」。「新增 ▾」可从**内置模板**（专注 / 会议 / 收工 / 睡前 / 离开一下 / 截图标注 / 久坐提醒）创建，改进程名再保存。组本身**只定义动作**，四种触发：托盘「运行：某组」、**全局热键**、启动清单里加「动作组」步骤、定时任务挂「点是后 / 静默动作组」。同组同时只跑一份。

**循环。** 组可以**整组重复**（重复次数 + 每轮间隔，在动作组编辑器里设）。若只想循环*其中一段*，把那段步骤单独建成一个组，再用「动作组」步骤引用它并设重复次数——组可以引用组，保存时会拦下环引用并报出引用链（`A → B → A`）。三种重复相乘：单步 × 引用 × 整组。单次运行有 **5000 步**保险丝，过大的组合会停下而不是没完没了。

「消息」步骤是**确认闸门**：答「否」会中止本组剩余步骤*连同后续轮次*，并向上传染给引用它的那个组——拒绝一次就够，即使它是被 ×N 循环的子组也一样。

消息步骤除了弹对话框，也可以选**卡片**形态：从右下角滑入，按你设的秒数自动关闭（0 = 一直留到你点掉），组不等你回应就照常往下跑。卡片也是唯一能从**启动清单**里弹出来的消息形态——开机时弹对话框会把整条清单卡住，卡片不会。

> **全局热键** —— 在组编辑器里点热键框、按下快捷键（如 `Ctrl+Alt+F`），即可在任何地方运行该组，无需打开菜单。Esc 取消、Delete 清空。停用的组会释放其组合键；系统保留的组合键（Alt+F4、Ctrl+Shift+Esc……）以及已被其它组或急停键占用的组合键会被拒绝并提示。 **热键是开关：** 组还在跑时再按一次即取消这一次运行 —— 别的组和启动清单照跑（要停一切用急停键）。只有绑了热键的组能这样取消。

### 设置

**开机延迟**（0–600 秒，仅开机自启）、**启动时最小化到托盘**、**急停键**（点输入框按下即录入，Esc 取消、Delete 清空；默认 `Ctrl+Alt+Q`）、**界面语言**（简体中文、English、日本語 等共 18 种，切换后自动重启生效）。

**导出配置 / 导入配置** —— 备份或把整套设置搬到另一台电脑。导出即把 `clockwork.settings.json` 另存到你选的位置；导入会**覆盖全部配置**（启动清单 / 定时任务 / 动作组 / 设置），故先弹确认、把当前配置备份为 `clockwork.settings.json.bak`，导入后自动重启生效。

## 小提示

- 列表里**双击条目即编辑**。填路径 / 进程 / 组合键 / 日期不用硬记：**「浏览…」「选择…」（带搜索）「捕获」「选日期」**。
- **拖动一行即可调整顺序**，启动清单和动作组编辑器的步骤列表都支持（上下移按钮照样能用）。
- **保存前先试跑一遍** —— 动作组编辑器里有 **▶ 运行这一步** 和 **▶ 运行整组**，跑的都是屏幕上此刻的内容。整组运行时按钮会变成 **■ 停止**，关掉编辑器也会让它停下来。
- 「定时任务」「动作组」页的**「复制」**会在选中项下方克隆一份——想要一条相近的配置时比重新建快；复制出的动作组名为「…（副本）」。
- **删除一律先确认**：列表条目、动作组编辑器里的步骤、系统启动项都一样。
- 双击 `Clockwork.exe` 只开设置窗口，**不会**立刻跑启动清单；想立刻跑用托盘「重新运行启动清单」。
- **请用正常方式启动**（双击 / 托盘 / 计划任务）。若用某些沙箱 / 受限权限的启动器（如 Lucy）打开，Windows 会限制部分底层调用，发送按键 / 窗口动作 / 已运行则激活 / 发送文本到指定进程 / 音量 等可能不可用（会给清楚提示，不影响单纯「启动程序」）。
- 个人设置在 `clockwork.settings.json`（仅本机）。删掉它重开即可恢复示例。任务状态在 `clockwork.state.json`（同样只在本机，删掉无妨）。
- 加 `.ahk` 步骤需装 AutoHotkey。全局热键 / 文本展开不在本工具范围（那是 AutoHotkey 的强项）。

## 给开发者

C#/.NET WPF，源码在 `app/`（需 .NET 10 SDK）。分层：`Core/` 纯逻辑 · `Native/` Win32 互操作 · `Engine/` 执行 · `ViewModels/` + `Views/` 界面 · `I18n/` + `Resources/` 多语言（中性 = 中文源，`Strings.<code>.resx` 每语言一份卫星程序集）。

- 跑测试（xUnit）：
  ```powershell
  dotnet test app.Tests/Clockwork.Tests.csproj
  ```
- 打包自包含单文件 exe（单文件 / 自包含 / 压缩等属性已写在 csproj 里）：
  ```powershell
  dotnet publish app/Clockwork.csproj -c Release -r win-x64
  ```
  产物在 `app/bin/Release/net10.0-windows/win-x64/publish/Clockwork.exe`。
- **CI / 发版**（GitHub Actions）：push / PR 自动在 Windows runner 上构建并跑全部测试；推送 `v*` 标签（如 `v2.0.0`）会自动构建、以标签号作文件版本、创建 GitHub Release 并附上 `Clockwork-<标签>.zip`（内含 `Clockwork.exe`）。
