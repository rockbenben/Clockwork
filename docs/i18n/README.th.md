> เครื่องมือใน System Tray ของ Windows: ตัวเปิดโปรแกรมตอนเริ่มระบบ · การเตือน · รายการเริ่มต้นของระบบ · กลุ่มการทำงาน

![Clockwork](../../assets/social-card.png)

เครื่องมือเล็ก ๆ ใน System Tray ของ Windows ที่ช่วยจัดการส่วนงานซ้ำ ๆ ในตอนเริ่มต้นวันทำงานหน้าคอมพิวเตอร์ของคุณ:

- 🚀 **รายการเริ่มต้น** — เปิดแอปที่คุณใช้ประจำโดยอัตโนมัติเมื่อล็อกอิน ตามลำดับ (สิทธิ์ผู้ดูแลระบบรายขั้นตอน, การหน่วงเวลา, เฉพาะบางวันในสัปดาห์ / เฉพาะก่อน N นาฬิกา, สไตล์หน้าต่าง, สลับไปหน้าต่างเดิมถ้ากำลังรันอยู่, เส้นทางสำรอง) และทำงานเล็ก ๆ น้อย ๆ ระหว่างทาง (ปิดหรือโฟกัสหน้าต่าง, ส่งคีย์ / ข้อความ, ตั้งระดับเสียง…)
- ⏰ **งานตามกำหนดเวลา** — เด้งการเตือนตรงเวลา; อ่านออกเสียง; ทำซ้ำตามวันในสัปดาห์ / ทุก ๆ N วัน / รายเดือน; หรือทริกเกอร์ "เมื่อล็อกอิน" การคลิก **ใช่** สามารถรันโปรแกรม, เปิดไฟล์ (เช่น เพลง) หรือ URL, หรือรันกลุ่มการทำงาน และยังรองรับการรันตามช่วงเวลาซ้ำและการรันเพียงครั้งเดียวด้วย
- 🧹 **รายการเริ่มต้นของระบบ** — แสดง **ทุกอย่างบนพีซีของคุณที่เริ่มทำงานอัตโนมัติ** และปิดสิ่งที่คุณไม่ต้องการ (ปิดใช้งาน ไม่ได้ลบ — เปิดกลับได้ทุกเมื่อ) คลิกเดียวเพื่อ "รับช่วง" รายการเข้าสู่รายการเริ่มต้นของคุณเอง
- 🎛️ **กลุ่มการทำงาน** — รวมชุดการทำงานหลายอย่างไว้ในกลุ่มที่นำกลับมาใช้ซ้ำได้ (โฟกัส / ประชุม / สรุปงาน / เข้านอน…) และทริกเกอร์ด้วยการคลิกครั้งเดียวจาก System Tray, **คีย์ลัดส่วนกลาง**, รายการเริ่มต้น, หรือการเตือน มีเทมเพลตในตัวให้พร้อมใช้

ไม่ต้องติดตั้ง พกพาได้เต็มรูปแบบในโฟลเดอร์เดียว ตั้งค่าทุกอย่างได้ด้วยเมาส์ ธีมมืด รองรับหน้าจอความละเอียดสูง (high-DPI)

## ความต้องการของระบบ

- Windows 10 / 11 (x64)
- ไม่ต้องติดตั้งอะไร: ไฟล์เดียวแบบ self-contained `Clockwork.exe` ที่มี .NET runtime รวมมาให้ในตัว

## เริ่มต้นใช้งาน

1. ดาวน์โหลด `Clockwork-<เวอร์ชัน>.zip` ล่าสุดจาก [Releases](https://github.com/rockbenben/Clockwork/releases) แล้วแตกไฟล์ — ข้างในมีไฟล์ `Clockwork.exe` เพียงไฟล์เดียว; วางไว้ในโฟลเดอร์ใดก็ได้ (พกพาได้ — วางที่ไหนก็ได้) หากต้องการบิลด์เอง ดู **สำหรับนักพัฒนา** ด้านล่าง
2. ดับเบิลคลิก **`Clockwork.exe`** เพื่อเปิดหน้าต่างการตั้งค่า
   - ในการ **รันครั้งแรก** จะโหลด **ตัวอย่าง** ไม่กี่รายการในรายการเริ่มต้นและการเตือน เพื่อให้คุณปรับให้เข้ากับของตัวเอง — ทั้งหมดยังไม่ถูกติ๊กไว้ จึงไม่มีอะไรทำงานจนกว่าคุณจะติ๊กเอง แท็บ **กลุ่มการทำงาน** ก็เริ่มต้นมาพร้อมสองกลุ่มที่พร้อมใช้งานทันที (ออกไปสักครู่ / เลิกงาน) — สองกลุ่มนี้ *ถูกติ๊กไว้* แล้ว เพราะกลุ่มจะไม่ทำงานเองโดยไม่มีใครสั่ง มันจะรันก็ต่อเมื่อคุณสั่งให้ทำงานเท่านั้น การตั้งค่าของคุณจะอยู่ใน `clockwork.settings.json` ข้าง ๆ ไฟล์ exe — อยู่ในเครื่องเท่านั้น ไม่เคยถูก commit
3. เพื่อให้รันทุกครั้งที่บูต: ที่แท็บ **การตั้งค่า** คลิก **เริ่มเมื่อล็อกอิน** (ลงทะเบียนงานที่ตั้งเวลาไว้ด้วยสิทธิ์ผู้ดูแลระบบ จึงไม่มีหน้าต่าง UAC เด้งเป็นพรืดตอนบูต)

> มันจะอยู่เงียบ ๆ ใน System Tray ดับเบิลคลิกไอคอนใน Tray เพื่อเปิดหน้าต่าง; ปุ่มปิดของหน้าต่างเพียงซ่อนมันลง Tray เท่านั้น หากต้องการปิดจริง ๆ ให้คลิกขวาที่ Tray แล้วเลือก **ออก**

> **มีคำเตือนตอนเปิดครั้งแรกถือเป็นเรื่องปกติ** ไฟล์ exe ไม่ได้เซ็นรับรองโค้ด SmartScreen จึงขึ้นว่า «Windows protected your PC» — คลิก **More info → Run anyway** โปรแกรมแอนตี้ไวรัสก็อาจแจ้งเตือนได้ เพราะการเขียนคีย์ Run ในรีจิสทรีและงานตามกำหนดเวลา คือสิ่งที่ตัวจัดการโปรแกรมเริ่มต้นต้องทำ และก็เป็นสิ่งที่มัลแวร์มักทำเช่นกัน จากภายนอกแยกไม่ออก ถ้าไม่อยากยอมรับด้วยความเชื่อใจ ให้คอมไพล์เองตามหัวข้อ **สำหรับนักพัฒนา** ด้านล่าง ผลลัพธ์เหมือนกัน และไบนารีเป็นของคุณเอง

## ห้าแท็บ

ห้าแท็บ รายละเอียดของทุกช่องอยู่ใน[คู่มือฉบับเต็ม](../USAGE.md)

- **รายการเริ่มต้น** — ขั้นตอนทำงานจากบนลงล่างตอนเข้าสู่ระบบ ประเภท: เปิดโปรแกรม · ส่งปุ่ม · ส่งข้อความ · ระดับเสียง · การกระทำกับหน้าต่าง · คำสั่งระบบ · กลุ่มการทำงาน · หน่วงเวลา · ข้อความ แต่ละขั้นตั้งหน่วงเวลาหลังทำงาน จำนวนครั้งที่ทำซ้ำ และเงื่อนไข (เฉพาะบางวัน / เฉพาะก่อน N นาฬิกา) ได้ ส่วนการเปิดโปรแกรมยังตั้งสิทธิ์ผู้ดูแล รูปแบบหน้าต่าง เปิดอยู่แล้วให้สลับไปหา และพาธสำรองได้ด้วย
- **งานตามกำหนดเวลา** — เวลา (หรือ "ตอนเข้าสู่ระบบ") × รอบ (วันในสัปดาห์ / ทุก N วัน / รายเดือน / ครั้งเดียว) × การกระทำหนึ่งอย่าง: การแจ้งเตือน (กล่องใช่/ไม่ใช่พร้อมปุ่มเลื่อน หรือการ์ดที่มุมจอ อ่านออกเสียงได้) หรือกลุ่มการทำงานที่รันแบบเงียบ พร้อมทั้งการรันเป็นช่วง การเตือนซ้ำ การตามเก็บงานที่พลาด และโหมดห้ามรบกวนจากถาดระบบ
- **รายการเริ่มต้นของระบบ** — ทุกอย่างที่เริ่มเองบนเครื่อง (คีย์ Run ในรีจิสทรี โฟลเดอร์ Startup งานตามกำหนดเวลา): ปิดได้ (แค่ปิดใช้งาน ไม่ได้ลบ) รับมาไว้ในรายการเริ่มต้นของคุณเอง หรือลบทิ้งถาวร
- **กลุ่มการทำงาน** — ชุดการกระทำที่นำกลับมาใช้ซ้ำได้ สั่งได้จากถาดระบบ **คีย์ลัดส่วนกลาง** (กดซ้ำเพื่อยกเลิกรอบนั้น) ขั้นตอนในรายการเริ่มต้น หรืองานตามกำหนดเวลา กลุ่มทำซ้ำทั้งกลุ่มได้และอ้างถึงกลุ่มอื่นได้ (การอ้างวนถูกปฏิเสธตอนบันทึก) ส่วนขั้นตอน **ข้อความ** ใช้ใช่ / ไม่ใช่กั้นขั้นตอนที่เหลือ
- **การตั้งค่า** — หน่วงเวลาเริ่มต้น (0–600 วินาที เฉพาะตอนบูต), เริ่มแบบย่อลงถาดระบบ, เริ่มพร้อมการเข้าสู่ระบบ, คีย์หยุดฉุกเฉิน, ภาษาอินเทอร์เฟซ (18 ภาษา), นำเข้า / ส่งออกการตั้งค่า

> **หยุดได้ทุกเมื่อ** — **ปุ่มหยุด** ที่ปลายขวาของแถบแท็บ (แสดงเฉพาะตอนมีอะไรกำลังทำงาน), ถาดระบบ → **หยุดการทำงานที่กำลังรัน** หรือ**คีย์หยุดฉุกเฉิน**ส่วนกลาง (ค่าเริ่มต้น `Ctrl+Alt+Q`) การรอนาน ๆ (หน่วงเวลาเริ่มต้น, รอหน้าต่าง) จะถูกตัดทันที

## เคล็ดลับ

- **ดับเบิลคลิกที่แถวเพื่อแก้ไข** เมื่อกรอกเส้นทาง / โปรเซส / คีย์ลัด / วันที่ คุณไม่ต้องพิมพ์เองด้วยมือ: **เรียกดู…**, **เลือก…** (ตัวเลือกโปรเซสที่ค้นหาได้), **บันทึก** และ **เลือกวันที่**
- **ลากแถวเพื่อจัดลำดับใหม่** — ใช้ได้ทั้งสามรายการ (รายการเริ่มต้น, งานตามกำหนดเวลา, กลุ่มการทำงาน) และรายการขั้นตอนในตัวแก้ไขกลุ่ม โดยปุ่มขึ้น / ลงยังใช้ได้เหมือนเดิม
- **ลองรันก่อนบันทึก** — ในตัวแก้ไขกลุ่มมี **▶ รันขั้นนี้** และ **▶ รันทั้งกลุ่ม** ทั้งคู่รันสิ่งที่อยู่บนหน้าจอตอนนี้ ระหว่างรันปุ่มจะเปลี่ยนเป็น **■ หยุด** และการปิดตัวแก้ไขก็ทำให้หยุดเช่นกัน
- **ทำสำเนา** (แท็บงานตามกำหนดเวลา / กลุ่มการทำงาน) จะโคลนแถวที่เลือกไว้ไว้ใต้แถวนั้นทันที — เร็วกว่าการสร้างรายการที่เกือบเหมือนกันขึ้นใหม่; กลุ่มที่ทำสำเนาจะมีชื่อว่า "… (สำเนา)"
- **การลบจะถามยืนยันก่อนเสมอ** ในทุกที่ — ทั้งแถวในรายการ, ขั้นตอนภายในตัวแก้ไขกลุ่ม และรายการเริ่มต้นของระบบ
- การดับเบิลคลิก `Clockwork.exe` เพียงเปิดการตั้งค่าเท่านั้น — มัน **ไม่** รันรายการเริ่มต้นทันที; ให้ใช้ **รันรายการเริ่มต้นอีกครั้ง** จาก Tray แทน
- **เปิดมันแบบปกติ** (ดับเบิลคลิก / Tray / งานที่ตั้งเวลาไว้) ตัวเปิดแบบแซนด์บ็อกซ์ / สิทธิ์ลดทอนบางตัวจะบล็อกการเรียกระดับต่ำ ดังนั้นการส่งคีย์ / การกระทำกับหน้าต่าง / สลับไปหน้าต่างเดิมถ้ากำลังรันอยู่ / การส่งข้อความไปยังโปรเซส / ระดับเสียง อาจไม่ทำงาน (คุณจะได้รับการแจ้งที่ชัดเจน; "เปิดโปรแกรม" ธรรมดาไม่ได้รับผลกระทบ)
- คอนฟิกของคุณคือ `clockwork.settings.json` (อยู่ในเครื่องเท่านั้น) ลบมันเพื่อรีเซ็ตกลับเป็นตัวอย่าง สถานะงานคือ `clockwork.state.json` (อยู่ในเครื่องเช่นกัน; ลบได้อย่างปลอดภัย)
- การเพิ่มขั้นตอน `.ahk` ต้องติดตั้ง AutoHotkey ไว้ คีย์ลัดส่วนกลาง / การขยายข้อความอยู่นอกขอบเขต — นั่นเป็นจุดแข็งของ AutoHotkey

## สำหรับนักพัฒนา

C#/.NET WPF; ซอร์สโค้ดอยู่ใน `app/` (ต้องใช้ .NET 10 SDK) เลเยอร์: `Core/` ตรรกะล้วน · `Native/` Win32 interop · `Engine/` การดำเนินการ · `ViewModels/` + `Views/` UI · `I18n/` + `Resources/` การแปลภาษา (neutral = ซอร์สภาษาจีน, หนึ่ง `Strings.<code>.resx` satellite ต่อภาษา)

- รันเทสต์ (xUnit):
  ```powershell
  dotnet test app.Tests/Clockwork.Tests.csproj
  ```
- บิลด์ไฟล์เดียวแบบ self-contained (single-file / self-contained / compression ถูกตั้งค่าไว้ใน csproj):
  ```powershell
  dotnet publish app/Clockwork.csproj -c Release -r win-x64
  ```
  ผลลัพธ์: `app/bin/Release/net10.0-windows/win-x64/publish/Clockwork.exe`
- **CI / releases** (GitHub Actions): การ push / PR จะบิลด์และรันเทสต์ทั้งหมดบน Windows runner; การ push แท็ก `v*` (เช่น `v2.0.0`) จะบิลด์, ประทับเวอร์ชันไฟล์จากแท็ก, สร้าง GitHub Release และแนบ `Clockwork-<แท็ก>.zip` (ซึ่งมี `Clockwork.exe` อยู่ข้างใน)
