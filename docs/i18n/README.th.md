## ทำอะไรได้บ้าง

- 🚀 **รายการเริ่มต้น** — เปิดแอปที่คุณใช้ประจำตามลำดับเมื่อล็อกอิน ตั้งการหน่วงเวลา เงื่อนไขวันในสัปดาห์ และสไตล์หน้าต่างได้รายขั้นตอน พร้อมปิด โฟกัส หรือปิดเสียงระหว่างทาง เงื่อนไขไม่ได้ดูแค่นาฬิกา ยังจำกัดได้ว่าให้ทำเฉพาะตอนที่โปรแกรมหนึ่งกำลังทำงาน (หรือไม่ได้ทำงาน) เฉพาะตอนเสียบไฟหรือเฉพาะตอนใช้แบตเตอรี่ และเฉพาะตอนที่มีไฟล์หรือโฟลเดอร์นั้นอยู่
- ⏰ **งานตามกำหนดเวลา** — การเตือนตรงเวลา อ่านออกเสียงได้ถ้าต้องการ หรือกลุ่มการทำงานที่รันแบบเงียบ การคลิก **ใช่** สามารถรันโปรแกรม เปิดไฟล์หรือ URL หรือสั่งกลุ่มให้ทำงาน หรือให้เหตุการณ์เป็นตัวสั่งแทนนาฬิกาก็ได้ — เมื่อปลดล็อก เมื่อล็อกหน้าจอ เมื่อตื่นจากสลีป เมื่อไม่มีการใช้งานครบ N นาที เมื่อเสียบหรือถอดสายไฟ หรือเมื่อแบตเตอรี่ต่ำ ต้องการแค่ครั้งเดียวใช่ไหม? ในถาดระบบมี **เตือนด่วน** ตั้งแต่ 5 ถึง 60 นาที เตือนครั้งเดียวแล้วลบตัวเอง ตัวกระตุ้นอื่น ๆ คอยดูฮาร์ดแวร์ — จอแสดงผลเปลี่ยน เครือข่ายกลับมาหรือหลุด เสียบไดรฟ์ USB — และอีกหนึ่งคอยดูคุณ: เตือนเมื่อทำงานต่อเนื่องครบ N นาที จะได้ลุกขึ้นยืดเส้นยืดสาย
- 🎛️ **กลุ่มการทำงาน** — รวมกิจวัตรหนึ่งชุด (โฟกัส / ประชุม / สรุปงาน / เข้านอน…) แล้วสั่งจาก System Tray, **คีย์ลัดส่วนกลาง**, รายการเริ่มต้น หรืองานตามกำหนดเวลา มีเทมเพลตให้พร้อมใช้ แต่ละขั้นส่งค่าต่อกันได้: **รับข้อความจากผู้ใช้ ให้ผู้ใช้เลือก** และ **ดึงข้อความที่เลือกไว้** ต่างเก็บผลลัพธ์ไว้ในตัวแปร แล้วขั้นถัดไปอ้างถึงมันเป็น `{ชื่อ}` ใน URL หรือในข้อความ — «ถามฉันว่าจะค้นอะไร แล้วค้นให้» ก็คือสองขั้นเท่านั้น
- 🧹 **รายการเริ่มต้นของระบบ** — ทุกอย่างบนพีซีที่เริ่มทำงานเองรวมอยู่ในรายการเดียว: ปิดสิ่งที่ไม่ต้องการ (ปิดใช้งาน ไม่ได้ลบ) หรือรับช่วงเข้าสู่รายการเริ่มต้นของคุณเอง
- 🔌 **พอร์ต** — พอร์ต TCP ที่กำลังรับฟังทุกพอร์ต พร้อมโปรเซสที่ถืออยู่และโปรเจกต์ที่มันมาจาก ดับเบิลคลิกที่แถวเพื่อเปิด `localhost:3000` ในเบราว์เซอร์ คลิกขวาเพื่อปล่อยพอร์ต ซึ่งจะสิ้นสุดทุกโปรเซสที่ถือมันรวมถึงโปรเซสลูก ค่าเริ่มต้นจะแสดงเฉพาะบริการที่เริ่มจากโฟลเดอร์โปรเจกต์ของคุณ dev server ที่ลืมปิดจึงไม่ถูกกลบไว้ใต้แอปแชทและบริการของระบบ
- ⚡ **แผงด่วน** — ปุ่มลัดปุ่มเดียว (ค่าเริ่มต้น `Ctrl+Alt+Space`) เปิดตารางไทล์ตรงตำแหน่งที่เมาส์อยู่: การกระทำของคุณเอง บวกกับเรียกใช้รายการเริ่มต้นอีกครั้ง หยุด ห้ามรบกวน และเปิดหน้าต่าง คลิกที่ไทล์ หรือใช้ปุ่มลูกศรเลือกแล้วกด Enter กด **Esc** หรือคลิกที่อื่นเพื่อปิด ในเมนูซิสเทมเทรย์ก็มี ดังนั้นการล้างปุ่มลัดจะปิดแค่ปุ่มลัด ไม่ใช่ตัวฟีเจอร์ ถนัดเมาส์มากกว่า? เปิด **กดปุ่มกลางค้างไว้** แล้วเปิดแผงได้โดยไม่ต้องแตะคีย์บอร์ด — การคลิกปุ่มกลางแบบปกติยังใช้ได้ หน้าของแผงเป็นสิ่งที่คุณสร้างเองและจัดเรียงเองในตัวจัดการแผง และทุกช่องบนหน้าหนึ่งคือหนึ่งการกระทำ ทำให้ล็อกหน้าจอ ปิดเสียง เปิดแอป เปิด URL และ «เรียกใช้ทั้งกลุ่ม» อยู่เคียงกันได้ พอหน้าเยอะขึ้นก็จัดเป็นหมวด: **แถวบนเลือกหมวด แถวซ้ายไล่หน้าในหมวดนั้น** ทั้งสองแถวลากเพื่อจัดลำดับได้ ถ้าไม่จัดหมวดเลย ทุกหน้าจะอยู่ใน *ไม่มีหมวด* และแถวหมวดจะไม่ปรากฏเลย ไม่ใช้เลยใช่ไหม **ตั้งค่า → ใช้แผงด่วน** หยุดการทำงานทั้งหมด ทั้งคีย์ลัดและปุ่มกลาง
- 🖱️ **เจสเจอร์เมาส์** — กด**ปุ่มขวา**ค้างแล้ววาดเส้น การกระทำที่ตรงกันจะทำงาน รองรับแปดทิศทางและขั้นทุกชนิด (รวมถึงเรียกใช้ทั้งกลุ่ม) เส้นจะปรากฏบนหน้าจอขณะที่คุณวาด และหายไปเมื่อปล่อยปุ่ม **ติดตั้งเสร็จก็มีมาให้ 10 แบบ** (คัดลอก / วาง / ย้อนกลับ / ไปข้างหน้า / ค้นหาข้อความที่เลือก (↑↓) / ไปล่างสุด และสี่ทิศทแยงสำหรับย่อ ขยาย ปักหมุดไว้บนสุด และปิดหน้าต่าง) ใช้ได้เลยหรือแก้ตามใจก็ได้ ขอบอกราคาไว้ก่อน: มีเจสเจอร์ที่เปิดอยู่เพียงหนึ่งอันปุ่มขวาก็ถูกยึดแล้ว ดังนั้น **การลากด้วยปุ่มขวาต้องหยุดสักครู่ก่อน** — กดค้างไว้นิ่ง ๆ ราว 0.2 วินาที แล้วค่อยลาก (ลากไฟล์ด้วยปุ่มขวาใน File Explorer, หมุนมุมมองในแอป 3D) ถ้าต้องการให้ปุ่มขวาไม่ถูกแตะต้องเลย แถวหัวเรื่องของตัวจัดการเจสเจอร์มีสวิตช์หลักอยู่ และไม่จำเป็นต้องใช้ของที่ให้มาด้วย: ปิดสวิตช์นั้น ให้ WGestures / StrokesPlus / Quicker เป็นคนวาด ส่วนการกระทำยังอยู่ที่นี่ผ่าน `Clockwork.exe --run-group "โฟกัส"` สวิตช์นี้มีที่แท็บ **ตั้งค่า** ด้วย (**ใช้ท่าทางเมาส์**)

> **หยุดได้ทุกเมื่อ** — ปุ่มหยุดที่ปลายขวาของแถบแท็บ (แสดงเฉพาะตอนมีอะไรกำลังทำงาน), ถาดระบบ → **หยุดการทำงานที่กำลังรัน** หรือคีย์หยุดฉุกเฉินส่วนกลาง (ค่าเริ่มต้น `Ctrl+Alt+Q`) การรอนาน ๆ จะถูกตัดทันที ไม่ต้องรอจนจบ

## ความต้องการของระบบ

| หัวข้อ | รายละเอียด |
| --- | --- |
| **ระบบ** | Windows 10 / 11, x64 |
| **การติดตั้ง** | ไม่ต้อง มีไฟล์ `Clockwork.exe` แบบพกพาไฟล์เดียว — วางในโฟลเดอร์ใดก็ได้ |
| **สิทธิ์ผู้ดูแล** | ต้องใช้เฉพาะ «เริ่มเมื่อล็อกอิน» และขั้นตอนที่คุณกำกับว่า **รันในฐานะผู้ดูแลระบบ** |
| **การตั้งค่าของคุณ** | `clockwork.settings.json` ข้าง ๆ ไฟล์ exe (หรือ `%APPDATA%\Clockwork\` ถ้าในการเปิดครั้งแรกโฟลเดอร์นั้นอ่านได้อย่างเดียว จากนั้นจะอยู่ที่เดิมตลอด) — ไม่มีอะไรออกจากเครื่อง |
| **อินเทอร์เฟซ** | 18 ภาษาและธีมสว่าง / มืด ภาษาจะตาม Windows เมื่อเริ่มใช้ครั้งแรก ธีมเริ่มต้นเป็นมืดและตั้งให้ตาม Windows ได้ |

**ข้อจำกัด** ไม่มีตัวติดตั้งก็ย่อมไม่มีการอัปเดตอัตโนมัติ — ดาวน์โหลด zip ใหม่แล้วแทนที่ไฟล์ exe ตัวเปิดแบบแซนด์บ็อกซ์จะบล็อกการส่งคีย์ การสั่งงานเมาส์ การกระทำกับหน้าต่าง สลับไปหน้าต่างเดิมถ้ากำลังรันอยู่ และระดับเสียง (คุณจะได้รับการแจ้งที่ชัดเจน ส่วน «เปิดโปรแกรม» ธรรมดายังทำงานได้) การรีแมปคีย์และการขยายข้อความอยู่นอกขอบเขต — นั่นเป็นงานของ AutoHotkey

## เริ่มต้นใช้งาน

1. ดาวน์โหลดเวอร์ชันล่าสุดจาก [Releases](https://github.com/rockbenben/Clockwork/releases) — สองบิลด์ สามไฟล์ให้เลือกโหลด — แล้ววางไฟล์ `Clockwork.exe` ไฟล์เดียวที่ได้มาในโฟลเดอร์ใดก็ได้
   - **`Clockwork-<เวอร์ชัน>-win-x64.zip`** — รวม .NET runtime มาให้ รันได้ทันทีบนเครื่อง Windows 10/11 ทุกเครื่อง ถ้าไม่แน่ใจ หรือเครื่องออฟไลน์หรือถูกล็อกจนติดตั้งอะไรไม่ได้ ให้เลือกอันนี้
   - **`Clockwork-<เวอร์ชัน>-win-x64-needs-dotnet10.zip`** — ต้องติดตั้ง [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) ไว้ก่อน ติดตั้งครั้งเดียวบนเครื่องที่ต่อเน็ตได้ หลังจากนั้นอัปเดตแต่ละครั้งดาวน์โหลดเพียงเล็กน้อย
   - **`Clockwork.exe`** — บิลด์เดียวกับไฟล์ zip ด้านบน เพียงแต่ไม่ได้บีบอัด กดเปิดใช้ได้เลย หรือวางทับไฟล์เดิมเพื่ออัปเดต ถ้าไม่มี runtime Windows จะเสนอให้ดาวน์โหลดเอง
2. ดับเบิลคลิกเพื่อเปิดหน้าต่างการตั้งค่า ตัวอย่างที่โหลดมา **ยังไม่ถูกติ๊กไว้** ทั้งหมด — จึงไม่มีอะไรทำงานจนกว่าคุณจะติ๊กเอง
3. เพื่อให้รันทุกครั้งที่บูต: ที่แท็บ **การตั้งค่า** ติ๊ก **เริ่มเมื่อล็อกอิน** (ลงทะเบียนงานที่ตั้งเวลาไว้ด้วยสิทธิ์ผู้ดูแลระบบ จึงไม่มีหน้าต่าง UAC เด้งเป็นพรืดตอนบูต)

จากนั้นมันจะอยู่ใน System Tray: ดับเบิลคลิกไอคอนเพื่อเปิดหน้าต่าง ส่วนปุ่มปิดของหน้าต่างเพียงซ่อนมันอีกครั้ง หากต้องการปิดจริง ๆ ให้คลิกขวาที่ Tray แล้วเลือก **ออก**

> [!IMPORTANT]
> **ไฟล์ exe ไม่ได้เซ็นรับรองโค้ด** SmartScreen จึงขึ้นว่า «Windows protected your PC» ในการเปิดครั้งแรก — คลิก **More info → Run anyway** โปรแกรมแอนตี้ไวรัสก็อาจแจ้งเตือนได้ เพราะการเขียนคีย์ Run ในรีจิสทรีและงานตามกำหนดเวลา คือสิ่งที่ตัวจัดการโปรแกรมเริ่มต้นต้องทำ และก็เป็นสิ่งที่มัลแวร์มักทำเช่นกัน จากภายนอกแยกไม่ออก ถ้าไม่อยากยอมรับด้วยความเชื่อใจ ให้ [คอมไพล์เอง](../../CONTRIBUTING.md) ผลลัพธ์เหมือนกัน และไบนารีเป็นของคุณเอง ทุกรีลีสยังมาพร้อมไฟล์ `SHA256SUMS.txt` และหลักฐานการบิลด์จาก GitHub: คำสั่ง `gh attestation verify <ไฟล์> -R rockbenben/Clockwork` พิสูจน์ได้ว่าไฟล์ที่ดาวน์โหลดถูกบิลด์โดย CI ของรีโพนี้ ไม่ใช่บนแล็ปท็อปของใคร

## เคล็ดลับ

- **ดับเบิลคลิกที่แถวเพื่อแก้ไข** พาธ โปรเซส และวันที่ไม่ต้องพิมพ์เอง: **ปุ่ม … ท้ายแถว** จะเปิดตัวเลือกที่ตรงกัน (ไฟล์ รายการโปรเซสที่ค้นหาได้ วันที่) ส่วนคีย์ลัดกด **จับปุ่ม** แล้วกดจริงเพื่อบันทึก
- **ลากแถวเพื่อจัดลำดับใหม่** — ใช้ได้ทั้งสามรายการ และรายการขั้นตอนในตัวแก้ไขกลุ่ม โดยปุ่มขึ้น / ลงยังใช้ได้เหมือนเดิม
- **ลองรันก่อนบันทึก** — **▶ รันขั้นนี้** และ **▶ รันทั้งกลุ่ม** ในตัวแก้ไขกลุ่มรันสิ่งที่อยู่บนหน้าจอตอนนี้ และระหว่างรันปุ่มจะเปลี่ยนเป็น **■ หยุด**
- **ทำสำเนา** จะโคลนงานหรือกลุ่มที่เลือกไว้ไว้ใต้แถวนั้นทันที — เร็วกว่าการสร้างรายการที่เกือบเหมือนกันขึ้นใหม่ **การลบจะถามยืนยันก่อนเสมอ** ในทุกที่
- การดับเบิลคลิก `Clockwork.exe` เพียงเปิดหน้าต่างเท่านั้น มัน **ไม่** รันรายการเริ่มต้นซ้ำ ให้ใช้ **รันรายการเริ่มต้นอีกครั้ง** จาก Tray แทน
