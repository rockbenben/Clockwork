> Windows のトレイツール：スタートアップランチャー · リマインダー · システムのスタートアップ項目 · アクショングループ

![Clockwork](../../assets/social-card.png)

一日のはじめに PC でおこなう決まりきった作業を引き受けてくれる、小さな Windows トレイツールです：

- 🚀 **スタートアップリスト** — ログイン時に毎日使うアプリを順番に自動で開き（ステップごとに管理者権限、遅延、特定の曜日のみ / N 時より前のみ、ウィンドウスタイル、実行中なら前面化、フォールバックパスを設定可能）、ついでにちょっとした雑務もこなします（ウィンドウを閉じる・フォーカスする、キー入力 / テキストを送る、音量を設定する…）。
- ⏰ **定時タスク** — 時間どおりにリマインダーをポップアップ；読み上げ；曜日 / N 日ごと / 毎月で繰り返し；または「ログイン時」に発火。**はい** をクリックすると、プログラムの実行、ファイル（音楽など）や URL を開く、アクショングループの実行ができます。間隔実行（繰り返し）と一回限りの実行にも対応しています。
- 🧹 **システムのスタートアップ項目** — **PC で自動起動するすべての項目**を一覧表示し、不要なものをオフに（削除ではなく無効化——いつでも戻せます）。ワンクリックで項目を「引き取り」、自分のスタートアップリストに取り込めます。
- 🎛️ **アクショングループ** — 一連のアクションを再利用可能なグループにまとめ（集中 / 会議 / 締め / 就寝…）、トレイ・**グローバルホットキー**・スタートアップリスト・リマインダーからワンクリックで発火。組み込みテンプレートも用意。

インストール不要、完全ポータブルな単一フォルダ、すべてマウスで設定可能；ダーク UI、高 DPI 対応。

> 📖 **詳しい使い方：** [English](../USAGE.md) · [中文](../USAGE.zh.md)

## 動作要件

- Windows 10 / 11（x64）
- インストール不要：.NET ランタイムを同梱した自己完結型の単一ファイル `Clockwork.exe`。

## はじめに

1. [Releases](https://github.com/rockbenben/Clockwork/releases) から最新の `Clockwork-<バージョン>.zip` をダウンロードして展開すると、中に単一の `Clockwork.exe` が入っています；それを任意のフォルダに置きます（ポータブル——どこに置いても OK）。自分でビルドする場合は下の **開発者向け** を参照。
2. **`Clockwork.exe`** をダブルクリックして設定ウィンドウを開きます。
   - **初回起動**では、スタートアップ一覧とリマインダーにいくつかの **サンプル** が読み込まれるので、自分用に手直しできます——いずれも最初はチェックが外れているので、自分でチェックを入れるまで何も実行されません。**アクショングループ** タブにも、すぐ使える 2 つのグループ（少し離席 / 終業・退勤）が最初から入っています——こちらは*チェック済み*です。グループは自分から発火することはなく、トリガーしたときだけ実行されるためです。設定は exe と同じ場所の `clockwork.settings.json` に保存されます——ローカル限定で、コミットされることはありません。
3. 毎回の起動時に実行するには：**設定** タブで **ログイン時に起動** をクリック（管理者権限でスケジュールされたタスクを登録するので、起動時に UAC の確認が大量に出ることはありません）。

> 静かにトレイに常駐します。トレイアイコンをダブルクリックするとウィンドウが開きます；ウィンドウの閉じるボタンはトレイに隠すだけです。完全に終了するには、トレイの右クリック **終了** から。

> **初回起動時に警告が出ますが、正常です。** この exe はコード署名されていないため、SmartScreen が「Windows によって PC が保護されました」と表示します —— 「詳細情報」→「実行」をクリックしてください。ウイルス対策ソフトが反応することもあります。レジストリの Run キーやタスクスケジューラーへの書き込みは、スタートアップ管理ツールの本来の仕事であると同時に、マルウェアがよくやることでもあり、外から見分ける手立てがないからです。信用だけで受け入れたくない場合は、下の**開発者向けビルド**の手順でご自身でビルドしてください。結果は同じで、バイナリはあなたのものです。

## 5 つのタブ

5 つのタブ。各項目の詳細は[完全ガイド](../USAGE.md)にあります。

- **スタートアップリスト** — ログイン時に上から順に実行。種類：プログラムを起動 · キーを送信 · テキストを送信 · 音量 · ウィンドウ操作 · システムコマンド · アクショングループ · 遅延 · メッセージ。各ステップにステップ後の遅延、繰り返し回数、曜日 / N 時前の条件を設定でき、プログラムはさらに管理者権限・ウィンドウスタイル・実行中なら前面化・フォールバックパスを指定できます。
- **定時タスク** — 時刻（または「ログイン時」）× 繰り返し（曜日 / N 日ごと / 毎月 / 一回限り）× アクション 1 つ：リマインダー（スヌーズ付きのはい / いいえダイアログ、または隅のカード、読み上げも可）か、サイレント実行のアクショングループ。ほかに間隔実行、繰り返し催促、逃した発火の追いつき、トレイからの応答不可（DND）。
- **システムのスタートアップ項目** — PC で自動起動するものをすべて一覧（レジストリの Run キー、スタートアップフォルダ、スケジュールされたタスク）：オフにする（削除ではなく無効化）、自分のスタートアップリストに取り込む、完全に削除する。
- **アクショングループ** — 一連のアクションを再利用可能な形にまとめ、トレイ・**グローバルホットキー**（もう一度押すとその実行を中止）・スタートアップリストのステップ・定時タスクから発火できます。グループ全体の繰り返しや他グループの参照（循環参照は保存時に拒否）も可能で、**メッセージ**ステップははい / いいえで以降の実行を止められます。
- **設定** — 起動遅延（0〜600 秒、起動時のみ）、起動時にトレイに最小化、ログイン時に起動、緊急停止ホットキー、UI 言語（18 種）、設定のエクスポート / インポート。

> **いつでも停止** — タブバー右端の**停止ボタン**（実行中のみ表示）、トレイ → **実行中のアクションを停止**、またはグローバルな**緊急停止ホットキー**（既定 `Ctrl+Alt+Q`）。起動遅延やウィンドウ待ちなどの長い待機はただちに中断されます。

## ヒント

- **行をダブルクリックして編集**。パス / プロセス / ショートカット / 日付を入力するとき、手打ちする必要はありません：**参照…**、**選択…**（検索可能なプロセスピッカー）、**キャプチャ**、**日付を選択** があります。
- **行をドラッグして並べ替え** — スタートアップリスト / 定時タスク / アクショングループの 3 つの一覧と、グループエディタのステップ一覧で使えます（上下ボタンも従来どおり）。
- **保存する前に試す** — グループエディタには **▶ このステップを実行** と **▶ グループ実行** があり、どちらも画面上の現在の内容を実行します。実行中はボタンが **■ 停止** に変わり、エディタを閉じても停止します。
- **複製**（定時タスク / アクショングループのタブ）は選択中の行をそのすぐ下に複製します——よく似た設定をもう一度作り直すより速く、複製したグループの名前は「…（コピー）」になります。
- **削除は必ず先に確認します**——リストの行、グループエディタ内のステップ、システムのスタートアップ項目、どこでも同じです。
- `Clockwork.exe` のダブルクリックは設定を開くだけで、スタートアップリストをすぐに実行**しません**；実行するにはトレイの **スタートアップリストを再実行** を使ってください。
- **通常どおり起動してください**（ダブルクリック / トレイ / スケジュールされたタスク）。一部のサンドボックス / 権限を落としたランチャーは低レベル呼び出しをブロックするため、キー送信 / ウィンドウ操作 / 実行中なら前面化 / プロセスへのテキスト送信 / 音量が動作しないことがあります（明確な通知が出ます；単純な「プログラムを起動」は影響を受けません）。
- 設定は `clockwork.settings.json`（ローカル限定）。削除するとサンプルにリセットされます。タスクの状態は `clockwork.state.json`（これもローカル；削除しても安全）。
- `.ahk` ステップの追加には AutoHotkey のインストールが必要です。グローバルホットキー / テキスト展開は対象外です——それは AutoHotkey の得意分野です。

## 開発者向け

C#/.NET WPF；ソースは `app/`（.NET 10 SDK が必要）。レイヤー：`Core/` 純粋ロジック · `Native/` Win32 インターオペ · `Engine/` 実行 · `ViewModels/` + `Views/` UI · `I18n/` + `Resources/` ローカライズ（ニュートラル = 中国語ソース、言語ごとに 1 つの `Strings.<code>.resx` サテライト）。

- テストを実行（xUnit）：
  ```powershell
  dotnet test app.Tests/Clockwork.Tests.csproj
  ```
- 自己完結型の単一ファイル exe をビルド（単一ファイル / 自己完結 / 圧縮は csproj で設定済み）：
  ```powershell
  dotnet publish app/Clockwork.csproj -c Release -r win-x64
  ```
  出力：`app/bin/Release/net10.0-windows/win-x64/publish/Clockwork.exe`。
- **CI / リリース**（GitHub Actions）：push / PR で Windows ランナー上でビルドし、すべてのテストを実行；`v*` タグ（例：`v2.0.0`）を push すると、ビルドし、タグからファイルバージョンを刻印し、GitHub Release を作成して `Clockwork-<タグ>.zip`（`Clockwork.exe` を同梱）を添付します。
