## できること

- 🚀 **スタートアップリスト** — ログイン時に毎日使うアプリを順番に開きます。ステップごとに遅延・曜日条件・ウィンドウスタイルを設定でき、ついでに閉じる・前面化・ミュートもこなします。 条件は時計だけではありません。「あるアプリが動いている / いない」「電源接続中のみ / バッテリー駆動中のみ」「あるファイルやフォルダーが存在するとき」でも絞れます。
- ⏰ **定時タスク** — 時間どおりのリマインダー（読み上げも可）、またはサイレント実行のアクショングループ。**はい** をクリックすると、プログラムの実行、ファイルや URL を開く、グループの発火ができます。 時計ではなくイベントで実行することもできます — ロック解除時、ロック時、スリープ復帰時、N 分間操作がないとき、電源の抜き差し時、バッテリー残量が少ないとき。 一度きりで十分なときは、トレイの**クイックリマインダー**を。5〜60 分、一度鳴ったら自動で消えます。
- 🧹 **システムのスタートアップ項目** — PC で自動起動するものをすべて一覧に：不要なものをオフに（削除ではなく無効化）、または自分のスタートアップリストに引き取り。
- 🎛️ **アクショングループ** — 一連の手順をまとめ（集中 / 会議 / 締め / 就寝…）、トレイ・**グローバルホットキー**・スタートアップリスト・定時タスクから発火。テンプレート付き。

> **いつでも停止** — タブバー右端の停止ボタン（実行中のみ表示）、トレイ → **実行中のアクションを停止**、またはグローバルな緊急停止ホットキー（既定 `Ctrl+Alt+Q`）。長い待機は待たされずに打ち切られます。

## 動作要件

| 項目 | 内容 |
| --- | --- |
| **システム** | Windows 10 / 11、x64 |
| **インストール** | 不要。ポータブルな `Clockwork.exe` 一つを任意のフォルダに置くだけ |
| **管理者権限** | 「ログイン時に起動」と、**管理者として実行**を指定したステップにのみ必要 |
| **設定の保存先** | exe と同じ場所の `clockwork.settings.json`（書き込めない場合は `%APPDATA%\Clockwork\`）— 端末の外には出ません |
| **表示言語** | 18 言語、初回は Windows の表示言語に追従 |

**制限。** インストーラーがない以上、自動更新もありません — 新しい zip をダウンロードして exe を差し替えてください。サンドボックス系のランチャーはキー送信 / ウィンドウ操作 / 実行中なら前面化 / 音量をブロックします（明確な通知が出ます。単純な「プログラムを起動」は影響を受けません）。キーの再割り当てとテキスト展開は対象外です — それは AutoHotkey の得意分野です。

## はじめに

1. [Releases](https://github.com/rockbenben/Clockwork/releases) から最新版をダウンロードし（ビルドは 2 種類、ダウンロードは 3 つ）、最終的に手元に残る単一の `Clockwork.exe` を任意のフォルダに置きます。
   - **`Clockwork-<バージョン>-win-x64.zip`**—— .NET ランタイム内蔵。Windows 10/11 ならどのマシンでもそのまま動きます。迷ったとき、またはオフラインや何も入れられない PC ではこちら。
   - **`Clockwork-<バージョン>-win-x64-needs-dotnet10.zip`**—— [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0) が必要。ネットにつながる PC で一度入れておけば、以降の更新はごく小さなダウンロードで済みます。
   - **`Clockwork.exe`**—— 上の zip と同じビルドを、zip に包まずそのまま置いたもの。クリックすれば動き、既存のファイルに上書きすれば更新も済みます。ランタイムが無ければ Windows がダウンロードを案内します。
2. ダブルクリックして設定ウィンドウを開きます。読み込まれるサンプルはすべて**チェックが外れた状態**です — 自分でチェックを入れるまで何も実行されません。
3. 毎回の起動時に実行するには：**設定** タブで **ログイン時に起動** にチェック（管理者権限でタスクを登録するので、起動時に UAC の確認が大量に出ることはありません）。

あとは静かにトレイに常駐します。アイコンをダブルクリックするとウィンドウが開き、ウィンドウの閉じるボタンは隠すだけです。完全に終了するにはトレイの右クリック **終了** から。

> [!IMPORTANT]
> **この exe はコード署名されていない**ため、初回起動時に SmartScreen が「Windows によって PC が保護されました」と表示します — 「詳細情報」→「実行」をクリックしてください。ウイルス対策ソフトが反応することもあります。レジストリの Run キーやタスクスケジューラーへの書き込みは、スタートアップ管理ツールの本来の仕事であると同時にマルウェアがよくやることでもあり、外から見分ける手立てがないからです。信用だけで受け入れたくない場合は、[ご自身でビルド](../../CONTRIBUTING.md)してください — 結果は同じで、バイナリはあなたのものです。 各リリースには `SHA256SUMS.txt` と GitHub のビルド来歴証明も付属します。`gh attestation verify <ファイル> -R rockbenben/Clockwork` で、ダウンロードした物が誰かのノート PC ではなく本リポジトリの CI でビルドされたことを検証できます。

## ヒント

- **行をダブルクリックして編集**。パス / プロセス / 日付は手入力不要です：**行末の … ボタン**がそれぞれの選択画面（ファイル、検索できるプロセス一覧、日付）を開き、ショートカットは **キャプチャ** で実際に押して記録します。
- **行をドラッグして並べ替え** — 3 つの一覧すべてと、グループエディタのステップ一覧で使えます（上下ボタンも従来どおり）。
- **保存する前に試す** — グループエディタの **▶ このステップを実行** と **▶ グループ実行** は画面上の現在の内容を実行し、実行中はボタンが **■ 停止** に変わります。
- **複製** は選択中のタスクやグループをそのすぐ下に複製します — よく似たものを作り直すより速い方法です。**削除は必ず先に確認**、どこでも同じです。
- `Clockwork.exe` のダブルクリックはウィンドウを開くだけで、スタートアップリストを再実行**しません**。実行するにはトレイの **スタートアップリストを再実行** を使ってください。
