## できること

- 🚀 **スタートアップリスト** — ログイン時に毎日使うアプリを順番に開きます。ステップごとに遅延・曜日条件・ウィンドウスタイルを設定でき、ついでに閉じる・前面化・ミュートもこなします。 条件は時計だけではありません。「あるアプリが動いている / いない」「電源接続中のみ / バッテリー駆動中のみ」「あるファイルやフォルダーが存在するとき」でも絞れます。
- ⏰ **定時タスク** — 時間どおりのリマインダー（読み上げも可）、またはサイレント実行のアクショングループ。**はい** をクリックすると、プログラムの実行、ファイルや URL を開く、グループの発火ができます。 時計ではなくイベントで実行することもできます — ロック解除時、ロック時、スリープ復帰時、N 分間操作がないとき、電源の抜き差し時、バッテリー残量が少ないとき。 一度きりで十分なときは、トレイの**クイックリマインダー**を。5〜60 分、一度鳴ったら自動で消えます。 ハードウェアを見るトリガーも増えました——ディスプレイの変化、ネットワークの復帰や切断、USB ドライブの接続——そしてあなた自身を見るものが一つ、N 分続けて作業したら「立ち上がろう」と声をかけます。
- 🎛️ **アクショングループ** — 一連の手順をまとめ（集中 / 会議 / 締め / 就寝…）、トレイ・**グローバルホットキー**・スタートアップリスト・定時タスクから発火。テンプレート付き。ステップ間で値を渡せます：**ユーザー入力 / ユーザー選択 / 選択中のテキストを取得**はそれぞれ変数に保存され、後続のステップが URL や文章の中で `{名前}` として参照します——「何を検索するか聞いてから検索する」は 2 ステップで書けます。
- 🧹 **システムのスタートアップ項目** — PC で自動起動するものをすべて一覧に：不要なものをオフに（削除ではなく無効化）、または自分のスタートアップリストに引き取り。
- 🔌 **ポート** — 待ち受け中の TCP ポートを、占有しているプロセスと、どのプロジェクトのものかと並べて一覧に。行をダブルクリックすればブラウザーで `localhost:3000` が開き、右クリックでポートを解放できます（占有しているプロセスをすべて、子プロセスごと終了）。既定ではあなた自身のプロジェクトディレクトリから起動したサービスだけが並ぶので、閉じ忘れた dev server がチャットアプリやシステムサービスに埋もれません。
- ⚡ **クイックパネル** —— ホットキー 1 つ（既定 `Ctrl+Alt+Space`）で、マウスのある場所にタイルの一覧が出ます。あなた自身の動作が並び、それに起動リストの再実行・停止・通知の一時停止・ウィンドウを開くが並びます。クリックでも、方向キーで選んで Enter でも実行できます。**Esc** か別の場所をクリックで閉じます。トレイメニューにも入口があるので、ホットキーを空にしても消えるのはショートカットだけで、機能自体は残ります。 マウス派なら**中ボタン長押し**を有効にすれば、キーボードなしで開けます。通常の中クリックはそのまま使えます。 パネルのページはパネルマネージャーで自分で作り、自分で並べ替えるものです。ページ上の 1 タイルが 1 つの操作なので、画面ロック・ミュート・アプリ起動・URL を開く、そして「アクショングループを丸ごと実行」までが同じページに並びます。 ページが増えたら分類しましょう：**上の行でカテゴリーを選び、左の行がそのカテゴリーのページを並べます**。どちらの行もドラッグで並べ替えられます。何も分類しなければすべて「未分類」に入り、カテゴリーの行はそもそも現れません。　まったく使わないなら、**設定 → クイックパネルを使う**で機能自体をオフにできます（ホットキーと中ボタンをまとめて）。
- 🖱️ **マウスジェスチャー** —— **右ボタン**を押したまま軌跡を描くと、対応する動作を実行します。8 方向、動作はどのステップ種別でも可（動作グループの実行も含む）。描いている間、その軌跡が画面に表示され、離すと消えます。**インストール直後から 10 個入っています**（コピー / 貼り付け / 戻る / 進む / 選択したテキストを検索（↑↓）/ 最下部へ、四つの斜め方向はウィンドウの最小化・最大化・最前面切り替え・閉じる）。そのまま使っても、書き換えても構いません。 代償を先に書いておきます：有効なジェスチャーが 1 つでもあれば右ボタンは横取りされるので、**右ドラッグは一拍おいてから** —— 押したまま 0.2 秒ほど静止させると右ボタンが返ってきます（エクスプローラーでファイルを右ドラッグする、3D アプリで視点を回す、といった操作はこの手順で）。右ボタンにいっさい触れてほしくないときのために、ジェスチャーマネージャーのタイトル行にマスタースイッチがあります。 内蔵のものを使わなくても構いません：そのスイッチを切って WGestures / StrokesPlus / Quicker に描画を任せ、動作のほうは `Clockwork.exe --run-group "集中"` で呼び出せます。　このスイッチは**設定**タブにもあります（**マウスジェスチャーを使う**）。

> **いつでも停止** — タブバー右端の停止ボタン（実行中のみ表示）、トレイ → **実行中のアクションを停止**、またはグローバルな緊急停止ホットキー（既定 `Ctrl+Alt+Q`）。長い待機は待たされずに打ち切られます。

## 動作要件

| 項目 | 内容 |
| --- | --- |
| **システム** | Windows 10 / 11、x64 |
| **インストール** | 不要。ポータブルな `Clockwork.exe` 一つを任意のフォルダに置くだけ |
| **管理者権限** | 「ログイン時に起動」と、**管理者として実行**を指定したステップにのみ必要 |
| **設定の保存先** | exe と同じ場所の `clockwork.settings.json`（初回起動時に書き込めなければ `%APPDATA%\Clockwork\`。以後はその場所を使い続けます）— 端末の外には出ません |
| **インターフェース** | 18 言語 + ダーク / ライトテーマ。言語は初回起動時に Windows に追従し、テーマは既定でダーク（Windows に追従させる設定も可） |

**制限。** インストーラーがない以上、自動更新もありません — 新しい zip をダウンロードして exe を差し替えてください。サンドボックス系のランチャーはキー送信 / マウス操作 / ウィンドウ操作 / 実行中なら前面化 / 音量をブロックします（明確な通知が出ます。単純な「プログラムを起動」は影響を受けません）。キーの再割り当てとテキスト展開は対象外です — それは AutoHotkey の得意分野です。

## はじめに

1. [Releases](https://github.com/rockbenben/Clockwork/releases) から最新版をダウンロードし（ビルドは 2 種類、ダウンロードは 3 つ）、最終的に手元に残る単一の `Clockwork.exe` を任意のフォルダに置きます。
   - **`Clockwork-<バージョン>-win-x64.zip`**—— .NET ランタイム内蔵。Windows 10/11 ならどのマシンでもそのまま動きます。迷ったとき、またはオフラインや何も入れられない PC ではこちら。
   - **`Clockwork-<バージョン>-win-x64-needs-dotnet10.zip`**—— [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0) が必要。ネットにつながる PC で一度入れておけば、以降の更新はごく小さなダウンロードで済みます。
   - **`Clockwork.exe`**—— 上の zip と同じビルドを、zip に包まずそのまま置いたもの。クリックすれば動き、既存のファイルに上書きすれば更新も済みます。ランタイムが無ければ Windows がダウンロードを案内します。
2. ダブルクリックして設定ウィンドウを開きます。読み込まれるサンプルはすべて**チェックが外れた状態**です — 自分でチェックを入れるまで何も実行されません。
3. 毎回の起動時に実行するには：**設定** タブで **ログイン時に起動** にチェック（管理者権限でタスクを登録するので、起動時に UAC の確認が大量に出ることはありません）。

あとは静かにトレイに常駐します。アイコンをダブルクリックするとウィンドウが開き、ウィンドウの閉じるボタンは隠すだけです。完全に終了するにはトレイの右クリック **終了** から。

> [!IMPORTANT]
> **この exe はコード署名されていない**ため、初回起動時に SmartScreen が「Windows によって PC が保護されました」と表示します — 「詳細情報」→「実行」をクリックしてください。ウイルス対策ソフトが反応することもあります。レジストリの Run キーやタスクスケジューラーへの書き込みは、スタートアップ管理ツールの本来の仕事であると同時にマルウェアがよくやることでもあり、外から見分ける手立てがないからです。信用だけで受け入れたくない場合は、[ご自身でビルド](../../CONTRIBUTING.md)してください — 結果は同じで、バイナリはあなたのものです。 各リリースには `SHA256SUMS.txt` と GitHub のビルド来歴証明も付属します。`gh attestation verify <ファイル> -R rockbenben/Clockwork` で、ダウンロードした物が誰かのノート PC ではなく本リポジトリの CI でビルドされたことを検証できます。

## ヒント

- **行をダブルクリックして編集**。パス / プロセス / 日付は手入力不要です：**行末の … ボタン**がそれぞれの選択画面（ファイル、検索できるプロセス一覧、日付）を開き、ショートカットは **キャプチャ** で実際に押して記録します。
- **行をドラッグして並べ替え** — 3 つの一覧すべてと、グループエディタのステップ一覧で使えます（上下ボタンも従来どおり）。
- **保存する前に試す** — グループエディタの **▶ このステップを実行** と **▶ グループ実行** は画面上の現在の内容を実行し、実行中はボタンが **■ 停止** に変わります。
- **複製** は選択中のタスクやグループをそのすぐ下に複製します — よく似たものを作り直すより速い方法です。**削除は必ず先に確認**、どこでも同じです。
- `Clockwork.exe` のダブルクリックはウィンドウを開くだけで、スタートアップリストを再実行**しません**。実行するにはトレイの **スタートアップリストを再実行** を使ってください。
