## 它能做什麼

- 🚀 **啟動清單** —— 登入時依序開啟你每天要用的應用程式，每步可設延遲、星期條件與視窗樣式；順手還能關閉、聚焦或靜音。 條件不只看時鐘：還能限定「某程式在跑 / 沒跑」「僅接電源 / 僅用電池」「某個檔案或資料夾存在時」。
- ⏰ **定時任務** —— 準時彈出提醒（想要的話還能朗讀），或靜默執行一個動作群組。點 **是** 可以執行程式、開啟檔案或網址，或觸發一個群組。 也可以不看時鐘、改由事件觸發 —— 解鎖時、鎖定時、睡眠喚醒時、閒置 N 分鐘後、插拔電源時、電量偏低時。 只想臨時定一個？托盤裡有**快速提醒** —— 5 到 60 分鐘，響一次就自己刪掉。 還有幾種觸發看的是硬體——插拔顯示器、網路接通或斷開、USB 隨身碟插入——以及一種看的是你：連續用滿 N 分鐘就提醒你起來活動一下。
- 🎛️ **動作群組** —— 把一套流程打包（專注 / 會議 / 收尾 / 就寢……），從系統匣、**全域熱鍵**、啟動清單或定時任務觸發。內建範本可用。步驟之間能傳值：**使用者輸入 / 使用者選擇 / 取得選取的文字**各產出一個變數，後面的步驟在網址或文字裡寫 `{名稱}` 引用它——「問我要搜什麼，再去搜」就是兩步。
- 🧹 **系統開機自啟項** —— 電腦上所有會自動啟動的項目集中成一張清單：把不需要的關掉（是停用，不是刪除），或接管進你自己的啟動清單。
- 🔌 **連接埠** —— 正在被監聽的 TCP 連接埠，連同佔用它的處理程序和它來自哪個專案：按兩下一列用瀏覽器開啟 `localhost:3000`，按右鍵釋放連接埠（結束佔著它的全部處理程序，含子處理程序）。預設只顯示從你自己專案目錄跑起來的服務，那個忘了關的 dev server 不會被聊天軟體和系統服務埋掉。
- ⚡ **快捷面板** —— 一個熱鍵（預設 `Ctrl+Alt+Space`）在滑鼠已經在的地方彈出磚塊網格：你自己的動作，再加重跑清單、停止、免打擾、開啟視窗。點一格，或方向鍵選中後按 Enter；**Esc** 或點到別處即消失。系統匣選單裡也有入口，所以清空熱鍵關掉的是快捷鍵，不是這個功能。 更喜歡用滑鼠？把**長按中鍵**打開，完全不用鍵盤就能喚出它 —— 普通中鍵點擊照常可用。 面板的頁是你在面板管理員裡自己建、自己排的一樣東西，頁上每一格是一個操作 —— 於是單個動作（鎖屏、靜音、開啟某個軟體、開啟某個網址）和「跑一整個動作」可以並排擺在同一頁上。頁多了就分類：**頂列選分類、左列列出這一類的頁**，兩列都能拖著排序；不分類的話它們全在「未分類」裡，那條分類列根本不會出現。而**設定 → 使用快捷面板**關掉的是功能本身，熱鍵和中鍵一起停。
- 🖱️ **滑鼠手勢** —— 按住**右鍵**畫一條軌跡，放開即執行對應的動作。八個方向，動作可以是任意一種步驟（也包括執行一整個動作組）。畫的時候螢幕上跟著出一條線，放開即消失。**裝完就帶 10 條常用的**（複製 / 貼上 / 上一頁 / 下一頁 / 搜尋選取的文字（↑↓）/ 到最底部，四個斜角是視窗的最小化·最大化·切換置頂·關閉），可直接用，也可以照著改。代價說在前面：只要有一條啟用的手勢，右鍵就被接管，**右鍵拖曳要先停一下再拖**（按住不動約 0.2 秒，右鍵就還給系統；檔案總管裡右鍵拖檔案、3D 軟體裡右鍵旋轉都照這個來）——手勢管理員標題列上有總開關，要讓右鍵完全不被碰時翻一下即可。不想用內建的也行：關掉總開關，讓 WGestures / StrokesPlus / Quicker 去畫，動作那半仍走 `Clockwork.exe --run-group "專注"`。**設定**頁也有一個總開關（**使用滑鼠手勢**）。

> **隨時叫停** —— 標籤列右端的停止按鈕（只在有東西執行時出現）、系統匣 →**停止正在執行的動作**，或全域緊急停止熱鍵（預設 `Ctrl+Alt+Q`）。漫長的等待會被當場切斷，不必等它跑完。

## 系統需求

| 項目 | 內容 |
| --- | --- |
| **系統** | Windows 10 / 11，x64 |
| **安裝** | 不需要。單一的可攜式 `Clockwork.exe`——丟進任何資料夾即可 |
| **管理員權限** | 只有「登入時啟動」和你標記為**以系統管理員身分執行**的步驟才需要 |
| **你的設定** | exe 旁的 `clockwork.settings.json`（首次執行時該資料夾不可寫則落到 `%APPDATA%\Clockwork\`，此後一直認這一份）——不會離開這台電腦 |
| **介面** | 18 種語言 + 深色 / 淺色主題。語言首次執行跟隨 Windows；主題預設深色，也可設為跟隨 Windows |

**已知限制。** 免安裝也意味著沒有自動更新——請下載新的 zip 覆蓋 exe。沙箱 / 降權啟動器會擋住傳送按鍵、滑鼠動作、視窗動作、已在執行則啟動與音量（會給明確提示，單純「啟動程式」不受影響）。按鍵重新對應與文字展開不在本工具範圍內——那是 AutoHotkey 的強項。

## 開始使用

1. 從 [Releases](https://github.com/rockbenben/Clockwork/releases) 下載最新版本——兩種構建、三個下載——最後你手上都是單一的 `Clockwork.exe`，丟進任何資料夾。
   - **`Clockwork-<版本號>-win-x64.zip`**—— 內含 .NET 執行環境，哪台 Windows 10/11 拿到都能直接跑。拿不準、或電腦在內網裝不了東西，就選它。
   - **`Clockwork-<版本號>-win-x64-needs-dotnet10.zip`**—— 需要已安裝 [.NET 10 桌面執行環境](https://dotnet.microsoft.com/download/dotnet/10.0)。能連網的電腦裝一次，之後每次更新都只下載一個很小的包。
   - **`Clockwork.exe`**—— 就是上面那個不含執行環境的版本，只是沒套 zip：點開即用，也可以直接蓋掉現有的那份完成更新。缺執行環境時 Windows 會自己提示下載。
2. 雙擊它開啟設定視窗。載入的範例**全都沒有勾選**——你不勾，就什麼都不會執行。
3. 想每次開機都執行：到 **設定** 分頁勾選 **登入時啟動**（會以系統管理員權限註冊排程工作，開機時不會冒出一堆 UAC 提示）。

之後它就待在系統匣：雙擊圖示開啟視窗，而視窗的關閉按鈕只是把它收回去。要真正結束，用系統匣右鍵的 **結束**。

> [!IMPORTANT]
> **這個 exe 沒有程式碼簽章**，所以首次執行時 SmartScreen 會顯示「已保護您的電腦」——點「其他資訊」→「仍要執行」。部分防毒軟體也可能報警，因為寫登錄檔 Run 機碼與排程工作，既是啟動管理器該做的事，也是惡意程式會做的事，從外部無從分辨。不想憑信任接受的話，[自己編譯一份](../../CONTRIBUTING.md)——結果一樣，執行檔是你自己的。 每個 Release 也附帶 `SHA256SUMS.txt` 與 GitHub 建置來源證明：`gh attestation verify <檔案> -R rockbenben/Clockwork` 可驗證下載的檔案確實出自本倉庫的 CI，而不是誰的筆電。

## 小技巧

- **雙擊某一列即可編輯**。路徑、行程、日期都不用硬記：**列尾的 … 按鈕**會打開對應的選擇器（檔案、可搜尋的行程清單、日期），快速鍵點 **「擷取」** 按一下即錄。
- **拖曳某一列即可調整順序** —— 三個清單與群組編輯器的步驟清單都支援；上移 / 下移按鈕照樣能用。
- **儲存前先試跑一遍** —— 群組編輯器的 **▶ 執行這一步** 與 **▶ 執行整組** 跑的都是畫面上此刻的內容，執行期間按鈕會變成 **■ 停止**。
- **複製** 會把選取的任務或群組複製到它正下方——比從頭重建一個幾乎一樣的快多了。**刪除一律會先詢問**，處處如此。
- 雙擊 `Clockwork.exe` 只會開啟視窗，**不會**重新執行啟動清單；要執行請用系統匣的 **重新執行啟動清單**。
