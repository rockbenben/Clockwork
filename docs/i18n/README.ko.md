## 무엇을 하나

- 🚀 **시작 목록** — 로그인 시 매일 쓰는 앱을 순서대로 엽니다. 단계마다 지연·요일 조건·창 스타일을 줄 수 있고, 지나는 김에 닫기·포커스·음소거도 처리합니다. 조건은 시계만 보지 않습니다. 특정 앱이 실행 중일 때(또는 아닐 때), 전원 연결 시에만 또는 배터리 사용 시에만, 특정 파일이나 폴더가 있을 때로도 제한할 수 있습니다.
- ⏰ **예약 작업** — 정시 알림(원하면 소리 내어 읽어 줍니다), 또는 조용히 실행되는 액션 그룹. **예**를 클릭하면 프로그램 실행, 파일이나 URL 열기, 그룹 실행이 됩니다. 시계 대신 이벤트로 실행할 수도 있습니다 — 잠금 해제, 화면 잠금, 절전 모드에서 깨어날 때, N분간 유휴 상태일 때, 전원을 연결하거나 분리할 때, 배터리가 부족할 때. 한 번만 필요하다면 트레이의 **빠른 알림**을 쓰세요. 5~60분, 한 번 울리고 스스로 사라집니다. 하드웨어를 지켜보는 트리거도 늘었습니다 — 디스플레이 변경, 네트워크 복귀나 끊김, USB 드라이브 연결 — 그리고 당신을 지켜보는 것 하나, N 분 동안 쉬지 않고 일하면 일어나라고 알려 줍니다.
- 🎛️ **액션 그룹** — 루틴을 하나로 묶어(집중 / 회의 / 마무리 / 취침…) 트레이·**전역 단축키**·시작 목록·예약 작업에서 실행합니다. 템플릿 포함. 단계 사이로 값을 넘길 수 있습니다: **사용자 입력 / 사용자 선택 / 선택한 텍스트 가져오기**가 각각 변수에 저장되고, 뒤따르는 단계가 URL 이나 문장 안에서 `{이름}` 으로 그것을 참조합니다 — 「무엇을 검색할지 물어본 다음 검색하기」는 두 단계면 됩니다.
- 🧹 **시스템 시작 항목** — PC에서 자동으로 시작되는 모든 것을 한 목록에: 필요 없는 것을 끄거나(삭제가 아니라 비활성화) 내 시작 목록으로 인계받습니다.
- 🔌 **포트** — 수신 중인 TCP 포트를 점유한 프로세스 및 어느 프로젝트에서 왔는지와 함께 한곳에. 행을 두 번 클릭하면 브라우저에서 `localhost:3000`이 열리고, 마우스 오른쪽 버튼으로 포트를 비울 수 있습니다(그 포트를 점유한 모든 프로세스를 자식 프로세스까지 종료). 기본값은 내 프로젝트 디렉터리에서 시작된 서비스만 보여 주므로, 끄는 걸 잊은 dev server가 채팅 앱과 시스템 서비스 속에 묻히지 않습니다.
- ⚡ **빠른 패널** — 단축키 하나(기본 `Ctrl+Alt+Space`)로 마우스가 있는 자리에 타일 격자가 뜹니다. 당신의 동작들이, 여기에 시작 목록 다시 실행·중지·방해 금지·창 열기가 더해집니다. 타일을 클릭하거나 방향키로 고른 뒤 Enter 를 누르면 됩니다. **Esc** 를 누르거나 다른 곳을 클릭하면 닫힙니다. 트레이 메뉴에도 있으므로 단축키를 지워도 사라지는 건 단축키뿐입니다. 마우스가 편하다면 **가운데 버튼 길게 누르기**를 켜세요. 키보드 없이 열립니다 — 평소의 가운데 클릭은 그대로 동작합니다. 패널의 페이지는 패널 관리자에서 직접 만들고 직접 배열하는 것입니다. 페이지의 타일 하나가 작업 하나이므로 화면 잠금, 음소거, 앱 실행, URL 열기, 그리고 「동작 그룹 통째로 실행」까지 한 페이지에 나란히 놓입니다. 페이지가 많아지면 분류하세요: **윗줄에서 분류를 고르고, 왼쪽 줄이 그 분류의 페이지를 보여줍니다**. 두 줄 모두 끌어서 정렬할 수 있고, 아무것도 분류하지 않으면 전부 「분류 없음」에 들어가 분류 줄 자체가 나타나지 않습니다. 전혀 사용하지 않는다면 **설정 → 빠른 패널 사용**으로 기능 자신을 끔다—단축키와 가운데 버튼을 함께.
- 🖱️ **마우스 제스처** —— **오른쪽 버튼**을 누른 채 궤적을 그리면 해당 동작이 실행됩니다. 8방향, 어떤 단계 종류든 가능(동작 그룹 실행 포함). 그리는 동안 궤적이 화면에 표시되고, 버튼을 놓으면 사라집니다. **설치 직후부터 10 개가 들어 있습니다**(복사 / 붙여넣기 / 뒤로 / 앞으로 / 선택한 텍스트 검색(↑↓) / 맨 아래로, 네 대각선은 창의 최소화·최대화·항상 위 전환·닫기). 그대로 써도 되고 고쳐 써도 됩니다. 대가는 미리 밝혀 둡니다: 켜진 제스처가 하나라도 있으면 오른쪽 버튼을 가져가므로 **오른쪽 끌기는 잠깐 멈췄다가** 하세요 — 누른 채 0.2 초쯤 가만히 있으면 오른쪽 버튼이 시스템으로 돌아갑니다(탐색기에서 파일을 오른쪽 버튼으로 끌기, 3D 앱에서 시점 돌리기가 이 방식입니다). 오른쪽 버튼을 아예 건드리지 않길 원한다면 제스처 관리자 제목 줄의 마스터 스위치를 끄면 됩니다. 내장된 것을 꼭 쓸 필요도 없습니다: 그 스위치를 끄고 WGestures / StrokesPlus / Quicker 에 그리기를 맡긴 뒤, 동작 쪽은 `Clockwork.exe --run-group "집중"` 으로 부르면 됩니다. 이 스위치는 **설정** 탭에도 있다(**마우스 제스처 사용**).

> **언제든 정지** — 탭 바 오른쪽 끝의 정지 버튼(실행 중일 때만 보입니다), 트레이 → **실행 중인 동작 정지**, 또는 전역 긴급 정지 단축키(기본값 `Ctrl+Alt+Q`). 긴 대기는 기다리지 않고 즉시 끊깁니다.

## 요구 사항

| 항목 | 내용 |
| --- | --- |
| **시스템** | Windows 10 / 11, x64 |
| **설치** | 필요 없음. 휴대용 `Clockwork.exe` 하나를 아무 폴더에나 두세요 |
| **관리자 권한** | 「로그인 시 시작」과 **관리자로 실행**을 표시한 단계에만 필요 |
| **설정 저장 위치** | exe 옆의 `clockwork.settings.json`(첫 실행 때 쓸 수 없는 폴더라면 `%APPDATA%\Clockwork\`. 이후로는 처음 정해진 위치를 계속 사용합니다) — 기기 밖으로 나가지 않습니다 |
| **인터페이스** | 18개 언어 + 어두운 / 밝은 테마. 언어는 첫 실행 시 Windows를 따르고, 테마는 기본이 어두운 테마입니다(Windows를 따르도록 설정 가능) |

**한계.** 설치 관리자가 없으니 자동 업데이트도 없습니다 — 새 zip을 받아 exe를 교체하세요. 샌드박스 실행기는 키 전송·마우스 동작·창 동작·실행 중이면 활성화·볼륨을 차단합니다(명확한 안내가 표시되며, 단순한 「프로그램 실행」은 영향을 받지 않습니다). 키 재배치와 텍스트 확장은 범위 밖입니다 — 그것은 AutoHotkey의 몫입니다.

## 시작하기

1. [Releases](https://github.com/rockbenben/Clockwork/releases)에서 최신 버전을 내려받아(빌드는 두 가지, 내려받는 것은 세 가지) 최종적으로 손에 남는 단일 `Clockwork.exe`를 아무 폴더에나 두세요.
   - **`Clockwork-<버전>-win-x64.zip`** — .NET 런타임 포함. Windows 10/11이면 어느 PC에서나 그대로 실행됩니다. 잘 모르겠을 때, 오프라인이거나 아무것도 설치할 수 없는 PC라면 이것을 받으세요.
   - **`Clockwork-<버전>-win-x64-needs-dotnet10.zip`** — [.NET 10 데스크톱 런타임](https://dotnet.microsoft.com/download/dotnet/10.0)이 필요합니다. 인터넷이 되는 PC에 한 번만 설치해 두면, 이후 업데이트는 아주 작은 파일만 내려받습니다.
   - **`Clockwork.exe`** — 바로 위 zip과 같은 빌드를 압축 없이 그대로 올린 것입니다. 눌러서 실행하거나, 쓰던 파일에 덮어써서 업데이트하세요. 런타임이 없으면 Windows가 내려받기를 안내합니다.
2. 더블클릭해 설정 창을 엽니다. 함께 로드되는 샘플은 모두 **체크가 꺼진** 상태입니다 — 직접 체크하기 전에는 아무것도 실행되지 않습니다.
3. 부팅할 때마다 실행하려면: **설정** 탭에서 **로그인 시 시작**을 체크하세요(관리자 권한으로 예약 작업을 등록하므로 부팅 시 UAC 프롬프트가 잔뜩 뜨지 않습니다).

그다음에는 트레이에 머무릅니다. 아이콘을 더블클릭하면 창이 열리고, 창의 닫기 버튼은 다시 숨길 뿐입니다. 완전히 종료하려면 트레이 우클릭 **종료**를 쓰세요.

> [!IMPORTANT]
> **이 exe는 코드 서명이 없어서** 처음 실행할 때 SmartScreen이 「Windows의 PC 보호」를 표시합니다 — 「추가 정보」→「실행」을 클릭하세요. 백신이 반응할 수도 있습니다. 레지스트리 Run 키와 예약 작업에 쓰는 것은 시작 프로그램 관리자가 당연히 하는 일이면서 동시에 악성코드가 흔히 하는 일이라, 밖에서는 구분할 방법이 없기 때문입니다. 신뢰만으로 받아들이고 싶지 않다면 [직접 빌드](../../CONTRIBUTING.md)하세요 — 결과는 같고, 바이너리는 당신 것입니다. 각 릴리스에는 `SHA256SUMS.txt`와 GitHub 빌드 출처 증명도 함께 제공됩니다. `gh attestation verify <파일> -R rockbenben/Clockwork`로 내려받은 파일이 누군가의 노트북이 아니라 이 저장소의 CI에서 빌드되었음을 검증할 수 있습니다.

## 팁

- **행을 더블클릭해 편집**하세요. 경로 / 프로세스 / 날짜는 직접 입력하지 않아도 됩니다: **행 끝의 … 버튼**이 해당 선택 창(파일, 검색되는 프로세스 목록, 날짜)을 열고, 단축키는 **캡처**로 직접 눌러 기록합니다.
- **행을 끌어서 순서 바꾸기** — 세 목록 모두와 그룹 편집기의 단계 목록에서 됩니다(위/아래 버튼도 그대로).
- **저장하기 전에 시험 실행** — 그룹 편집기의 **▶ 이 단계 실행**과 **▶ 그룹 실행**은 지금 화면에 있는 내용을 실행하며, 실행 중에는 버튼이 **■ 중지**로 바뀝니다.
- **복제**는 선택한 작업이나 그룹을 바로 아래에 복제합니다 — 비슷한 것을 처음부터 다시 만드는 것보다 빠릅니다. **삭제는 언제나 먼저 확인합니다**, 어디서든 마찬가지입니다.
- `Clockwork.exe`를 더블클릭하면 창만 열릴 뿐, 시작 목록을 다시 실행하지 **않습니다**. 실행하려면 트레이의 **시작 목록 다시 실행**을 쓰세요.
