> Windows 트레이 도구: 시작 프로그램 실행기 · 알림 · 시스템 시작 항목 · 액션 그룹

![Clockwork](../../assets/social-card.png)

컴퓨터 앞에서 하루를 시작할 때의 반복적인 일들을 대신 처리해 주는 작은 Windows 트레이 도구입니다:

- 🚀 **시작 목록** — 로그인 시 매일 쓰는 앱을 순서대로 자동으로 열고(단계별 관리자 권한, 지연, 특정 요일만 / N시 이전만, 창 스타일, 실행 중이면 활성화, 대체 경로 설정 가능), 지나는 김에 몇 가지 잡일도 처리합니다(창 닫기 또는 포커스, 키 입력 / 텍스트 전송, 볼륨 설정…).
- ⏰ **예약 작업** — 정시에 알림을 띄우고; 소리 내어 읽어 주며; 요일 / N일마다 / 매월 반복하거나; "로그인 시" 트리거합니다. **예**를 클릭하면 프로그램 실행, 파일(예: 음악)이나 URL 열기, 또는 액션 그룹 실행이 가능합니다. 간격 반복 실행과 1회 실행도 지원합니다.
- 🧹 **시스템 시작 항목** — **PC에서 자동으로 시작되는 모든 항목**을 나열하고 필요 없는 것을 끕니다(삭제가 아니라 비활성화 — 언제든 되돌릴 수 있음). 클릭 한 번으로 항목을 "인계받아" 자신의 시작 목록으로 가져옵니다.
- 🎛️ **액션 그룹** — 일련의 동작을 재사용 가능한 그룹으로 묶어(집중 / 회의 / 마무리 / 취침…), 트레이·**전역 단축키**·시작 목록·알림에서 클릭 한 번으로 트리거합니다. 기본 제공 템플릿 포함.

설치 불필요, 완전히 이동 가능한 단일 폴더, 모든 것을 마우스로 설정 가능; 다크 UI, 고 DPI 지원.

> 📖 **자세한 사용법:** [English](../USAGE.md) · [中文](../USAGE.zh.md)

## 요구 사항

- Windows 10 / 11 (x64)
- 설치할 것 없음: .NET 런타임이 내장된 자체 포함 단일 파일 `Clockwork.exe`.

## 시작하기

1. [Releases](https://github.com/rockbenben/Clockwork/releases)에서 최신 `Clockwork-<버전>.zip`을 내려받아 압축을 풀면 안에 단일 `Clockwork.exe`가 있습니다; 그것을 아무 폴더에나 두세요(이동 가능 — 어디에 두든 상관없음). 직접 빌드하려면 아래 **개발자용**을 참조하세요.
2. **`Clockwork.exe`**를 더블클릭해 설정 창을 엽니다.
   - **첫 실행** 시 시작 목록과 알림에 몇 가지 **샘플**이 로드되므로 자신에게 맞게 고칠 수 있습니다 — 모두 처음에는 체크가 꺼져 있어, 직접 체크하기 전에는 아무것도 실행되지 않습니다. **액션 그룹** 탭도 바로 실행할 수 있는 두 그룹(잠깐 자리 비움 / 마무리·퇴근)으로 시작합니다 — 이 두 그룹은 이미 *체크되어* 있는데, 그룹은 스스로 발동하지 않고 트리거했을 때만 실행되기 때문입니다. 설정은 exe 옆의 `clockwork.settings.json`에 저장됩니다 — 로컬 전용이며 절대 커밋되지 않습니다.
3. 부팅할 때마다 실행하려면: **설정** 탭에서 **로그인 시 시작**을 클릭하세요(관리자 권한으로 예약 작업을 등록하므로 부팅 시 UAC 프롬프트가 잔뜩 뜨지 않습니다).

> 조용히 트레이에 머무릅니다. 트레이 아이콘을 더블클릭하면 창이 열립니다; 창의 닫기 버튼은 트레이로 숨길 뿐입니다. 완전히 종료하려면 트레이 아이콘을 우클릭해 **종료**를 사용하세요.

> **처음 실행할 때 경고가 뜨는 것은 정상입니다.** 이 exe는 코드 서명이 없어 SmartScreen이 「Windows의 PC 보호」를 표시합니다 —— 「추가 정보」→「실행」을 클릭하세요. 백신이 반응할 수도 있습니다. 레지스트리 Run 키와 예약 작업에 쓰는 것은 시작 프로그램 관리자가 당연히 하는 일이면서 동시에 악성코드가 흔히 하는 일이라, 밖에서는 구분할 방법이 없기 때문입니다. 신뢰만으로 받아들이고 싶지 않다면 아래 **개발자 빌드**를 따라 직접 빌드하세요 —— 결과는 같고, 바이너리는 당신 것입니다.

## 다섯 개의 탭

탭은 다섯 개이며, 항목별 자세한 설명은 [전체 가이드](../USAGE.md)에 있습니다.

- **시작 목록** — 로그인 시 위에서 아래로 실행됩니다. 종류: 프로그램 실행 · 키 전송 · 텍스트 전송 · 볼륨 · 창 동작 · 시스템 명령 · 액션 그룹 · 지연 · 메시지. 각 단계마다 단계 후 지연, 반복 횟수, 요일 / N시 이전 조건을 줄 수 있고, 프로그램은 관리자 권한·창 스타일·실행 중이면 활성화·대체 경로도 지정할 수 있습니다.
- **예약 작업** — 시각(또는 "로그인 시") × 주기(요일 / N일마다 / 매월 / 한 번) × 동작 하나: 알림(다시 알림이 있는 예 / 아니요 대화 상자, 또는 모서리 카드, 음성 읽기 가능)이나 조용히 실행되는 액션 그룹. 여기에 간격 실행, 반복 재알림, 놓친 발화 따라잡기, 트레이의 방해 금지가 더해집니다.
- **시스템 시작 항목** — PC에서 자동 시작되는 모든 것(레지스트리 Run 키, 시작 폴더, 예약 작업)을 나열합니다: 끄기(삭제가 아니라 비활성화), 내 시작 목록으로 가져오기, 완전히 삭제하기.
- **동작 그룹** — 여러 동작을 재사용 가능한 묶음으로 만들어 트레이, **전역 단축키**(다시 누르면 그 실행을 취소), 시작 목록 단계, 예약 작업에서 실행합니다. 그룹은 전체를 반복하거나 다른 그룹을 참조할 수 있고(순환 참조는 저장 시 거부), **메시지** 단계가 예 / 아니요로 이후 진행을 막습니다.
- **설정** — 시작 지연(0–600초, 부팅 시에만), 시작 시 트레이로 최소화, 로그인 시 시작, 긴급 정지 단축키, UI 언어(18종), 설정 내보내기 / 가져오기.

> **언제든 정지** — 탭 바 오른쪽 끝의 **정지 버튼**(실행 중일 때만 보임), 트레이 → **실행 중인 동작 정지**, 또는 전역 **긴급 정지 단축키**(기본값 `Ctrl+Alt+Q`). 시작 지연이나 창 대기 같은 긴 대기는 즉시 중단됩니다.

## 팁

- **행을 더블클릭해 편집**하세요. 경로 / 프로세스 / 단축키 / 날짜를 채울 때 손으로 입력할 필요가 없습니다: **찾아보기…**, **선택…**(검색 가능한 프로세스 선택기), **캡처**, **날짜 선택**이 있습니다.
- **행을 끌어서 순서 바꾸기** — 시작 목록 / 예약 작업 / 동작 그룹 세 목록과 그룹 편집기의 단계 목록에서 모두 됩니다(위/아래 버튼도 그대로).
- **저장하기 전에 시험 실행** — 그룹 편집기에는 **▶ 이 단계 실행**과 **▶ 그룹 실행**이 있고, 둘 다 지금 화면에 있는 내용을 실행합니다. 실행 중에는 버튼이 **■ 중지**로 바뀌며, 편집기를 닫아도 실행이 멈춥니다.
- **복제**(예약 작업 / 액션 그룹 탭)는 선택한 행을 바로 아래에 복제합니다 — 비슷한 항목을 처음부터 다시 만드는 것보다 빠릅니다; 복제된 그룹의 이름은 "… (사본)"이 됩니다.
- **삭제는 언제나 먼저 확인합니다** — 목록 행, 그룹 편집기 안의 단계, 시스템 시작 항목 모두 마찬가지입니다.
- `Clockwork.exe`를 더블클릭하는 것은 설정만 열 뿐이며, 시작 목록을 즉시 실행하지 **않습니다**; 실행하려면 트레이의 **시작 목록 다시 실행**을 사용하세요.
- **정상적으로 실행하세요**(더블클릭 / 트레이 / 예약 작업). 일부 샌드박스 / 권한을 낮춘 실행기는 저수준 호출을 차단하므로 키 전송 / 창 동작 / 실행 중이면 활성화 / 프로세스로 텍스트 전송 / 볼륨이 작동하지 않을 수 있습니다(명확한 안내가 표시됩니다; 단순한 "프로그램 실행"은 영향을 받지 않습니다).
- 설정은 `clockwork.settings.json`(로컬 전용)입니다. 삭제하면 샘플로 초기화됩니다. 작업 상태는 `clockwork.state.json`(역시 로컬; 삭제해도 안전)입니다.
- `.ahk` 단계를 추가하려면 AutoHotkey가 설치되어 있어야 합니다. 전역 단축키 / 텍스트 확장은 범위 밖입니다 — 그것은 AutoHotkey의 강점입니다.

## 개발자용

C#/.NET WPF; 소스는 `app/`(.NET 10 SDK 필요). 레이어: `Core/` 순수 로직 · `Native/` Win32 상호 운용 · `Engine/` 실행 · `ViewModels/` + `Views/` UI · `I18n/` + `Resources/` 지역화(중립 = 중국어 소스, 언어마다 하나의 `Strings.<code>.resx` 새틀라이트).

- 테스트 실행(xUnit):
  ```powershell
  dotnet test app.Tests/Clockwork.Tests.csproj
  ```
- 자체 포함 단일 파일 exe 빌드(단일 파일 / 자체 포함 / 압축은 csproj에 설정됨):
  ```powershell
  dotnet publish app/Clockwork.csproj -c Release -r win-x64
  ```
  출력: `app/bin/Release/net10.0-windows/win-x64/publish/Clockwork.exe`.
- **CI / 릴리스**(GitHub Actions): push / PR은 Windows 러너에서 빌드하고 모든 테스트를 실행합니다; `v*` 태그(예: `v2.0.0`)를 push하면 빌드하고, 태그에서 파일 버전을 새기고, GitHub Release를 만들어 `Clockwork-<태그>.zip`(`Clockwork.exe` 포함)을 첨부합니다.
