> Открытый план 365 #020 · Утилита в трее Windows: запуск при старте · напоминания · элементы автозагрузки системы · группы действий

![Clockwork](../../assets/social-card.png)

Небольшая утилита в трее Windows, которая берёт на себя рутину при начале рабочего дня за компьютером:

- 🚀 **Список автозапуска** — автоматически открывает ваши повседневные приложения при входе, по порядку (права администратора для каждого шага, задержки, только-в-определённые-дни-недели / только-до-N-часов, стиль окна, активировать-если-запущено, запасные пути) и попутно выполняет мелкие задачи (закрыть или сфокусировать окна, отправить нажатия клавиш / текст, задать громкость…).
- ⏰ **Задачи по расписанию** — показывают напоминание вовремя; проговаривают его вслух; повторяют по дням недели / каждые-N-дней / ежемесячно; либо срабатывают «при входе». Нажатие **Да** может запустить программу, открыть файл (например, музыку) или URL либо выполнить группу действий. Также поддерживаются запуск по интервалу и однократное выполнение.
- 🧹 **Элементы автозагрузки системы** — показывают **всё, что автоматически запускается на вашем ПК**, и отключают то, что вам не нужно (отключено, а не удалено — можно вернуть в любой момент). Один клик «перехватывает» элемент в ваш собственный список автозапуска.
- 🎛️ **Группы действий** — объедините ряд действий в многоразовую группу (Фокус / Совещание / Завершение / Отход ко сну…) и запускайте её одним кликом из трея, **глобальной горячей клавишей**, из списка автозапуска или напоминания. Встроенные шаблоны включены.

Без установки, полностью портативна в одной папке, всё настраивается мышью; тёмный интерфейс, поддержка высокого DPI.

> 📖 **Полное руководство:** [English](../USAGE.md) · [中文](../USAGE.zh-CN.md)

## Требования

- Windows 10 / 11 (x64)
- Ничего устанавливать не нужно: автономный однофайловый `Clockwork.exe` со встроенной средой выполнения .NET.

## Начало работы

1. Скачайте свежий `Clockwork-<версия>.zip` из раздела [Releases](https://github.com/rockbenben/Clockwork/releases) и распакуйте его — внутри единственный `Clockwork.exe`; поместите его в любую папку (портативно — куда угодно). Чтобы собрать самому, см. **Для разработчиков** ниже.
2. Дважды щёлкните по **`Clockwork.exe`**, чтобы открыть окно настроек.
   - При **первом запуске** загружается несколько **примеров** в списке автозапуска и напоминаниях, чтобы вы адаптировали их под себя — все они изначально не отмечены, так что ничего не выполняется, пока вы сами не поставите галочку. Вкладка **Группы действий** также сразу открывается с двумя готовыми к запуску группами (Отойти ненадолго / Завершение дня) — они уже *отмечены галочкой*, потому что группа никогда не срабатывает сама по себе; она выполняется только тогда, когда вы её запускаете. Ваши настройки хранятся в `clockwork.settings.json` рядом с exe — только локально, никогда не коммитятся.
3. Чтобы запускать его при каждой загрузке: на вкладке **Настройки** нажмите **Запускать при входе** (регистрирует запланированную задачу с правами администратора, поэтому при загрузке не будет вала запросов UAC).

> Она тихо сидит в трее. Дважды щёлкните по значку в трее, чтобы открыть окно; кнопка закрытия окна лишь сворачивает его в трей. Чтобы выйти по-настоящему, используйте **Выход** в контекстном меню трея.

> **Предупреждение при первом запуске — это нормально.** Файл exe не подписан, поэтому SmartScreen показывает «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**. Антивирус тоже может сработать: запись ключей Run в реестре и заданий планировщика — это ровно то, чем занимается менеджер автозагрузки, и одновременно то, чем занимается вредонос; снаружи их не различить. Если не хотите принимать это на веру, соберите программу сами по разделу **Для разработчиков** ниже — результат тот же, а бинарник ваш собственный.

## Пять вкладок

### Список автозапуска

**Упорядоченный список шагов**, выполняемых сверху вниз при входе. Нажмите **Добавить ▾**, чтобы выбрать тип; добавляйте/удаляйте/меняйте порядок свободно; каждый шаг можно включить/отключить, задать ему **задержку после шага**, **число повторов** (повторить N раз) и условия (**только в определённые дни недели / только до N часов**). Типы шагов:

- **Запуск программы** — цель (**Обзор…** для выбора файла) / аргументы / рабочий каталог (оставьте пустым = папка цели) / администратор. Целью может быть `.exe`, документ, ярлык или URL; `.ps1` выполняется через PowerShell. Дополнительно: **стиль окна** (свёрнутое / развёрнутое / скрытое), **активировать, если уже запущено** (вывести на передний план вместо перезапуска; имя процесса через **Выбрать…**), **запасные пути** (по одному полному пути в строке; используется первый существующий — удобно, когда пути установки различаются на разных машинах).
- **Отправка клавиш** — например, Win+D, Alt+K, Ctrl+Enter, F5 (**Захват** для записи сочетания нажатием).
- **Отправка текста** — вводит строку в активное окно (или в выбранный **целевой процесс** через **Выбрать…**).
- **Громкость** — отключить / включить звук / задать уровень.
- **Действие с окном** — по имени процесса (**Выбрать…**, с поиском): закрыть / свернуть / развернуть / вывести-на-передний-план / вывести-на-передний-план-и-отправить-клавиши; медленные приложения могут **ждать появления окна до N секунд**.
- **Системная команда** — показать рабочий стол / заблокировать / выключить монитор / очистить корзину / очистить буфер обмена / открыть Параметры / Диспетчер задач / снимок экрана / сон / гибернация / выход из системы / перезагрузка / выключение (последние три сначала запрашивают подтверждение).
- **Задержка** — просто подождать N секунд перед следующим шагом.
- **Группа действий** — запускает заданную группу действий; её число повторов означает, сколько раз срабатывает *эта ссылка* (сама группа тоже может повторяться внутри — см. **Группы действий** ниже).

> **Задержка при старте** (вкладка Настройки, только при загрузке): подождать фиксированное число секунд после входа, чтобы «шторм входа» (конкуренция за диск/ЦП со стороны всех автозапусков) прошёл до выполнения списка; ручной повторный запуск не затрагивается. Увеличьте её (0–600 с), если всё стартует слишком рано.

> **Остановить в любой момент** — **кнопка остановки** в правом конце строки вкладок окна (появляется, только пока что-то выполняется), трей → **Остановить выполняемые действия**, либо глобальная **аварийная горячая клавиша** (задаётся на вкладке Настройки; по умолчанию `Ctrl+Alt+Q`). То, что выполняется, останавливается после текущего действия; долгие ожидания (задержка при старте, ожидание окна) прерываются немедленно.

### Задачи по расписанию

Задайте **время** (или переключитесь на **при входе**), **периодичность** (дни недели / каждые N дней / ежемесячно / **один раз в указанную дату**) и выберите одно **действие**: **показать напоминание** либо **тихо запустить группу действий**. На экране остаются только поля выбранного действия, так что вы никогда не заполняете поле, которое ничего не делает.

Напоминания с действием **По-Да** (запустить программу / открыть файл / URL / запустить группу действий) открывают диалог **Да / Нет** с кнопкой **Отложить** (по умолчанию 10 мин, меню ▾ 5–60 мин); остальные выезжают в углу как **карточка напоминания** (закрывается сама через заданное число секунд, **0 = остаётся, пока вы её не закроете**). Текст можно озвучить.

**Интервальные запуски** превращают одну задачу в расписание на весь день: *каждые N минут до HH:mm* (пусто = до конца дня). В отличие от **повторных напоминаний**, которые прекращаются, едва вы подтвердите, интервал продолжается после вашего ответа — именно это делает тихую группу пригодной для опроса. Интервалы не переходят через полночь; завтра всё начинается заново со собственного времени задачи. Прогресс сохраняется: перезапуск приложения в полдень не теряет оставшиеся круги дня.

**Один раз** срабатывает в свою дату и затем **сам снимает галочку**, оставаясь в списке — поменяйте дату и отметьте снова, чтобы использовать повторно. Он ждёт окончания повторных напоминаний или откладывания и только потом выключается, поэтому никогда не обрывает доставку.

Диалог, оставшийся без ответа, не блокирует очередь и не теряется: максимум через минуту он превращается в **автоматическое «отложить на 10 минут»** и появляется снова. Это состояние сохраняется на диск, как любое откладывание — оно переживает перезапуск, а с включённым **«наверстать при пропуске»** напоминание сработает ещё раз на следующий день, даже если ночь пересекла полночь. Повторные срабатывания одного напоминания делят одну карточку (с пометкой **×N**), а закрытые или истёкшие карточки можно показать снова через меню трея **«Недавние»**.

Дополнительно: **автозакрытие**, **повторное напоминание** (всплывает снова каждые N минут до дедлайна), **задержка после срабатывания + случайный разброс**, **допуск** (подхватить срабатывание, пропущенное из-за кратковременного выключения/сна), **наверстать при пропуске** (сработать ещё раз, если гибернация/выключение его пропустили) и **опорная дата** для «каждые N дней» (**Выбрать дату**). «Сработало сегодня» и «отложено до» переживают перезапуски (`clockwork.state.json`), поэтому отложенное переносится через перезапуск и ничто не срабатывает дважды.

Нужно сосредоточиться или провести совещание? Трей предлагает **Приостановить напоминания на 1 / 2 / 4 часа** (Не беспокоить): всё (включая тихие группы) подавляется и автоматически возобновляется по истечении времени.

### Элементы автозагрузки системы

Перечисляет **всё, что автоматически запускается** (ключи Run в реестре, папки Автозагрузки, запланированные задачи). Снимите флажок **Включить**, чтобы отключить элемент — **отключено, а не удалено; поставьте флажок снова, чтобы восстановить** (действует немедленно). Элементы, помеченные **нужны права администратора**, предлагают перезапуститься с повышением. Системные / политики / одноразовые элементы (Run групповой политики, RunOnce, Winlogon, Active Setup) трогать нельзя, и они **скрыты по умолчанию** — отметьте **Показывать системные / только-для-чтения элементы**, чтобы их увидеть (недоступны, приглушены). Щёлкните строку правой кнопкой, чтобы выбрать **Перенести в список запуска** (передаёт элемент Clockwork; только ключи Run в реестре и элементы папки Автозагрузки) или **Удалить из системы** (удаляет запись навсегда — сначала спросит, и отменить это нельзя; обратимый вариант — снять флажок). Верхний **фильтр** ищет по имени / команде; наведите курсор на усечённую команду, чтобы прочитать её целиком.

### Группы действий

Объедините действия в многоразовую группу. **Добавить ▾** создаёт её из **встроенного шаблона** (Фокус / Совещание / Завершение / Отход ко сну / Отлучиться / Снимок экрана / Перерыв от сидения) — подправьте имена процессов и сохраните. Группа **только определяет действия**; запускайте её четырьмя способами: из трея (**Запустить: <группа>**), **глобальной горячей клавишей**, как **шаг группы действий** в списке автозапуска (при загрузке) или из задачи по расписанию (**По-Да / тихая группа**). Одновременно выполняется только одна копия группы.

**Циклы.** Группа может **повторяться целиком** (число повторов + пауза между кругами, в редакторе группы). Чтобы повторить только *часть* последовательности, вынесите эти шаги в отдельную группу и сошлитесь на неё шагом **группа действий**, задав ему число повторов — группы могут ссылаться на группы, а при сохранении круговые ссылки отклоняются с показом цепочки (`A → B → A`). Три регулятора повторов перемножаются: на шаг × на ссылку × на всю группу. Один запуск ограничен предохранителем в **5000 шагов**, поэтому чрезмерная комбинация останавливается, а не работает бесконечно.

Шаг **сообщения** — это барьер подтверждения: ответ **Нет** прерывает остаток группы *и её оставшиеся круги*, а также передаётся наружу той группе, которая на неё сослалась — отказать один раз достаточно, даже внутри подгруппы, повторяемой ×N.

> **Глобальная горячая клавиша** — в редакторе группы щёлкните по полю горячей клавиши и нажмите сочетание (например, `Ctrl+Alt+F`), чтобы запускать эту группу откуда угодно, без меню. Esc отменяет, Delete очищает. Отключённые группы освобождают своё сочетание; зарезервированные системой сочетания (Alt+F4, Ctrl+Shift+Esc…) и сочетания, уже занятые другой группой или аварийной горячей клавишей, отклоняются с уведомлением.

### Настройки

**Задержка при старте** (0–600 с, только при загрузке), **запускать свёрнутой в трей**, **аварийная горячая клавиша** (щёлкните по полю и нажмите ваше сочетание; Esc отменяет, Delete очищает; по умолчанию `Ctrl+Alt+Q`) и **язык интерфейса** (упрощённый китайский, английский, 日本語 и ещё 15 — всего 18; переключение перезапускает приложение для применения).

**Экспорт конфигурации / Импорт конфигурации** — перенесите всю свою настройку на другой ПК или сохраните резервную копию. Экспорт записывает копию `clockwork.settings.json` в любое место по вашему выбору; импорт заменяет **всё** (список автозапуска / задачи по расписанию / группы действий / настройки), поэтому он сначала спрашивает подтверждение, сохраняет текущую конфигурацию в `clockwork.settings.json.bak` и перезапускает приложение для применения.

## Советы

- **Дважды щёлкните по строке, чтобы её отредактировать.** При заполнении путей / процессов / сочетаний / дат не нужно вводить вручную: **Обзор…**, **Выбрать…** (выбор процесса с поиском), **Захват** и **Выбрать дату**.
- **Дублировать** (вкладки «Задачи по расписанию» / «Группы действий») создаёт копию выбранной строки прямо под ней — быстрее, чем собирать почти такую же заново; дублированная группа получает имя «… (копия)».
- **Удаление всегда сначала спрашивает подтверждение** — везде: строки списков, шаги внутри редактора групп и элементы автозагрузки системы.
- Двойной щелчок по `Clockwork.exe` только открывает настройки — он **не** запускает сразу список автозапуска; для этого используйте **Повторно выполнить список автозапуска** в трее.
- **Запускайте её обычным способом** (двойной щелчок / трей / запланированная задача). Некоторые песочницы / запускающие с пониженными правами блокируют низкоуровневые вызовы, поэтому отправка клавиш / действия с окном / активировать-если-запущено / отправка-текста-в-процесс / громкость могут не работать (вы получите чёткое уведомление; обычный «запуск программы» не затрагивается).
- Ваша конфигурация — `clockwork.settings.json` (только локально). Удалите её, чтобы сбросить к примеру. Состояние задач — `clockwork.state.json` (тоже локально; удалять безопасно).
- Для добавления шага `.ahk` нужен установленный AutoHotkey. Глобальные горячие клавиши / расширение текста вне области задач — это сильная сторона AutoHotkey.
