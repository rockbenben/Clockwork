> Утилита в трее Windows: запуск при старте · напоминания · элементы автозагрузки системы · группы действий

![Clockwork](../../assets/social-card.png)

Небольшая утилита в трее Windows, которая берёт на себя рутину при начале рабочего дня за компьютером:

- 🚀 **Список автозапуска** — автоматически открывает ваши повседневные приложения при входе, по порядку (права администратора для каждого шага, задержки, только-в-определённые-дни-недели / только-до-N-часов, стиль окна, активировать-если-запущено, запасные пути) и попутно выполняет мелкие задачи (закрыть или сфокусировать окна, отправить нажатия клавиш / текст, задать громкость…).
- ⏰ **Задачи по расписанию** — показывают напоминание вовремя; проговаривают его вслух; повторяют по дням недели / каждые-N-дней / ежемесячно; либо срабатывают «при входе». Нажатие **Да** может запустить программу, открыть файл (например, музыку) или URL либо выполнить группу действий. Также поддерживаются запуск по интервалу и однократное выполнение.
- 🧹 **Элементы автозагрузки системы** — показывают **всё, что автоматически запускается на вашем ПК**, и отключают то, что вам не нужно (отключено, а не удалено — можно вернуть в любой момент). Один клик «перехватывает» элемент в ваш собственный список автозапуска.
- 🎛️ **Группы действий** — объедините ряд действий в многоразовую группу (Фокус / Совещание / Завершение / Отход ко сну…) и запускайте её одним кликом из трея, **глобальной горячей клавишей**, из списка автозапуска или напоминания. Встроенные шаблоны включены.

Без установки, полностью портативна в одной папке, всё настраивается мышью; тёмный интерфейс, поддержка высокого DPI.

> 📖 **Полное руководство:** [English](../USAGE.md) · [中文](../USAGE.zh.md)

## Требования

- Windows 10 / 11 (x64)
- Ничего устанавливать не нужно: автономный однофайловый `Clockwork.exe` со встроенной средой выполнения .NET.

## Начало работы

1. Скачайте свежий `Clockwork-<версия>.zip` из раздела [Releases](https://github.com/rockbenben/Clockwork/releases) и распакуйте его — внутри единственный `Clockwork.exe`; поместите его в любую папку (портативно — куда угодно). Чтобы собрать самому, см. **Для разработчиков** ниже.
2. Дважды щёлкните по **`Clockwork.exe`**, чтобы открыть окно настроек.
   - При **первом запуске** загружается несколько **примеров** в списке автозапуска и напоминаниях, чтобы вы адаптировали их под себя — все они изначально не отмечены, так что ничего не выполняется, пока вы сами не поставите галочку. Вкладка **Группы действий** также сразу открывается с двумя готовыми к запуску группами (Отойти ненадолго / Завершение дня) — они уже *отмечены галочкой*, потому что группа никогда не срабатывает сама по себе; она выполняется только тогда, когда вы её запускаете. Ваши настройки хранятся в `clockwork.settings.json` рядом с exe — только локально, никогда не коммитятся.
3. Чтобы запускать его при каждой загрузке: на вкладке **Настройки** нажмите **Запускать при входе** (регистрирует запланированную задачу с правами администратора, поэтому при загрузке не будет вала запросов UAC).

> Она тихо сидит в трее. Дважды щёлкните по значку в трее, чтобы открыть окно; кнопка закрытия окна лишь сворачивает его в трей. Чтобы выйти по-настоящему, используйте **Выход** в контекстном меню трея.

> **Предупреждение при первом запуске — это нормально.** Файл exe не подписан, поэтому SmartScreen показывает «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**. Антивирус тоже может сработать: запись ключей Run в реестре и заданий планировщика — это ровно то, чем занимается менеджер автозагрузки, и одновременно то, чем занимается вредонос; снаружи их не различить. Если не хотите принимать это на веру, соберите программу сами по разделу **Для разработчиков** ниже — результат тот же, а бинарник ваш собственный.

## Пять вкладок

Пять вкладок; каждое поле разобрано в [полном руководстве](../USAGE.md).

- **Список запуска** — шаги выполняются сверху вниз при входе в систему. Типы: запустить программу · отправить клавиши · отправить текст · громкость · действие с окном · системная команда · группа действий · пауза · сообщение. У каждого шага есть задержка после выполнения, число повторов и условия (только в определённые дни недели / только до N часов); у программ ещё права администратора, стиль окна, активировать-если-запущено и запасные пути.
- **Задачи по расписанию** — время (или «при входе») × периодичность (день недели / каждые N дней / ежемесячно / один раз) × одно действие: напоминание (окно Да/Нет с отложить или карточка в углу, можно зачитать вслух) либо группа действий, выполняемая молча. Плюс запуски по интервалу, повторные напоминания, наверстывание пропущенного срабатывания и режим «не беспокоить» из трея.
- **Элементы автозагрузки системы** — всё, что запускается на ПК само (ключи Run в реестре, папки «Автозагрузка», задачи планировщика): выключить (отключено, не удалено), забрать в свой список запуска или удалить насовсем.
- **Группы действий** — переиспользуемый набор действий, запускаемый из трея, **глобальной горячей клавишей** (нажмите ещё раз, чтобы отменить этот запуск), шагом списка запуска или задачей по расписанию. Группа может повторяться целиком и ссылаться на другие группы (циклические ссылки отклоняются при сохранении); шаг **сообщение** останавливает остальное ответом Да / Нет.
- **Настройки** — задержка запуска (0–600 с, только при загрузке), запускать свёрнутым в трей, запуск при входе, аварийная горячая клавиша, язык интерфейса (18), экспорт / импорт конфигурации.

> **Остановить в любой момент** — **кнопка остановки** справа на панели вкладок (видна, только пока что-то выполняется), трей → **Остановить выполняемые действия** или глобальная **аварийная клавиша** (по умолчанию `Ctrl+Alt+Q`). Долгие ожидания (задержка запуска, ожидание окна) прерываются сразу.

## Советы

- **Дважды щёлкните по строке, чтобы её отредактировать.** При заполнении путей / процессов / сочетаний / дат не нужно вводить вручную: **Обзор…**, **Выбрать…** (выбор процесса с поиском), **Захват** и **Выбрать дату**.
- **Перетащите строку, чтобы изменить порядок** — во всех трёх списках (список запуска, задачи по расписанию, группы действий) и в списке шагов редактора группы; кнопки вверх/вниз по-прежнему работают.
- **Проверьте до сохранения** — в редакторе группы есть **▶ Выполнить этот шаг** и **▶ Выполнить группу**, обе запускают то, что сейчас на экране. Во время выполнения кнопка превращается в **■ Стоп**, а закрытие редактора останавливает запуск.
- **Дублировать** (вкладки «Задачи по расписанию» / «Группы действий») создаёт копию выбранной строки прямо под ней — быстрее, чем собирать почти такую же заново; дублированная группа получает имя «… (копия)».
- **Удаление всегда сначала спрашивает подтверждение** — везде: строки списков, шаги внутри редактора групп и элементы автозагрузки системы.
- Двойной щелчок по `Clockwork.exe` только открывает настройки — он **не** запускает сразу список автозапуска; для этого используйте **Повторно выполнить список автозапуска** в трее.
- **Запускайте её обычным способом** (двойной щелчок / трей / запланированная задача). Некоторые песочницы / запускающие с пониженными правами блокируют низкоуровневые вызовы, поэтому отправка клавиш / действия с окном / активировать-если-запущено / отправка-текста-в-процесс / громкость могут не работать (вы получите чёткое уведомление; обычный «запуск программы» не затрагивается).
- Ваша конфигурация — `clockwork.settings.json` (только локально). Удалите её, чтобы сбросить к примеру. Состояние задач — `clockwork.state.json` (тоже локально; удалять безопасно).
- Для добавления шага `.ahk` нужен установленный AutoHotkey. Глобальные горячие клавиши / расширение текста вне области задач — это сильная сторона AutoHotkey.

## Для разработчиков

C#/.NET WPF; исходники в `app/` (нужен .NET 10 SDK). Слои: `Core/` чистая логика · `Native/` interop Win32 · `Engine/` выполнение · `ViewModels/` + `Views/` интерфейс · `I18n/` + `Resources/` локализация (нейтральный = китайский источник, по одному сателлиту `Strings.<code>.resx` на язык).

- Запуск тестов (xUnit):
  ```powershell
  dotnet test app.Tests/Clockwork.Tests.csproj
  ```
- Сборка автономного однофайлового exe (однофайловость / автономность / сжатие заданы в csproj):
  ```powershell
  dotnet publish app/Clockwork.csproj -c Release -r win-x64
  ```
  Результат: `app/bin/Release/net10.0-windows/win-x64/publish/Clockwork.exe`.
- **CI / релизы** (GitHub Actions): push / PR собирают и прогоняют все тесты на Windows-раннере; отправка тега `v*` (например, `v2.0.0`) собирает, проставляет версию файла из тега, создаёт GitHub Release и прикрепляет `Clockwork-<тег>.zip` (содержащий `Clockwork.exe`).
