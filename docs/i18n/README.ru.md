## Что умеет

- 🚀 **Список автозапуска** — по порядку открывает ваши повседневные приложения при входе, с задержкой, условием по дням недели и стилем окна для каждого шага; попутно закрывает, выводит на передний план или отключает звук.
- ⏰ **Задачи по расписанию** — напоминание вовремя, при желании зачитанное вслух, либо группа действий, выполняемая молча. Нажатие **Да** может запустить программу, открыть файл или URL либо запустить группу.
- 🧹 **Элементы автозагрузки системы** — всё, что запускается на вашем ПК само, в одном списке: отключите ненужное (отключено, а не удалено) или перехватите в свой собственный список автозапуска.
- 🎛️ **Группы действий** — соберите сценарий (Фокус / Совещание / Завершение / Отход ко сну…) и запускайте его из трея, **глобальной горячей клавишей**, из списка автозапуска или задачи по расписанию. Шаблоны включены.

> **Остановить в любой момент** — кнопка остановки справа на панели вкладок (видна, только пока что-то выполняется), трей → **Остановить выполняемые действия** или глобальная аварийная клавиша (по умолчанию `Ctrl+Alt+Q`). Долгие ожидания обрываются, а не пережидаются.

## Требования

| Аспект | Подробности |
| --- | --- |
| **Система** | Windows 10 / 11, x64 |
| **Установка** | Не нужна. Один `Clockwork.exe` со встроенной средой выполнения .NET — положите в любую папку |
| **Права администратора** | Только для «Запускать при входе» и для шагов, помеченных **запуск от администратора** |
| **Ваши настройки** | `clockwork.settings.json` рядом с exe (или `%APPDATA%\Clockwork\`, если папка доступна только для чтения) — ничего не покидает компьютер |
| **Интерфейс** | 18 языков, при первом запуске следует языку интерфейса Windows |

**Ограничения.** Раз нет установщика — нет и автообновления: скачайте новый zip и замените exe. Запуск из песочницы блокирует отправку клавиш, действия с окнами, активировать-если-запущено и громкость (вы получите чёткое уведомление; обычный «запуск программы» работает). Переназначение клавиш и расширение текста остаются вне области задач — это работа AutoHotkey.

## Начало работы

1. Скачайте свежий `Clockwork-<версия>.zip` из раздела [Releases](https://github.com/rockbenben/Clockwork/releases), распакуйте и положите единственный `Clockwork.exe` в любую папку.
2. Дважды щёлкните по нему, чтобы открыть окно настроек. Загруженные примеры все **без галочек** — ничего не выполняется, пока вы сами не отметите.
3. Чтобы запускать при каждой загрузке: на вкладке **Настройки** отметьте **Запускать при входе** (регистрирует запланированную задачу с правами администратора, поэтому при загрузке не будет вала запросов UAC).

Дальше программа сидит в трее: двойной щелчок по значку открывает окно, а кнопка закрытия лишь снова его прячет. Чтобы выйти по-настоящему, используйте **Выход** в контекстном меню трея.

> [!IMPORTANT]
> **Файл exe не подписан**, поэтому при первом запуске SmartScreen показывает «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**. Антивирус тоже может сработать: запись ключей Run в реестре и заданий планировщика — это ровно то, чем занимается менеджер автозагрузки, и одновременно то, чем занимается вредонос; снаружи их не различить. Если не хотите принимать это на веру, [соберите программу сами](../../CONTRIBUTING.md) — результат тот же, а бинарник ваш собственный.

**Полное руководство** — каждое поле, каждый крайний случай: [English](../USAGE.md) · [中文](../USAGE.zh.md)

## Советы

- **Дважды щёлкните по строке, чтобы её отредактировать.** Пути, процессы, сочетания и даты подставляются за вас: **Обзор…**, **Выбрать…** (выбор процесса с поиском), **Захват**, **Выбрать дату**.
- **Перетащите строку, чтобы изменить порядок** — во всех трёх списках и в списке шагов редактора группы; кнопки вверх/вниз по-прежнему работают.
- **Проверьте до сохранения** — **▶ Выполнить этот шаг** и **▶ Выполнить группу** в редакторе запускают то, что сейчас на экране, а кнопка на время выполнения превращается в **■ Стоп**.
- **Дублировать** создаёт копию выбранной задачи или группы прямо под ней — быстрее, чем собирать почти такую же заново. **Удаление всегда сначала спрашивает подтверждение**, везде.
- Двойной щелчок по `Clockwork.exe` только открывает окно; он **не** запускает список автозапуска заново. Для этого используйте **Повторно выполнить список автозапуска** в трее.
