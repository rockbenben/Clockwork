# Clockwork 使用说明

[English](USAGE.md) · **中文** · [← 返回 README](../README.zh.md)

电脑上重复的事，自动帮你做：开机自动开好软件 · 按时提醒 · 一键完成一串操作。

一个 Windows 托盘小工具，管好开机与日常五件事（外加一个「设置」页）：

1. **我的启动清单** —— 开机自动按顺序打开常用软件、顺手做几件杂事。
2. **定时任务** —— 到点弹窗提醒（可朗读 / 重复催促 / 点「是」后做事）或静默运行动作；支持仅一次、循环运行，或按星期 / 每 N 天 / 每月的常规周期。
3. **动作** —— 把一串动作打包成「组」（专注 / 收工 / 睡前……），一键触发，或绑**全局热键**随手唤起。
4. **系统启动项** —— 查看并管理电脑里所有开机自启项，一键关闭不需要的。
5. **端口** —— 看清哪些端口正被监听、分别是谁占着，双击用浏览器打开 `localhost:3000`，右键释放端口。

界面提供 **18 种语言**，首次运行默认跟随系统显示语言（可在「设置」页手动切换）。

---

## 怎么开始

1. 把 `Clockwork-<版本号>-win-x64.zip` 解压到任意文件夹（绿色免安装，放哪都行），里面是单个 `Clockwork.exe`。带 `-needs-dotnet10` 的包是同一个 exe 去掉内置 .NET 运行时，体积只有零头，但要求电脑上已装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)；这一版还额外直接挂了个没打包的 `Clockwork.exe`，不想解压就下它。
2. 双击 **`Clockwork.exe`** 打开设置窗口。
3. 想每次开机自动运行：到 **「设置」** 页勾选「开机自启」（用管理员权限注册计划任务，开机时不会弹一堆授权框）。

平时它安静待在右下角托盘。点窗口的关闭按钮只是收起到托盘，不会退出；彻底退出用托盘右键 **「退出」**。在「设置」页勾选 **「启动时最小化到托盘」** 后，手动打开也直接进托盘、不弹主窗口。

## 第一次用：把示例换成你自己的

首次打开，启动清单和定时任务里各有几条**示例**（都带「示例」字样），挑的是最有代表性的几种玩法——静音、开程序、仅工作日开网址（条件执行）、把聊天软件最小化挂后台、发组合键——只是演示给你照葫芦画瓢用的，放心大胆改或删。**它们全都默认没勾选**，也就是说装完什么都不会自动跑；想让哪条生效，勾上它再说。动作标签页首次已经预置了「离开一下」与「收工·下班」两个组，可以直接用；想要其余套路，从「从模板…」里选一个加进来即可。

最常见的「开机自动打开我常用的几个软件」，这样弄：

1. 切到 **我的启动清单**。
2. 把用不上的示例整条删掉（选中 → 删除 → 确认，删完自动选中下一条，连着删很顺手）。
3. **「新增 ▾」→「打开」→ 启动程序**，「目标」填你要开的软件：
   - 系统能找到的填程序名即可：`msedge.exe`（Edge）、`notepad.exe`（记事本）；
   - 找不到的填**完整路径**：右键该程序 →「打开文件所在位置」→ 右键图标「属性」，把里面的「目标」路径复制粘进来；
   - 网址（`https://…`）、文档、`.ps1` 脚本、快捷方式（`.lnk`）也都能填；路径可以带引号或 `%USERPROFILE%` 这类环境变量，会自动处理。
   - `.ps1` 要填**完整路径**（裸文件名 PowerShell 找不到），用哪个 PowerShell 由程序自动挑，细节见下面「步骤类型」表后的注意事项。
4. 想某个软件晚点再开，就把它的 **「执行后延时」** 调大几秒，或上下移调顺序。
5. 托盘图标右键 → **「重新运行启动清单」** 先试跑一遍，确认都对。
6. 满意后到 **「设置」** 页勾上「开机自启」，以后开机自动照做。

> 只想用「定时任务」或「动作」？去对应标签页照同样思路改示例即可，启动清单可全删空——四块功能各自独立，用哪块开哪块。

## 我的启动清单

- 一条**有序步骤表**，开机从上到下依次执行。可增删；**拖动条目即可调整顺序**——每行最左边有一个**拖动手柄**（≡），鼠标移到那一行就会亮起来；上移 / 下移按钮也照样能用（键盘可达，且适合一格一格微调）。**双击条目即编辑**；**右键**打开「复制」（定时任务那页还有「今天不再」）。（三个列表页的操作完全一致。）
- 每步可单独启停、设「执行后延时」、设「重复次数」（循环动作：连续执行 N 次，每次之间等「执行后延时」），并设**执行条件**（见下）。「消息」步骤没有重复次数——它恒定只弹一次，把别的类型改成「消息」时残留的次数不会生效。
- 选中一条按 **「运行」** = 立即只跑这一步看效果（无视该项启停与时间条件，纯测试）；结果弹托盘气泡反馈。
- **「新增 ▾」→「打开」，第一项是「从开始菜单选择…」** —— 列出开始菜单里的全部程序——**包括便笺、画图这类没有 exe 路径的 Store / UWP 应用**（它们不以文件形式存在，手填是填不出来的）。搜一下、按住 Ctrl / Shift 多选，确定即逐条变成「启动程序」步骤，不用再去右键属性复制路径。加进来的步骤**默认不勾选**，看一眼没问题再启用。
- **「新增 ▾」按你想做什么分节，每节一个子菜单**（常用 / 运行动作 / 打开 / 控制程序 / 系统与声音 / 流程）。顶层只有这几个意图词，机制名在里面——「关掉微信」该点「窗口操作」还是「发送按键」这种问题，先选「控制程序」就绕过去了。（平铺过一版，十几种类型加上小节头是一堵二十多行的墙，在 1366×768 的小本上直接长出上下滚动箭头，末尾几项要滚才看得见。）
- **「新增 ▾」→「常用」** —— 一份预填好的清单：复制 / 粘贴 / 搜索选中的文字 / 后退 / 前进 / 播放暂停·上一曲·下一曲 / 音量调高·调低 / 最小化·最大化·切换置顶·关闭当前窗口。它们不是新类型，只是既有类型填好了字段的样子（「复制」的真身就是「发送按键 `Ctrl+C`」），选完照样进同一个步骤编辑器，进去还能改。**给鼠标手势用的**：画手势的人心里想的词是「复制」，不是「发送按键」。
  开机清单里没有这一节——那里的每一条都在问「你眼下正看着什么」，而开机那一刻没人在场。

### 步骤类型

| 类型 | 说明 |
| --- | --- |
| **启动程序** | 程序（完整路径或裸程序名）/ 快捷方式 / 脚本 / 文件夹 / 网址 / 文档 / `ms-settings:` 等协议都行（目标右边的 **…** 按钮直接选文件）；`.ps1` 自动用 PowerShell 运行，并会**自动挑合适的那个 PowerShell**（见本表下方注意事项）。目标与工作目录都可以带引号或写 `%USERPROFILE%` 这类环境变量，会自动处理。工作目录留空 = 目标所在目录。进阶：**窗口风格**（最小化 / 最大化 / 隐藏启动）、**已在运行则激活**（**默认开启**：把它带到最前、不重复启动；进程名右边 **…** 可挑。目标是网址 / `.lnk` / `.ps1` / 文档时进程名推导不出来，本选项自动空转、照常启动）、**备用路径**（每行一条完整路径，主路径不存在时用第一个存在的——多设备安装路径不一致时用）。 |
| **发送按键** | 如 Win+D、Alt+K、Ctrl+Enter、F5（支持 Enter / Tab / Esc / Del / 方向键等键名；可点「捕获」按快捷键自动填）。**带修饰键的滚轮**（如 `Ctrl+滚轮` 缩放）也在这里：按住 Ctrl 在组合键框里滚一下就录成 `Ctrl+WheelDown`；**按住 Shift 滚则录成横向滚**——录键盘是按一下，录滚轮就是滚一下，不用记写法（也可双击手输 `WheelUp` / `WheelDown`）。**只是单纯滚动/点击的话，用下面的「鼠标」步骤更直接**（下拉选，不用记写法）。手输可用 `LeftClick` / `DoubleClick` / `RightClick` / `MiddleClick` / `MouseBack` / `MouseForward`。 滚轮只能发、不能绑成全局热键（系统的热键注册表达不了滚轮）。 |
| **鼠标** | 一个下拉管全部鼠标动作：**滚动**（上 / 下 / 左 / 右，一次一格）、**点击**（左键单击 / 左键双击 / 右键单击 / 中键单击）、**侧键**（后退 / 前进）。要点 N 次 / 滚 N 格就把「重复次数」调大，用「执行后延时」控制节奏（如 5 次 × 50ms）。<br>横向滚发的是真正的横向滚轮事件（`HWHEEL`），比 `Shift+滚轮` 那种土办法兼容性好，宽表格 / 甘特图 / 时间轴用得上。<br>**位置规则不同，务必分清：** 滚动发给**鼠标指针下**的窗口（Windows 的「悬停时滚动非活动窗口」设置决定，Win10/11 默认开；关掉则发给前台窗口）；**点击落在鼠标当前所在的位置**——本程序不会去挪指针（挪指针要处理绝对/相对坐标、多屏与 DPI 缩放，还会打断你手上的操作）。所以点击类动作要么先用「窗口动作 → 带到最前面」把目标摆好、并确保指针已在该在的地方，要么只用在**后退 / 前进**这种与位置无关的动作上。<br>键盘能做的优先用键盘：滚动用「发送按键」发 `PageDown`、后退用 `Alt+←`，都比鼠标稳；只认鼠标的地方（地图、看图软件、Electron 长列表、CAD）才需要它。 |
| **发送文本** | 往当前焦点窗口逐字输入一段文本（换行 = 回车、Tab 生效）；可选「目标进程」（右边 **…** 可挑）——填了先把它的窗口带到最前再输入，留空则发给当前焦点窗口。**输入法开着也不受影响**：文本按 Unicode 直接送进目标窗口，不经键盘布局、不会被拼音候选框吃掉，中文、重音字母、emoji 一视同仁。 |
| **音量** | 静音 / 取消静音 / 设为音量（设音量会先自动取消静音）/ **麦克风静音 / 麦克风取消静音**（关的是系统默认录音设备本身，比会议软件自带的静音更彻底——所有软件都收不到你的声音）。 |
| **窗口动作** | 按进程名（右边 **…** 可挑，带搜索）关闭 / 最小化 / 最大化 / **置顶** / 带到最前面 / 置前并发送按键 / **回到刚才那个窗口**。**置顶是开关**——同一步再执行一次就取消，所以一条手势管「钉住」和「放开」两件事。**它按窗口分别记**：钉住 A 之后点到 B、再触发一次是钉住 B，要放开 A 得先让 A 回到前台。它不抢前台，因为你要钉的常常是副窗口（参考文档、播放器），抢一次前台就把你正在打字的那个顶掉了。**进程名填 `*` = 当前窗口**，也就是你画手势、点面板格子之前正用着的那一个——手势尤其需要它，右键划在哪个窗口上动作就该落在哪个窗口，事先根本没有进程名可填（前台是 Clockwork 自己时不动手，否则在主界面点「运行」试跑一条「关闭当前窗口」，关掉的会是 Clockwork）；慢启动应用可设「等窗口出现最多 N 秒」，窗口一出现才动手、不盲等固定延时。**「回到刚才那个窗口」不选目标**：它回的是你触发这条动作那一刻正用着的那个窗口，摆在一串窗口步骤的末尾用——上面每一个动作都要先抢一次前台才动手，所以一条「最小化 Slack、最小化 Discord」跑完，焦点落在哪儿全看 Windows 的心情，而你想回去的是按下那一刻的地方。触发时前台如果是 Clockwork 自己（在编辑器里点「运行这一步」试跑就是这种情况），它会如实说没有可回去的窗口。<br>只认**真正的应用窗口**——进程的隐藏辅助窗口（任务栏、桌面、各种后台壳窗口）会被排除，所以「关闭 explorer」不会误伤任务栏。动作发出后还会**复核有没有真的生效**，没生效如实报告（并与「压根没找到窗口」分开措辞：前者该查是不是被前台锁定/提权窗口/未保存对话框挡住，后者该查进程为什么没起来）。 |
| **打开网址** | 只有一个地址框。它从「运行程序」里拆出来——那个框的说明写着「程序 / 快捷方式 / 脚本 / 文件夹 / 网址 / 文档」，想打开一个网页的人得先在六种东西里认出自己那一档。<br>地址里可以写 `{名字}` 占位，运行时换成对应的值并自动转义（见下面「把几步串成一个动作」）。程序路径里**不做**这个替换——那是注入面。|
| **获取选中的文字** | 替你按一次复制键，把选中的文字取到剪贴板，供后面的步骤用 `{clipboard}` 取用；也可以顺便**输出到一个变量**。用的是和「搜索选中的文字」同一台机器：剪贴板版本号判定、终端里换一套复制键、取不到时报出进程名和键名。|
| **用户输入** | 弹一个框问一句，把你打进去的那段文字**输出到变量**。提示语就是框上那句话；默认值可留可不留（预填好、全选，想改直接敲，想用回车即走）。按 Esc / 取消 = 这一组别做了，后面的步骤全停——不是「给个空答案接着跑」，因为后面多半正等着那个值。空着回车**不算取消**：那是「这一项我就是要留空」。|
| **用户选择** | 同上，只是把输入框换成一个列表：选项一行一个，运行到这一步时列出来让你挑一个，选中那一行进变量。双击一项 = 选它并确定。一个选项都没配时如实说一声并跳过，而不是弹一个点不动的空框。|
| **等剪贴板变化** | 等到剪贴板被改动，或等满设定的秒数（1–60）。超时**不算失败**——等到了就往下走，没等到也往下走，只是如实说一声。|
| **系统命令** | 显示桌面 / 锁屏（回来需输密码）/ 息屏（只关屏幕，动鼠标即亮）/ 清空回收站 / 清空剪贴板 / **设置剪贴板文本** / **搜索选中的文字** / **播放声音** / 打开 Windows 设置 / 打开任务管理器 / 截图 / **显示器：仅电脑屏幕·复制·扩展·仅第二屏幕** / **关闭通知（免打扰）· 打开通知** / **屏幕亮度** / 睡眠（秒醒）/ 休眠（断电保存）/ 注销 / 重启 / 关机（后三项执行前需确认）。四条带参数，选中命令时才出现：「设置剪贴板文本」多一个文本框，「播放声音」多一个文件路径框（**留空 = 系统提示音**，跟随你的 Windows 声音方案；填了就放那个 `.wav`。只认 wav，别的格式用「启动程序」指向它、交给系统的播放器。声音是异步放的，不会把动作卡在这一步），「屏幕亮度」多一个 0–100 的数值框，「搜索选中的文字」多一个**搜索引擎**下拉：Bing / Google / 百度 / DuckDuckGo / Yandex / Naver，默认 Bing；选「自定义…」才会露出地址框，`{0}` 写在被搜的词该出现的位置。<br>「搜索选中的文字」替你按一次 `Ctrl+C` 再拿剪贴板里的内容去搜——「选中了什么」没有 API 可问，只能这么取，**代价是剪贴板会被覆盖**。没选中东西时它不会开一个空搜索页，而是如实告诉你没选中。<br>**在终端窗口上换一套复制键**（cmd / PowerShell / Windows Terminal / conhost / mintty / ConEmu 等）：那些地方 `Ctrl+C` 是「中断当前命令」而不是复制，照发下去只想搜个词却把正在跑的 `npm install` 打断了。所以按顺序试 **`Ctrl+Insert` → `Ctrl+Shift+C` → `Ctrl+C`**，第一下成了就不试后面的。前两个在任何终端里都只会复制、绝不中断，默认配置下必定命中；`Ctrl+C` 排在最后是被实测逼出来的——**Windows Terminal 的默认键位表里 `Ctrl+C` 根本没绑复制**，于是很多人自己改成了它，而那种配置会盖掉默认的前两个键。代价说清楚：在终端里**什么都没选中**还画了这条手势时，最后那一下会中断一次正在跑的命令。内嵌终端的宿主（VS Code、Visual Studio）**有意留在 `Ctrl+C`**——按进程名分不开焦点在编辑区还是终端面板。<br>等剪贴板的上限是 1 秒：复制成功就立刻继续，只有真的没复制到才会等满再报错。复杂网页和 PDF 阅读器写剪贴板可能要几百毫秒（Quicker 的故障排除文档专门列了这一条）。 |
| **消息** | 弹一句话。两种呈现：**对话框**（要点掉，可选「是/否确认」并在点是后做事）或**卡片**（右下角滑入、不打断，按秒数自动关，0 = 留到你点掉）。**启动清单里只有卡片形态会弹**——开机时弹对话框会把整条清单卡住，所以对话框形态在清单里被静默跳过。消息步骤恒定只弹一次，没有「重复次数」。详见下面「动作」章节。 |
| **延时** | 单纯等待 N 秒再继续下一步；放清单最前面可整体推迟启动。 |
| **动作** | 引用一个已定义好的动作；设「重复次数」即可把整组动作循环 N 遍。 |

> **几条注意事项**
> - **显示器切换**走系统自带的 `DisplaySwitch.exe`，和按 Win+P 选一项完全等价；切换要一两秒才落定，后面紧跟别的步骤记得留点延时。
> - **关闭通知**关的是 Windows 的通知总开关（对应设置里「从应用和其他发送者获取通知」），不是 Win11 的「专注 / 勿扰」——后者没有可写的公开开关。它**不会自己恢复**，务必配一条「打开通知」收尾，内置模板「恢复常态」就是干这个的。
> - **屏幕亮度**只对系统能调的显示器有效（笔记本内屏、部分一体机）；外接显示器走的是另一套协议，调不到，会如实报错而不是假装成功。这一步内部调一次 PowerShell，约半秒到一秒。
> - **`.ps1` 用哪个 PowerShell 是自动挑的。** 脚本存成现在最常见的「无 BOM UTF-8」且含中文时，系统自带的 Windows PowerShell 5.1 会按系统代码页去解码，整个脚本在解析阶段就崩、一行都执行不到；这种脚本会自动改用 PowerShell 7。没装 PowerShell 7 时会明确提示（装它，或把脚本另存为带 BOM 的 UTF-8），而不是丢一个退出码给你。老的 ANSI/GBK 脚本仍照旧交给 5.1——它们在 5.1 下本来就是对的。另外 `.ps1` 要填**完整路径**，裸文件名 PowerShell 找不到。
> - **睡眠 / 休眠不会假装成功。** 这两个状态可能被驱动或组策略禁用（命令行 `powercfg /a` 可查）；禁用时这一步会如实报错，而不是记成已完成、让电脑整夜醒着。

### 执行条件（每一步都能设）

不满足就跳过这一步，整条清单接着往下走。条件之间是**「且」**——都设了就得都满足。

| 条件 | 说明 |
| --- | --- |
| **仅这些星期** | 一个都不勾 = 每天。 |
| **仅 N 前 / 仅 N 后** | 各自可填 `HH:mm`（只填小时也认）。两条一起用就是一个区间：「仅 09:00 后」+「仅 18:00 前」= 只在上班时段执行。 |
| **进程条件** | 选「该进程在运行 / 该进程没运行」并填进程名（右边 **…** 可挑）。典型用法：游戏在跑时才静音 IM；备份软件没跑时才开始备份。 |
| **电源条件** | 仅接电源时 / 仅用电池时。拔了电源就别跑重活。台式机读不到电池，一律按「接着电源」处理。 |
| **路径存在** | 填了则仅当该文件 / 文件夹存在时才执行——U 盘插上了才备份、报告导出了才发邮件。文件夹也算存在。与「目标」框认同一套写法：带引号的路径、`%USERPROFILE%` 这类环境变量都行。 |

> 条件会写进列表的**摘要**列（`（周一二三）`、`（仅18:00后）`、`（Slack 在运行）`、`（用电池）`、`（存在 E:\backup）`）——一步没跑时，那一列就是唯一的线索，不必开编辑器猜。

### 开机延迟

在「设置」页的「开机延迟 N 秒」框，**仅开机自启时生效**。登录后先固定等这么多秒，让「登录风暴」（磁盘 / CPU 被一堆自启抢占）过峰，再跑清单；手动「重新运行」不受影响。开机太早、有软件没起来就把它调大（0–600 秒）。这是整体延时的**唯一旋钮**；只想让某一步慢一点则用那步的「执行后延时」。

### 清单跑坏了怎么办

有两样东西专为「清单干了你不想要的事」这种情况准备。

**开机时有步骤失败会告诉你。** 每次运行都会在配置旁写一份 `clockwork.run.log`（托盘 →「查看上次启动日志」），但开机那一次没人盯着屏幕，所以失败现在还会弹一张卡片：「共 12 步，3 步失败」。跑得干净就一声不响——只有出现失败、撞上步数上限或被叫停时才弹。这一次恰恰是你最看不到、也最值得被告知的一次运行。

**你可以让清单干脆别跑。** 清单里只要有一步会抢焦点、锁屏或注销，每次登录就都是同一场埋伏，而要修它得先进得去。两条退路，对应两种处境：

- **登录时按住 Shift。** 用在你已经进不去的时候——那会儿唯一还能用的输入就是键盘。它只跳过这一次开机，下次照常运行。
- **在 `clockwork.settings.json` 旁边建一个名叫 `clockwork.disable-startup` 的空文件。** 用在你还进得了桌面、只是想让清单先别跑的时候——比如正在调某一步，或者今天不想开那一堆软件。它一直有效直到你删掉它，每次开机的卡片上都会说明这一点并写出完整路径。

两条路都不影响程序照常起到托盘，所以想验证改好了没有，「重新运行启动清单」就在手边。

### 随时叫停

三个入口，做的事完全一样：窗口标签条右端的**急停按钮**，托盘右键 → **「停止正在运行的动作」**，或按全局**急停键**（在「设置」页设置；默认 `Ctrl+Alt+Q`）。正在跑的启动清单 / 动作 / 单步会在当前动作做完后立刻停下（循环设多了不用干等）；开机延迟、等窗口出现等长等待也会被立即打断。日志如实记录「已手动停止」。热键被别的程序占用而注册失败时会弹托盘气泡提醒（此时用按钮或托盘菜单的「停止」兜底）。

> 急停按钮**只在真有东西在跑的时候才存在**——这正是它的用意：它出现就说明有动作在跑，它消失就说明真的停下来了。悬停可看到当前急停键。

> **只想停某一个动作**：再按一次**那个组自己的热键**（见「动作 → 热键是开关」）。急停是总闸，会把启动清单和所有在跑的组一起停掉。
> 注意这条只对**绑了热键的组**成立——由定时任务的静默组 / 「点是后」/ 被别的组引用而跑起来的组，若本身没绑热键，就没有单独取消的入口，只能用急停。想让某个长时间运行的无人值守组可随时叫停，就给它单独绑一个热键。

> 想「等网络 / 桌面就绪再跑」而非固定干等，勾设置页的 **「等系统就绪再跑」**（以前只能手改 json 里的 `startupWaitForReady`）：就绪即走、最多等 90 秒，然后再叠加上面的固定延迟。开机太早、软件起不来时开它，比一味调大延迟更准。

## 定时任务

- 每条任务到点后二选一：**弹窗提醒**（文本 / 语音 / 点「是」后动作）或**静默运行动作**（不弹窗，直接跑）。
- **触发：** 定时（到点）、**登录时**（可设「仅开机 N 分钟内」才算登录——新建默认 10 分钟），或下面 7 种**事件**。
- **周期：** 按星期 / 每 N 天 / 每月某号；提醒可朗读。

### 事件触发

不看钟表，看机器身上发生了什么；条件一成立立刻执行，动作与定时任务完全一样（弹窗提醒 / 朗读 / 点是后做事 / 静默跑动作）。

| 事件 | 什么时候发生 |
| --- | --- |
| **空闲时** | 连续没有键鼠操作满 N 分钟（默认 10）。**一次离开只触发一次**，人回来后重新计时。 |
| **连续使用时** | 空闲的镜像：一直没歇地用满 N 分钟（默认 30）——就是那条「起来活动一下」的提醒。**一轮只触发一次**，离开键盘满一分钟即重新计时。 |
| **解锁时 / 锁屏时** | Win+L 锁屏、以及回来解锁的那一刻。切换用户、远程连断不算——那是另一件事。 |
| **睡眠唤醒时** | 合盖 / 睡眠之后重新醒来。适合「唤醒后重连 VPN」这类收拾现场的活。 |
| **接上电源时 / 拔掉电源时** | 插拔充电器的那一下。「拔电源→切省电」这种最典型。 |
| **电量偏低时** | 用电池且电量跌破 N%（默认 20）。**跌破只触发一次**，充回阈值以上或插上电源才会再次生效。 |
| **显示器变化时** | 插拔外接屏、改分辨率、切换投影模式。配上「显示模式」系统命令，插拔扩展屏就成了一套现成的流程。它只说「变了」，不说往哪边变——接上和拔掉在这里长得一样，要分开处理就在步骤上加进程条件或路径条件。 |
| **网络接通时 / 网络断开时** | 这台机器重新有可用网络了，或刚刚失去网络。「睡眠唤醒时」只能近似地代劳的那些重连活，这才是它们准确的触发点——等网络真的通了再挂网络盘，而不是开盖后 200 毫秒就动手。 |
| **U 盘插入时** | 有卷挂上来了。插上就备份，不必去轮询盘符是否出现。多分区的 U 盘只触发一次，不会一个分区一次。 |

- **星期限制照样有效**（「工作日解锁时打卡」），编辑器里那排星期不会隐藏。
- 「宽限」「错过必补」对事件**没有意义**，会自动隐藏：事件是发生即触发，机器不在就根本没发生过，没有需要补的东西。
- 「稍后」「重复催促」「循环运行」照常可用——事件响过之后的续接和定时任务走的是同一套。
- 「暂停提醒（勿扰）」期间事件同样不触发，与定时任务一个待遇。
- 空闲、连续使用与电量是**轮询**出来的（搭提醒计时器的车，默认 30 秒一轮），所以可能比设定值晚半分钟；锁屏 / 解锁 / 唤醒 / 插拔电源 / 显示器变化 / 网络通断 / U 盘插入都是系统直接通知的，即时。
- **全屏游戏和演示中不会被提醒打断。** Windows 报告屏幕正忙时（独占全屏游戏、全屏应用、投影模式），本该上屏的提醒会安静地往后推 5 分钟再试，全屏挂多久就推多久。不丢、也没有次数上限：出了全屏就看到它。两个例外仍照常弹，因为对它们来说「别打断」是错的答案——**静默动作**（它根本不上屏，没有可打断的东西）和托盘的**快速提醒**（那个计时器是你几分钟前亲手设的，「你说 5 分钟」高于这份礼貌）。这和你自己开关的**暂停提醒**是两回事；Windows 的专注助手刻意没有接进来——两套互相看不见的勿扰，是最难查清的一种静音。
- **循环运行**：设「每隔 N 分钟一次，直到 HH:mm」（留空 = 当天结束）。与「未确认时催促」是两码事——催促是没人理才再喊、点确认就停；循环是到点就跑、确认了下一轮照跑。循环不跨午夜，次日由当天首次触发重新开始。
- **今天不再**：右键那一行 →「**今天不再**」（**再点一次即撤销**）。跳过后时间列会显示成「22:00 · 今天跳过」——做的地方在右键菜单，看的地方在行上，不用记自己点没点过。当天剩下的这条全部作废（含在途的催促、循环和「稍后」），明天照常。三种触发（定时 / 登录时 / 事件）口径一致。它比「取消勾选」安全——取消勾选没有到期日，忘了打开就是一条永久静默失效的提醒。跳过状态会落盘，重启也不会白跳。
- **快速提醒**：托盘右键 →「**快速提醒**」→ 5 / 15 / 25 / 30 / 60 分钟。误差不超过一轮心跳（默认 30 秒）且绝不提前；正在「暂停提醒」时会明确告诉你要等勿扰结束才响，而不是假装已经排好。当场建一条一次性提醒，**它会出现在本页列表里**（改主意就直接删掉），自带提示音、常驻卡片（不点不消失），**响过就自己从列表里删掉**——临时计时器不该在配置里留下死行。想要别的时长就在这一页正常建一条。那一分钟恰好撞上勿扰或睡眠时会补响（不是丢掉）；真跨了天没响成，下次启动会把这条过期的清掉，不留死行。
- **仅一次**：周期选「仅一次」并指定日期。触发完成后条目自动取消勾选但保留在列表里——想再用改个日期重新勾上即可。
- **声音**：编辑器里一个「声音」下拉，四选一——**不出声 / 提示音（叮一声）/ 语音播报（念出内容）/ 提示音 + 语音播报**。提示音是系统的「星号」音，只为让你抬一下头；语音播报会把提醒内容整句念出来。两者都选时提示音先响、随后才开口（否则「叮」会盖在第一个字上）。卡片不抢焦点也不置顶，你在看另一块屏幕时，声音往往是唯一会被察觉的部分。跟随你的 Windows 声音方案，静音方案下自然不响；静默动作不出声（那正是「静默」的意思）。新装的样例默认带提示音，升级上来的存量提醒保持原样不动。
- 没配动作的提醒 → 走右下角**提醒卡片**（不置顶抢视线）；显示多久由「自动关闭」秒数决定，**0 = 不自动关、常驻到你点掉为止**——离屏一会儿也不会错过。重复催促型仍用弹窗，好一键停催。
- 配了「点是后」动作（运行程序 / 打开文件 / 开网页 / 跑动作）→ 弹置顶 **「是 / 否」** 窗，还有「稍后」可打个盹（默认 10 分钟，旁边 ▾ 可选 5 / 10 / 15 / 30 / 60 分钟）。回车＝「是」照旧；弹出后的头 0.6 秒内「是」不响应——正在打字时被夺走焦点，一个在途的空格 / 回车不会把动作误跑了。
- **没人应答的弹窗会自己让路：** 弹窗是模态的，一直挂着会挡住后面所有提醒。没设「自动关闭」的弹窗最多停留 1 分钟；到点没人应答就自动当作「**稍后 10 分钟**」，过会儿重新弹——队伍不堵，也绝不静默丢失（这个「稍后」和手点的一样落盘，中途重启也不丢；跨天自动作废，开了「**错过必补**」的例外：次日补弹一次）。配了重复催促的仍按你设的节奏催。连着 **6 轮**都没人应答，就不再弹窗打扰，改成右下角**常驻卡片**挂着等你回来——人不在时对着空屏幕反复弹没有意义。注意卡片上没有「是/否」：降级后「点是后」的动作不会再跑。手点的「稍后」不算在这 6 轮里，还会把已累计的轮数清零——人在场，重新起算。封的是**轮数**不是时长：默认设置下 6 轮约 1 小时，但你若把「自动关闭」设成很大的值（比如 1800 秒），每轮还要先挂那么久的窗，总时长会成倍拉长。
- **同一条提醒重复触发只占一张卡片**（眉标右端标 `×N`），不会把右下角堆满。点掉 / 挤掉 / 自动消失的卡片，连同弹窗形态的提醒（无人应答的标成警示色），都能在托盘右键 →「**最近通知**」里回看并重弹（会话级，重启即清）。
- **进阶：** 自动关闭 · 重复催促（没确认就每 N 分钟再弹，直到某时刻；「直到」留空则最多催 20 次）· 到点后延迟 + 随机延迟 · 宽限（到点时恰好关机 / 睡眠，N 分钟内补弹）· **错过必补**（休眠 / 关机把提醒整段错过时，下次程序在跑就补弹一次）· 「每 N 天」的**起算日**（点 **…** 选日期；留空则保存时钉为今天，从那天起每 N 天一次）。
- **状态落盘：** 「当天已提醒过」「稍后到几点」记在 `clockwork.state.json`，重启程序也不丢——打的盹跨过重启仍会响，同一条提醒一天也不会重复弹。循环运行的进度也是同样落盘，中途重启不丢当天剩余轮次。
- **几个跨午夜 / 长待机的边角，都按「不多不少响一次」处理：** 时刻很晚的提醒（如 23:59）即使实际弹出已经过了零点，记的仍是它**该响的那一天**，次日照常再响，不会退化成隔天一次；催促链睡过了自己的截止时刻就此结束，不会在次日早上复活、接着催一上午；系统时间被改乱（虚拟机还原、主板电池没电）时留下的荒谬未来时刻会被当脏数据丢弃，不会把一条提醒永久卡死到只能手删状态文件。
- **勿扰：** 托盘右键 **「暂停提醒 ▸」** → 1 / 2 / 4 / 8 小时，或「**到今天结束**」（这一列里唯一不用自己算的一项——今天在出差 / 在录屏 / 在开会），期间所有提醒（含静默动作）都不触发，到时自动恢复，也可随时点「恢复提醒」；错过的按宽限 / 错过必补的正常规则处理。
- **静默动作：** 到点不弹窗、直接跑指定动作。选中任务按「运行」立即运行一次——注意：静默任务的「运行」会**真的执行**那个动作。
- **列表两列写的是什么：** 「登录时」触发的任务，周期列显示「**每次登录**」（它根本不看星期 / 每月这类周期，所以编辑器里那一块也一并隐藏）；**静默**任务的文本列显示它跑的是哪个组，而不是留一格空白。
- **「复制」** 在选中任务下方克隆一份（文案与设置照搬、运行状态独立）——「同一条任务、一天提醒两次」这种需求，复制后只改时间即可。

## 动作

- **「新增」** 直接开一个空动作。想照着现成的改，用旁边的 **「从模板…」**：内置模板（专注模式 / 会议模式 / 恢复正常 / 下班 / 睡前 / 离开一下 / 久坐提醒 / 快速搜索）选一个，改成自己的软件再保存。
  - **「恢复常态」是配套的开关出口**：关通知、麦克风静音都是有状态的，不会自己恢复。专注 / 会议都会关掉一些东西，用完点一次「恢复常态」（或绑个热键）把它们开回来。
- 列表现在会显示每个组的**动作摘要**与**热键**两列（空组的摘要显示「（空）」）。
- 同一组同时只会跑一份，重复触发自动跳过（热键除外——见下面的「再按一次 = 取消」）。
- 四种触发：托盘 **「运行：某组」** · **全局热键** · 启动清单里加「动作」步骤（开机跑）· 定时任务挂「点是后 / 静默动作」（定时跑）。另外在动作页选中一行按 **「运行」** 可随时手动跑一次。
- **「在托盘菜单显示」**（组编辑器里，**新建的组默认不勾**）：组一多，托盘菜单就被撑成长条；而多数组是靠热键 / 提醒 / 被别的组引用触发的，不必占一行。没勾的组照样能用——热键、提醒、引用、以及动作页的「运行」按钮都不受影响，只是不出现在托盘里。升级前就有的组会保持原样显示，不会突然消失。
- **全局热键：** 在组编辑器里点热键框、按下组合（如 `Ctrl+Alt+F`），之后不开菜单、在任何程序里按键即跑该组。Esc 取消、Del 清空；改动即时生效、无需重启。**禁用**的组会让出组合给别的组用。以下会被拒并提示：**系统保留**组合（Alt+F4、Alt+Tab、Ctrl+Shift+Esc……）、已被**其它启用组**或**急停键**占用、以及**被别的程序占用**（换一个组合即可）。
- **热键是开关——再按一次 = 取消。** 组还在跑时再按同一个热键，就取消**这一次运行**：剩余步骤和后续轮次都不再执行，托盘弹一条「已请求取消动作「某组」」的回执。取消只管这一组，**启动清单和别的组照跑**（要停一切请用急停键）。几点实际影响：
  - 多数组几百毫秒就跑完了，那时再按等于**重新跑一次**——「取消」只对还在跑的组（带延时 / 循环轮次的那种）有意义。
  - 轮间延时、步骤间延时会被**当场打断**，不用等这一觉睡完。
  - 组正卡在**「消息」确认框**上时按取消：弹窗要你点掉才会消失，但那个答案会作废——点「是」也不会再跑 onYes 分支，整组就此停下。
  - 组 A 引用了组 B，B 正在跑时按 **B 的热键**：取消的是**这一整次运行**（A 也一并收手）——只停 B 让 A 接着往下走，会留下一个执行到一半的现场，比不取消更难收拾。
- 组里的「消息」步骤可当**确认闸门**：答「否」中止整组（比如收工前问「记录好了吗？」）。
- **呈现方式：** 消息步骤可以选**对话框（需点掉）**（默认，效果同上）或**卡片（不打断）**——卡片从右下角滑入，按你设的秒数**自动关闭**（**0 = 一直留到你点掉**），组不等你回应就照常往下跑。切到卡片形态会隐藏并清空「是/否确认」与「点是后」两个字段，因为卡片唯一的交互就是点掉它。卡片也是唯一能从**启动清单**里弹出来的消息形态——开机时弹对话框会把整条清单卡住，所以对话框形态的消息步骤在启动清单里会被静默跳过。
- 动作编辑器里，**拖动一个步骤即可调整顺序**——和三个列表页一样，每行最左边有拖动手柄（≡）；上移 / 下移按钮也照样能用。
- **「复制」** 把选中组克隆为「…（副本）」，改出一个变体很快。副本**不带热键**（同一组合键不能被两个组占用），需要的话另设一个。
- 删除**被引用**的组（被定时任务的「点是后」/「静默动作」，或某个「动作」步骤引用）时，会告知共有多少处引用并一并清理，不会留下指向已删组的悬空引用。

### 保存前先试跑一遍

动作编辑器里有两个运行按钮，跑的都是**编辑器里此刻的内容**，不是上一次保存的版本——改完一步不用先保存就能试。

- **▶ 运行这一步** 只跑选中的这一行。如果选中的正好是一个「动作」引用步骤，跑的是该组**已保存**的版本，不会带上你在别处对那个子组做的未保存改动。
- **▶ 运行整组** 从头到尾整组跑一遍，和真实触发一样——延时、重复次数、星期 / N 点前这些条件都照样生效，星期条件不对的步骤在周末试跑照样会被跳过。

整组运行期间，**▶ 运行整组** 按钮会变成 **■ 停止**；关掉动作编辑器窗口也会让它停下来。运行途中弹出的确认框（比如消息步骤）会显示在编辑器窗口前面，而不是被挡在后面。

### 把几步串成一个动作

**能产出值的步骤有一个「输出到变量」，后面的步骤在文本里用 `{名字}` 引用它。** 就这一条规矩。

产出值的有三种：**用户输入**、**用户选择**、**获取选中的文字**。能引用变量的是「送出去的文字」：
打开网址的地址、发送文本的内容、系统命令的文本参数。程序路径和参数里**不替换**——那是注入面。

于是「选中什么就翻译什么」是两步：

1. **获取选中的文字**
2. **打开网址** `https://www.deepl.com/translator#auto/zh/{clipboard}`

而「问我搜什么，再去搜」也是两步：

1. **用户输入**，提示语「搜什么？」，输出到变量 `关键词`
2. **打开网址** `https://www.bing.com/search?q={关键词}`

把它绑一条手势或一格面板，随时一划就弹框、一回车就出结果。

几条要知道的：

- **`{clipboard}` 是唯一的内置名**，读的是此刻真实的剪贴板，不需要哪一步先产出它——别的程序刚复制的东西也算。
- **名字不区分大小写**，两边的空格也不算数（`{ 关键词 }` 和 `{关键词}` 是同一个）。
- **写错名字会看得见**：查不到的名字**原样留在**地址里，你一眼就知道是哪个词没生效。而一个**存在但为空**的变量换成空串——那不是写错，是那一步真的没取到东西。
- **作用域是「这一次运行」**：一次触发（含它引用的子动作）共用一份，跑完就没。没有全局变量、不落盘、不跨动作。
- **一律是字符串**，没有类型、没有表达式。
- **开机清单里不能问**：那条路是无人值守跑的，问句步骤会被跳过并如实记一条——登录时弹一个拦住整条清单的输入框，不是任何人想要的。

### 从外部触发一个动作

凡是能启动一个程序的地方，现在都能跑一个组：

```
Clockwork.exe --run-group "专注"
Clockwork.exe --run-group=专注
```

名字大小写不敏感、首尾空格自动去掉，也可以直接给组的 **id**。名字里有空格就加引号，和任何命令行一样。

计划任务、桌面快捷方式、Stream Deck 的某个键、AutoHotkey 的某个绑定，都可以指过来。如果 Clockwork 已经在托盘里，请求会交给那一份，启动的这个进程立刻退出——它**不会**顺带把设置窗口弹出来，那对一个本该半夜静默运行的组来说是个莫名其妙的副作用。如果还没有实例在跑，这个进程就成为托盘实例并自己执行该组，然后像正常启动那样常驻。

跑不成会告诉你：名字不存在、或者那个组被停用了，都会弹一张点名的卡片，而不是悄无声息，让你回头去调一条本来就没问题的命令行。转交请求的那个进程若投递失败也会返回非零退出码，脚本里判得到。

## 快捷面板

鼠标所在处的一片瓦片网格，一个键就出来——省得手已经在屏幕中间，还要跑去够角落里那个托盘图标。

- **按面板热键**（默认 `Ctrl+Alt+Space`，在「设置」页改——那个框里 Esc 取消、**Del 清空**，清空后靠中键长按和托盘入口打开），面板出现在指针位置。再按一次、按 **Esc**、或者点到别处，它就消失。
- **页是你自己建的一样东西，不是某个动作的副业。** 在**面板管理器**里点左栏末尾的 **+**，当场落下一张卡，名字正等着改，并且**归进你当时正看着的那一类**；往里放东西点空位即可。顶栏末尾还有一颗 **+**，那是新建分类的——它**只建一类，不连带建页**，建完左栏是空的，点那颗 + 放第一页进去。页有名字、分类、绑哪个程序，全在页眉那一条上就地改，没有另一扇设置窗。
  - **页和动作是两样东西。** 动作是「一串操作 + 怎么触发（热键 / 托盘 / 被引用）」，页是「一屏格子 + 什么时候出现（分类 / 场景）」。两者没有共同的属性，所以不再共用一个存储对象 —— 从旧版升上来的配置会自动搬过去，动过什么会在启动时报给你看。
  - **每种步骤类型都能当格子用** —— 运行程序、打开网址、发送按键、鼠标、发送文本、音量、窗口操作、系统命令、运行动作、延时、消息……一格执行那一个操作，与步骤旁边那个「运行」按钮走的是同一条路。
  - **想要一格「跑一整个动作」？** 往页里加一条**运行动作**步骤指过去就是了 —— 那本来就是那个步骤类型的用途。于是「专注 / 收工」这种整套例程，和锁屏、静音这种单个操作，可以并排摆在同一页上。那一格没设图标时，用被指的那个动作的图标。
  - 页与页的顺序拖页签就能改，页内拖格子就能改。
- **停用的格子是置灰而不是不显示** —— 「它被关掉了」和「它没了」这两件事得分得清。
- **再加上你本来就常按的那几样**，用分隔线隔在下面，不会和你自己的动作混在一起：重新运行启动清单、停止正在运行的动作、暂停 / 恢复提醒、打开窗口。
- **鼠标键盘都行。** 点一格，或者方向键选中后回车——焦点默认就落在第一格，全程不碰鼠标也能用。
- **它先关自己，再跑动作。** 会切前台、会发按键的动作需要先把前台还回去；留着一个置顶面板挡在那儿，按键会打到面板上，刚激活的窗口又被面板压住。
- **也可以长按鼠标中键。** 在「设置」页勾上，按住约 350 毫秒（可调）即弹出面板 —— 完全不用键盘，而面板就出现在手已经在的地方。
  - **普通中键点击照常可用。** 按下去的那一瞬间还无从知道这是点击还是长按，所以按下会被先扣住；你要是早早松手，就补发一次真正的中键。中键开新标签、粘贴、自动滚动，一切照旧。
  - **中键拖拽也还在**：按住之后移动即判为拖拽，扣住的那次按下会原样交给下面的程序，面板不出现。
  - **松手才弹面板**，不是按到时长就弹。按着键没法点格子，松手即弹意味着面板就位时指针已经在它旁边了。
  - **默认关闭**，因为它要装一个全局鼠标钩子 —— 这种东西该是你明知道地打开，而不是跟着一次升级默默继承下来。万一 Windows 不让装（安全软件、组策略），会弹卡片说明，而不是留下一个悄无声息不存在的功能。
  - 普通点击开始误弹面板就把时长调大，按着觉得迟钝就调小。范围夹在 150–2000 毫秒 —— 再低的话，稍慢一点的点击就会被当成长按，中键会变得不好点。
- **托盘菜单里也有入口**，所以清空热键关掉的是那个快捷键，不是这个功能。
- **要关掉功能本身**，取消「设置」页的「**使用快捷面板**」。热键、中键长按、托盘入口一起停，
  而且——这才是这个开关的意义——一个鼠标钩子都不装。
- **面板以指针为中心弹出** —— 每一格到指针的距离都一样短，而不是让最远那个角比最近的远上三倍。靠近屏幕边缘时它只往回让到刚好完整落在指针所在的那块屏幕上，混合 DPI 的多显示器同样成立。
- **格子是图标在上、文字在下。** 图标一眼说明这是哪一类东西 —— 运行程序、按键、音量、窗口、系统命令 —— 这是那么窄的一行文字做不到的。图标取自 Windows 自带的字体，不增加体积，任何缩放下都清晰。
- **每个格子都记着自己被按过多少次。** 计数认的是步骤自己的身份、不是它占的那个格子，所以给格子改名、拖到另一页、甚至删掉再建一个同名的，计数都跟着走。打开**面板管理器**，每个格子上的角标和悬停提示里都有这个数；页脚的**「清空点击统计」** —— 只在真有数据时才出现 —— 把它们一次清掉。
  - **它不会改变面板显示什么。** 没有任何格子会因为点击数被重排、被隐藏或被顶到前面：这是「你常按什么」的记录，不是「你该按什么」的建议。
  - **计数与设置分开存放**，在 `clockwork.usage.json` 里：点击发生的那一刻就得记下来，而保存设置要重绑全部热键、重装鼠标钩子 —— 一个计数器不该付那笔代价，尤其不该在你正连点的时候付。丢一次也无所谓，所以它没有重试队列。
  - **清空会先问一句**，因为那份历史是这个文件里唯一没有第二份的东西。它只动计数 —— 不碰设置，也不碰格子。

### 分页

页跟着内容走，而不是按格子数机械切：**每一页都是你自己建、自己命名的。** 所以你翻的是「常用」「开发」这样的页，而不是「第 2 页 / 共 4 页」。一页装不下时才按容量续到下一屏，续屏沿用同一个页名 —— 那是容量问题，不是内容问题。

**两条栏：上边选分类，左边列这一类里的页。** 分类就是你给页起的一个归类名（「写代码」「下班」），
默认不填 —— 不填的页都在「未分类」那一格里，那也是绝大多数人一直看到的样子。
页只有一个落点（左栏），所以不存在「这一页到底在哪条栏上」这个问题。

- **只有一类时不画分类栏**，当前这一类只有一页时不画页签栏（那时它只会把名字重复一遍）。
  面板管理器的外观栏里各有一个勾，用来在有好几个时也**强制隐藏**其中一条。
- **腰栏那排圆点管的是另一件事**：一页装不下时会切成几屏，圆点表示「这一页的第几屏」。
  页签回答「哪一页」，圆点回答「第几屏」——两条栏都关掉时，圆点才退回表示「哪一页」，
  否则关掉页签等于把翻页入口一起关掉了。
- **搜索时两条栏都收起来**：结果来自所有页，留着一条高亮的页签等于说「你在这一页里搜」。
- 面板管理器里也是这两条栏（同一套样式）。**给一页归类**有三条路，随手哪条都行：
  把它的页签**拖到顶栏某一格上**、或点页眉上那颗写着当前分类的按钮。顶栏末尾那颗 **+** 新建一类，
  并**连带在里面建一页**（空分类点进去什么都没有），新的一类排在顶栏末尾，名字当场就能改。
  **双击分类那一格**改名——改的是这一类里每一页的归类名，因为分类不是一条独立记录，它是从页上涌现出来的。
  管理器的分类栏**一直都在**（哪怕只有「未分类」一格），因为那颗 + 是新建分类的唯一入口。
- **两条栏都能自由排序**：拖页签换页的先后，拖顶栏那一格换分类的先后（整类一起走，类内的先后不变）。
  归类时那一页会并到它新那一类的段尾——不并的话两类的页交错，而分类的先后是「哪一类的第一页更靠前」，
  交错之后再拖同一类里的页就可能顺带改掉分类顺序：拖的是页，动的却是分类。
- **右键页签（或页眉）**：重命名 / **从面板移除**。移除只是把这一页从面板上摘下来，动作本身留在「动作」页，热键和定时任务照旧指得到它；真正的删除仍只在那儿，且会先把引用数摆给你看。

**一个组还可以只属于某个程序。** 面板管理器里，每一页的页眉上都写着它绑给谁，默认是淡着的「任何程序」；点一下就能改，或者解回任何程序。（组编辑器里那个**仅在此程序上显示**是同一个字段。）填了进程名，这个组就只在**你呼出面板那一刻正用着那个程序**时才出现在面板上。

**它和分类是两回事。** 分类是你自己起的归类名，绑定程序是「什么时候该出现」——一页可以既归在「写代码」里、又绑给 Code。而且绑定不是管理器里的一层筛选：所有页始终都在栏上，绑了程序的也在——你要改它的绑定，恰恰得先看得见它。筛选只发生在面板真正被呼出的那一刻。

这才是面板值得被呼出的理由：在编辑器上弹出来是你的开发动作，在文件管理器上弹出来是文件动作。匹配的那一页会排到最前、面板打开就停在它上面 —— 对的动作已经在光标底下，不用翻页。当前程序没有对应的页时，面板照旧停在通用页，与没有这个功能时完全一致。

- **前台程序是在面板出现之前的那一瞬读的** —— 面板自己会抢走前台，晚一步问，答案永远是 Clockwork。
- **别和步骤上的进程条件混为一谈。**「仅在此程序上显示」问的是「你此刻正用着哪个程序」，决定这一组**显不显示**；步骤的「进程条件」问的是「那个程序在不在跑」，决定这一步**执不执行**。后者完全可以在后台成立（微信开着，而你在写代码）。
- 通用页上，场景组的格子也排在全局格子前面。
- 前台读不到时（受限进程、没有前台窗口），场景组保持隐藏，而不是跑到错的程序上冒出来。

- **翻页**用滚轮、**PageUp / PageDown**，或直接点索引上的某一段。方向键留给格子之间移动 —— 两者抢同一组键的话，走到行尾到底是换行还是翻页就说不清了。
- **顶部那条索引是一把刻度尺，一段刻度 = 一页**，当前那段是黄铜色。它**取代了数字页码**：一把显示位置的刻度已经把「第几页、共几页」说完了，旁边再写一行 02/04 是同一件事说两遍。页名就在它旁边。
- 页是环绕的，滚过最后一页回到第一页。
- 一页装不下时**在页内纵向滚动** —— 那是容量问题，不该变成第二页。
- 只有一页时，索引和页名整个消失 —— 没有可导航的东西。

### 调成你想要的样子

「设置」页的**快捷面板**一节：

- **版面 —— 读作「列数 × 上带行数 + 下带行数」**（默认 4 × 3 + 4）。凹槽分成上下两条带，中间一条发丝线。两条带没有语义差别，分带是**节奏**：一整块 7 行的方格阵读起来是一堵墙，切成 3 + 4 之后眼睛有了落点 —— 键盘分区是同一个道理。下带设 **0** 即单条带。
  - 列数 × 总行数同时就是**一页的容量**（默认 28 格）。超出的续到下一页，页名不变。
  - 两条带是**上限**不是预留：只有五个动作时下带根本不画，小面板就保持小。
- **格子尺寸**（紧凑 / 标准 / 宽松）—— 紧凑 + 8 列是一块密集的小键盘；宽松 + 3 列是给触摸屏用的大目标。
- **只显示图标** —— 去掉文字、格子收成接近正方，一屏能放下的动作大幅增加。名字仍在悬停提示里，所以这是「把信息挪到需要时才看」，不是把它扔掉。
- **显示自带操作** —— 底部那排重跑清单 / 停止 / 免打扰 / 打开窗口。你要是习惯从托盘够这几样，把它关掉换空间。

## 循环执行

- **整组循环**：动作编辑器里设「整组重复次数 / 每轮间隔」，每次触发时整组按轮数连跑。
- **循环一段步骤**：把这段步骤单独建成一个动作，在原组里用「动作」步骤引用它并设「重复次数」。
- 三种重复各司其职并相乘：单步「重复次数」（一步连跑几次）× 引用步骤的「重复次数」（这段子序列跑几次）× 整组重复（每次触发跑几轮）。
- 组可以嵌套引用组；保存时会检查「动作」**步骤**之间的环引用（A→B→A 会被拦下并报出引用链）。经由消息步骤「点是→运行动作」形成的环不在保存校验范围内，但运行时会被重入保护挡住（跳过并提示，不会空转）。
- **消息步骤答「否」= 全部收手**：组里的消息步骤点「否」（或按 Esc 关掉），本组剩余步骤连同**后续轮次**一起停；这个组若是被别的组引用的，上层的引用轮次也一并停。所以按上面的推荐做法把一段步骤抽成子组引用 ×N 时，拒绝一次就够——不会被同一个确认框追问 N 次。
- 引用的动作**找不到**（组被删、或建步骤时没选组）、**已禁用**、或**正在跑**（含环引用）时都不会默默跳过：找不到与重入按警告提示，已禁用按普通提示（那是你自己关掉的，不是故障）。重入还会停掉这条引用的剩余轮次——同一条提示不会刷 N 遍。
- **组里某一步没生效也会说话。** 脚本文件不存在、程序被卸载、找不到目标窗口这类「跑了但没成」，会弹一条托盘提示并记进 `clockwork.error.log`，整组照常往下走。以前这条路径是完全静默的——同一个步骤放开机清单里有「⚠」可查，而热键、定时静默组（正是无人值守跑的那条）什么都不说。同一步反复出事只叠加计数，不会堆一屏卡片。
- 保险丝：单次运行最多执行 **5000 步**——每个普通步骤的每一次执行算一步，每一次「动作」引用迭代也各算一步（否则一条只含引用、叶子组是空的链条能绕过保险丝）。超出即停并在运行日志里说明。急停键随时可打断。

## 系统启动项

- 列出电脑里**所有开机自启**项（注册表 Run 键 / 启动文件夹 / 计划任务）。
- 取消「启用」勾选即关闭——**只是禁用、不删除，随时勾回来恢复**（即时生效）。
- 带「需管理员」的项：操作时会提示以管理员身份重新打开，同意后再操作即可。
- 系统 / 策略 / 一次性项（组策略 Run、RunOnce、Winlogon、Active Setup）不可改动、**默认不显示**——勾右上角「显示系统 / 只读项」才列出（置灰、仅供查看；对它们下面两个右键操作也不可用）。
- **右键某行**有两个操作：
  - **「接管到启动清单」** —— 把某项交给本工具接管（自动停用原项 + 加进你的清单）。仅支持注册表 Run 键与启动文件夹项；计划任务暂不支持，会给出提示。
  - **「从系统中删除」** —— 彻底移除该项（注册表值 / 启动文件夹快捷方式 / 计划任务）。会先弹确认，**且无法撤销**；若只是不想让它开机启动，取消「启用」勾选即可。若该项此前被接管、清单里仍有步骤指向它的快捷方式，确认框会特别说明——因为删掉快捷方式会让那个步骤失效。
- 顶部**过滤框**可按名称 / 命令快速筛。

## 端口

- **一行 = 一个端口**（不是一个进程），后面跟着占着它的全部进程。IPv4 / IPv6 两张表都读，同一个服务同时监听 `127.0.0.1` 和 `::1` 也只算一行（地址列并排显示）。
- **一个端口确实可能被好几个进程同时占着**，进程列会写成 `python ×2`，PID 列列出全部。Windows 的 `SO_REUSEADDR` 允许后来者直接绑到一个已被占用的地址上（Linux 上这个选项基本只影响 TIME_WAIT，语义完全不同），而**哪一个真正收新连接微软文档写的是 indeterminate**——实测过：连续三次连接全部落到**先**启动的那个，按启动时间猜会猜反。Python 的 `HTTPServer` 默认就开着它，所以同一个脚本跑两遍不会报错——早那个变成收不到连接的僵尸，而从外面看一切正常。按端口分行才看得出这件事。
- **切到这一页时重新扫描，停在这页时每 5 秒自动刷新**——新起的服务最多 5 秒就自己出现，不用等你去点。左下角的**「刷新」**保留，想立刻看时用。右下角常驻一行 **`5 / 49 个端口 · 每 5 秒自动刷新`**：分子是当前档位筛出来的，分母是全部正在监听的——用一个数字回答「我是不是被藏了东西」，比拿一段说明去解释筛选规则快得多。
  - 扫描结果与上一轮完全相同时**一个界面元素都不会动**，所以不会闪、不会丢选中行、不会把滚动位置弹回去。
  - 窗口隐到托盘、或你切到别的标签页时，轮询停掉。
- **「来源」列**回答「这个端口到底是谁」，格式是 **「项目 · 入口」**：光看进程名，两个 `node` 分不出来，但 `web-tools-by-ai · start-server.js` 和 `035-shiye · cdp-proxy.mjs` 一眼就能分。
  - **项目取自进程的工作目录**——这是最可靠的一刀，因为 dev server 的 cwd 就是项目根。`tools\serve.py` 这种相对路径，除了 cwd 没有任何办法知道它属于哪个项目。
  - cwd 落在 `C:\Windows` 这类无身份目录时，退回按命令行路径推断：`node_modules` 前一段就是项目名；再不行就跳过 `scripts` / `bin` / `dist` 这类通用目录往上找。
  - **悬停看完整命令行与工作目录**。提权 / 受保护进程两样都读不到，这一列会空着（实测 34 个占端口进程里能读到 13 个，读不到的都是 svchost 这类）。
- 注意它**不参与分档**：`cdp-proxy` 这类工具链常驻服务照样出现在「只看项目服务」里。有意不去猜——来源已经写在那里，看一眼就知道是谁，比一条会出错、会把你自己的服务藏起来的规则可靠。
- **双击一行**用默认浏览器打开 `http://localhost:<端口>`；右键菜单里的**「用浏览器打开」**是同一个动作。
- 一个进程常常占着**好几个端口**（Next 的构建 worker、QQ / 微信都是如此）。前两档**只显示对外的那个**（绑 `0.0.0.0` / `::` 的），其余折起来，端口列写成 `3000 +7` 告诉你还有多少个——实测一个 Next 服务就占 14 个端口，只有 1 个对外，其余全是 worker 的内部通信（只绑 `127.0.0.1`），逐个占一行会把列表淹掉。
  - 一个都不绑全网卡时退回最小端口号；真对外服务两个端口（HTTP + HTTPS）时两个都留。**「显示全部端口」那一档不折叠**，那一档的意思就是逐条列全。
  - 被折起来的端口不是消失了：**释放其中任一个，它们会一起没**，**悬停这一行**就会把它们逐个列出（`同时监听：10290, 10291`）；释放端口的确认框里也会再列一遍。搜索也仍然找得到它们（见下）。
- 右键**「释放端口」** —— 结束占用该端口的**全部**进程，每个都**连同子进程一起**（`npm run dev` 这类会自己起 worker，只杀监听的那个会留下孤儿）。确认框会逐个点名要结束的进程（`python (8588)、python (9800)`），**未保存的内容会丢失**。只被内核占位（PID 0 / 4）的行没东西可杀，菜单项置灰。
- 右上角两个复选框拼出**三档视图**，从窄到宽（**各自的判据写在它自己的悬停提示里**——「这个开关到底按什么认」这个问题，人恰好是在指着这个开关时才问）：
  - **「只看项目服务」（默认开）** —— 两个判据取并集：
    - **工作目录里有项目标记**（沿 cwd 往上最多找 6 层，看 `.git` / `package.json` / `pyproject.toml` / `go.mod` / `Cargo.toml` 等）——**主判据**。它不看进程名，所以 Go / Rust 编译出的任意命名二进制也能认出来——那正是纯白名单已知的盲区。
    - **进程名在运行时白名单里**（node / bun / deno、python、java、dotnet、ruby / php、nginx / caddy、postgres / mysqld / mongod / redis-server、Docker 端口转发进程、ngrok / cloudflared / ollama 等）——**补充**。提权进程读不到 cwd，只靠主判据会把那种情况下的 dev server 一并藏掉。
    - 这一档**不卡 1024 门槛**，本地 nginx 起在 80 上也能看到。
  - **两个都不勾** —— 只挡系统服务：端口 ≥ 1024、排除内核占位，并挡掉 `svchost`、`services` 等噪音源（svchost 一开机就占十来个动态端口）。**Go / Rust 编译出来的二进制叫什么名字都有，白名单必然漏掉，就在这一档找**。
  - **「显示全部端口」** —— 不过滤。勾上它时「只看项目服务」会置灰（两者同时勾上是自相矛盾的说法）。
- 「只看项目服务」的勾选状态**会存进配置**，不用每次重启重新勾；「显示全部端口」不存，它是一次性的「让我看看全貌」。
- 顶部**过滤框**可按端口号、进程名或命令行筛（只要匹配到任一占用者就算命中，所以搜「serve」或项目名比记端口号更顺手）。
  - **有搜索词时不折叠**：折叠是为了让默认浏览视图安静，而你敲了查询就是明确表达了要找什么——否则敲一个被折进去的端口号（它真实存在）会得到零行。
  - 但它**不绕过档位**：是在当前那一档之上再筛。想看系统服务请勾「显示全部端口」，搜索不会把它们捞回来。

## 鼠标手势

按住**右键**画一条轨迹，松手即运行对应的动作。管理器的入口是**主窗口标签条右端那颗折线图标**，快捷面板表圈右端也有一颗。

- **一条手势 = 一个动作 + 一条轨迹。** 动作就是普通的步骤，十种类型任选；「跑一整个动作」用**运行动作**步骤指过去。所以「粘贴」「锁屏」这种只作为手势存在的动作，不必先为它建一个动作。其中最常用的那十几个——复制 / 粘贴 / 搜索选中的文字 / 后退前进 / 播放暂停与上下一曲 / 音量增减 / 最小化·最大化·切换置顶·关闭当前窗口——在「新增 ▾ → 常用」里直接有，选完画一条轨迹就成了。
- **画的时候看得见，而且认出来的那一刻线会变亮。** 右键一动，屏幕上就跟着出一条线；**一旦画出的轨迹命中了某条手势，线立刻变亮加粗**——松手之前你就知道认没认出来，不必等松手才发现画歪了。它会跟着继续画而灭掉、再亮起：画出 ↑ 命中「复制」，往下画成 ↑↓ 就灭，成为「搜索」时重新亮。只换颜色和粗细，不闪不弹不出字——这条线本来就在你眼睛正看的地方。那条线**点得穿、也不抢焦点**：指针下面的程序照常收到你的一切操作，所以「最小化当前窗口」这类动作认的仍是你原本在用的那个窗口，不是这条线。
- **八个方向**：← ↑ → ↓ 以及四个斜角 ↖ ↗ ↙ ↘。轨迹存成方向串（轴向 `L U R D`，斜角借小键盘布局的 `7 9 1 3`），显示时换成箭头。
- **画歪一点没关系。** 八个扇区不是平分的：轴向各 56°、斜角各 34°。轴向是默认意图、斜角是刻意为之，所以宽容度给轴向 —— 横线歪到 28° 仍读作「→」，而认真画的 45° 斜线离两侧边界还有 17°。画在边界上的直线不会反复横跳：它切出的那串交替短腿会被逐个并进最长的一条（见下一条）。
- **两段就是两个方向。** 方向是按「腿」测的，不是按滑动窗口测的：拐角处那一小段横跨两条腿、本身是斜的，若拿它定方向就会凭空多出一个斜角。这里先细采样存点，抬起时切成若干腿，短于最短腿长的并入较长的邻居，再用每条腿的首尾两点重新定方向。
- **首次使用带 10 条样例，装完即可用。** 手势与示例清单、示例提醒不同：后两者会去开程序、会弹窗打断，所以默认不启用；手势只在你主动画出一条轨迹时才发生，画之前什么也不做。

  **代价说在前面**：只要有一条启用的手势，右键就被接管。按下会被先扣住，直到你松手、或者**按住不动 0.2 秒**，所以**右键拖拽要先停一下再拖** —— 按下、等一下、再拖（资源管理器里右键拖文件、3D 软件里右键旋转、右键拖动滚屏都照这个来）。那一停正是两者的分界：手势是按下就开始动的，按下不动的就不是手势，右键随即还给系统。要让右键完全不被碰，翻下面那个总开关；不想要某一条，在管理器里取消勾选它即可。

  | 轨迹 | 动作 | | 轨迹 | 动作 |
  |---|---|---|---|---|
  | ↑ | 复制 | | ↙ | 最小化当前窗口 |
  | ↓ | 粘贴 | | ↗ | 最大化当前窗口 |
  | ← | 后退 | | ↖ | 切换当前窗口置顶 |
  | → | 前进 | | ↘ | 关闭当前窗口 |
  | ↑↓ | 搜索选中的文字 | | →↓ | 到最底部 |

  轴向那四条给最常用的四件事，也最好画（轴向扇区各 56°，斜角只有 34°）。**四个斜角凑齐窗口的四件事**，方向本身就是意思：往左下收起、往右上撑开、往左上钉住、往右下扫走。置顶是开关，同一条手势管「钉住」和「放开」。

  「关闭」放在斜角上是有意的：斜角扇区只有 34°，画不准就不会中——一个会关掉窗口的动作，**不容易误画正是它该有的性质**，而轴向那 56° 的宽容度该留给无害的操作。

  **两笔的那两条都用轴向，不用斜角。** 「搜索选中的文字」曾经是 ∧（↗↘），实测它只在两条腿都画在 40–60° 且画得干净时才读作 ↗↘：人画尖角自然会画到 65–80°，那就落进 ↑ 和 ↓ 的扇区，稳定读成 ↑↓；再画弯一点，顶点还会多切出一两个方向。斜角扇区本来就只有 34°，两条腿的误差叠加还要过一个顶点，可用窗口窄得没剩多少。改成 ↑↓ 之后 80–90° 任意画法都稳——**把手本来就在画的形状认下来，比逼手去画 45° 强**。同类工具也是这么做的：默认手势集清一色轴向组合（WGestures 默认干脆只开四向，八向是选项）。

  两笔手势有个固有性质：第二笔太短就会读成第一笔。↑↓ 的第二笔落空会跑「复制」，无害；选它而不是 ↓↑，正是因为后者落空会跑「粘贴」，那会改掉你的内容。

  单条斜角（窗口那四条）比斜角组合可靠得多，但也要**对着屏幕的角画**：画歪时可用窗口大约是 40–50°，超出就落到相邻的轴向上去了。
- **总开关：「设置」页的「使用鼠标手势」，手势管理器标题行右边也有一个。** 关掉即完全不监听右键——一个开关，比把每条逐个取消勾选、事后再逐个勾回来强。右键拖拽不必靠它（先停一下就行），所以它是留给「要右键完全不被碰」的场合：某个程序自己对按住右键另有安排，或者你让别的手势软件去画。勾掉当下就生效，不用重启。
- **没配手势时右键完全不受影响。** 只有总开关开着**且**存在启用的手势，程序才装那个全局鼠标钩子；否则一根毫毛不动。
- **连着画两次就跑两次。** 界面上那颗「运行」按钮有一道防连点的闸（气泡回执要几秒才出，急着连点会把同一步跑两遍），**手势不走那道闸**：画一次要花一秒，画两次就是故意的——↖ 切换置顶正是这种用法（钉住、再放开）。而那道闸拦下时是彻底无声的，用在手势上会变成「连着画两次，第二次凭空消失」。
- **跑成功不弹回执，跑失败才弹。** 十条默认手势里八条效果肉眼直接可见（粘贴出字、窗口最小化、浏览器打开），再弹一张卡等于每天几十次地把你已经看见的事又说一遍。但**失败一定要说**——手势失败是彻底无声的（窗口被未保存对话框挡着关不掉、搜索时其实什么都没选中），没有那张卡就只剩「我画了，没反应」。于是三种结局分得开：**没绑动作**＝收笔处的小药丸写着你画的串；**跑成功**＝什么都没有，动作本身就是回答；**跑失败**＝通知卡写明哪一步、为什么。
  （编辑器里那两颗 **▶ 运行** 按钮照旧弹回执——那儿是在试跑，屏幕上多半看不出变化，那张卡是它唯一的结果。）
- **画了但没匹配上：什么都不发生，但会就地告诉你画的是什么。** 补发一次右键会在轨迹终点弹出一个莫名其妙的菜单，比没反应更糟；而完全沉默会把「没绑动作」「画歪了」「动作跑失败了」混成同一种「按了没反应」。所以收笔处会浮出一颗小药丸写着你画出来的那一串（比如 `↑↓`），亮 0.9 秒自己消失 —— **不是通知卡**：手势是一划而过的操作，反馈不该比操作本身还重，也不该出现在离你的手一整个屏幕远的角落。**没画就松手**则补发一次真正的右键 —— 上下文菜单本来就出在松手那一刻，用户无感。**按住不动**满 0.2 秒，那次按下本身就还给系统：菜单在你手指还按着的时候就出来，不用等你松手。
- **绑的是动作时，再画一次即停下** —— 与热键触发动作的语义一致，学一次就够。
- **录入方式就是使用方式。** 管理器右边那块画布用的是运行时同一个量化器，你在上面画出什么就存什么；列表里的缩略图画的也是真实笔迹，认一条手势靠的是形状，不是读它的名字。
- 两条手势不能绑同一条轨迹（会当场拦下并说明是谁占着）—— 否则跑哪个只能看列表顺序，没法预期。

> **监听期间右键拖拽要先停一下**：按下、按住不动约 0.2 秒，再拖（资源管理器里拖文件、3D 软件里转视角）。同类工具也是这么做的。只在存在手势时才有这个影响。

### 想用别的手势软件？让它来调 Clockwork

Clockwork 的手势不是二选一的门槛。**动作本来就能从外部触发**（见[从外部触发一个动作](#从外部触发一个动作)），所以专业手势工具完全可以只负责「画」，动作这一半仍旧留在 Clockwork 里：

1. 手势管理器标题行右边的**总开关关掉** —— 右键当场恢复原样，一个钩子都不装。
2. 在 WGestures / StrokesPlus.net / Quicker 里画你要的手势。
3. 那条手势的动作设成运行：

   ```
   Clockwork.exe --run-group "专注"
   ```

请求会交给托盘里那份常驻实例执行，启动的这个进程立刻退出，**不弹任何窗口**。

这么做换来两件事：那些工具在手势识别上打磨的年头比我们长；而且**右键完全不被碰**——一个钩子都不装，拖拽不用先停一下，遇上那种对按住右键另有安排的程序也不会出岔子。它们多半还提供排除名单这类更细的开关，而 Clockwork 这边的取舍是「简单，代价说清楚」。

反过来说，只用 Clockwork 自带的手势也完全够——十条样例装完即用，不必先去装一个手势软件。

## 设置

分三段，顺序照「什么时候会用到它」排。

**开机与启动**

- **开机自启**：这一段的总开关，故排在最前——一个复选框，勾上即以管理员权限注册计划任务（开机不弹授权框），取消勾选即移除。需要提权时程序会自己重开一次去办；万一没办成，勾选状态会弹回原样，不会显示一个假的状态。
- **开机延迟**（0–600 秒）：登录后先等这么久再跑清单，避开登录风暴。**仅开机自启时生效**，手动「重新运行启动清单」不受影响。
- **等系统就绪再跑**（桌面 / 网络）：就绪即走、最多等 90 秒，然后再叠加上面的固定延迟。开机太早、软件起不来时开它比一味调大延迟更准。
- **启动时最小化到托盘**（手动打开也直接进托盘、不弹主窗口）。

**常规** —— 全应用范围的东西，其中前两项都是「全局怎么叫它」。

- **急停键**：点击输入框后按下想要的快捷键即录入，Esc 取消、Del 清空停用；默认 `Ctrl+Alt+Q`。
- **鼠标手势**：入口是**主窗口标签条右端那颗折线图标**（「管理手势…」），不在设置页里；快捷面板表圈右端也有一颗。没有启用的手势时右键完全照常。
- **界面语言**：简体中文、English、日本語 等共 18 种，切换后自动重启生效。
- **主题**：深色 / 浅色 / 跟随系统，切换后自动重启生效。「跟随系统」读的是 Windows 设置里的**应用**模式（不是系统模式），与资源管理器保持一致。
- **导出配置**：把 `clockwork.settings.json` 另存到你选的位置（默认文件名 `clockwork.settings.backup.json`）。适合大改前先备份，或把整套设置搬到另一台电脑。
- **导入配置**：用选定文件**覆盖当前全部配置**（启动清单 / 定时任务 / 动作 / 手势 / 设置）。会先弹确认，把当前配置备份成 `clockwork.settings.json.bak` 留一条后路，校验文件能正常解析后再覆盖，随后自动重启让配置全量生效。任务状态（`clockwork.state.json`）不受影响。
- **配置文件读不出来时不会被覆盖。** 手改 json 漏个逗号、或上次保存时断电留下半截文件，启动时会以默认配置起来、弹一条提示，并把原文件另存为 `clockwork.settings.json.bad`。原文件不会被默认配置盖掉——修好它再重启即可恢复；即使你没注意到提示、照着重建了一遍再保存，那份 `.bad` 也还在。

**快捷面板** —— 六项，全都只影响那一个浮层；顺序按「先怎么叫出来、再长什么样」。呼出方式两项、外观四项，详见前面的**快捷面板**一节。

- **快捷面板键**：用法同急停键；默认 `Ctrl+Alt+Space`。清空它之后托盘菜单里的入口还在，面板照样打得开。组合被别的程序占用时会注册失败并弹卡片点名——换一个即可；急停键先注册，撞车时它优先。
- **长按鼠标中键唤出面板**：默认关闭，旁边跟着长按时长（350 毫秒，夹在 150–2000）。放行规则与细节见前面的**快捷面板**。
- **版面 / 格子尺寸 / 只显示图标 / 显示自带操作**：见前面**调成你想要的样子**。

## 小提示

- 双击 `Clockwork.exe` 只打开设置窗口，**不会**立刻执行启动清单；要立刻跑用托盘「重新运行启动清单」。
- **右侧按钮跟着选中项走**：没选中任何一行时，「编辑 / 删除 / 上移 / 下移 / 运行」整组置灰——它们只对选中项生效。「新增」始终可用。右键菜单里的「复制」（定时任务页还有「今天不再」）同理：没选中、或右键落在表头 / 空白处时，菜单干脆不弹——弹一个作用在别处的菜单比不弹更糟。
- **列宽装不下的内容不会被无声切掉**：四个列表里被截断的单元格都以「…」收尾，鼠标悬停即可读到整格全文。
- **删除一律先弹确认**：列表条目、动作编辑器里的步骤、系统启动项都一样，确认框会写明要删的是哪一条，选错了能在删掉前发现。
- 个人设置存在文件夹内的 `clockwork.settings.json`（只在你自己电脑上）；删掉它重开程序即可恢复成示例配置。任务状态存在 `clockwork.state.json`（同样只在本机，删掉无妨——最多当天的任务再触发一次）。面板格子的点击统计存在 `clockwork.usage.json`（同样只在本机，删掉也只是丢掉计数）。备份或换电脑建议用设置页的**「导出配置 / 导入配置」**。
- **这几个文件放在哪：** 首次运行时，`Clockwork.exe` 所在目录可写就放在它旁边（常见的绿色便携用法）；不可写（比如放在 `C:\Program Files` 下）则落到 `%APPDATA%\Clockwork\`。**此后认的是「配置已经在哪」，不再每次重新判断目录可不可写**——否则同一台机器上「双击打开」（不提权）和「开机自启」（提权）会挑到不同的两份配置，表现成「以管理员重开后设置全空」或「开机跑的清单不是我配的」。「导出配置」导出的始终是当前实际生效的那份，不必自己去找。
- 填路径 / 进程 / 日期不用硬记：**行尾的 … 按钮**会打开对应的选择器（文件、带搜索的进程列表、日期），组合键点 **「捕获」** 按一下即录。进程选择框和系统启动项列表都带搜索 / 过滤。
- 请用**正常方式启动**（双击 `Clockwork.exe` / 托盘 / 计划任务）。若用某些沙箱 / 受限权限的启动器（如 Lucy）打开，Windows 会限制部分底层调用，发送按键 / 鼠标 / 窗口动作 / 已运行则激活 / 发送文本到指定进程 / 音量 等原生功能可能不可用（会给清楚提示，不影响单纯「启动程序」）。
- 全局热键可用来**触发动作**（每组单独设，见上）。任意按键重映射 / 文本展开仍不在本工具范围（那是 AutoHotkey 的强项；加 `.ahk` 步骤需装 AutoHotkey）。
